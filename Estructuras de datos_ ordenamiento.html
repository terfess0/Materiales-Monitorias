3. Ordenamiento y Búsqueda en C++

Algoritmos clásicos: Burbuja, Shell, Quicksort, Mergesort y Búsqueda (Lineal y Binaria). Análisis de rendimiento temporal, memoria RAM y aplicaciones en bases de datos e industria.

¿Por qué estudiar cómo ordenar?

Ordenar datos es una de las operaciones más costosas computacionalmente. Elegir el algoritmo correcto según el volumen de datos y la memoria disponible es clave en el desarrollo de software profesional.

Avanza con las flechas del teclado o los botones inferiores.

3.1. Tipos de Ordenamiento (Conceptos)

No todos los algoritmos son iguales. Se clasifican principalmente por cómo manejan la memoria y si mantienen el orden original de datos duplicados.

Por Uso de Memoria (Espacio)

  • In-place (En el lugar): Ordenan los datos modificando el array original sin requerir arrays adicionales grandes. Son muy eficientes en memoria (Costo espacial: O(1)).
    Ej: Burbuja, Shell, Quicksort.
  • Out-of-place (Con memoria extra): Requieren crear arrays temporales para copiar datos. Si tienes 1GB de datos, necesitarás 1GB extra de RAM (Costo espacial: O(N)).
    Ej: Mergesort.

Por Estabilidad

  • Estables: Si dos elementos tienen el mismo valor, conservan el orden relativo en el que aparecieron originalmente.
    Ej: Burbuja, Mergesort.
  • Inestables: No garantizan conservar el orden relativo entre elementos iguales. Al dar saltos grandes o particiones, los pueden invertir.
    Ej: Quicksort, Shell Sort.
EJEMPLO PRÁCTICO: CRITERIO DE ESTABILIDAD (Aclaración: No aplica al uso de memoria; demuestra únicamente el orden de datos duplicados)

Demostración del Criterio de Estabilidad: ¿Qué ocurre con dos datos de igual valor?

Imagina ordenar una lista de estudiantes por nota. Si dos estudiantes tienen la misma nota (5), ¿cuál de los dos queda primero en la lista ordenada? Observa qué ocurre con 5ₐ (primer registro) y 5ᵦ (segundo registro):

Lista Inicial: 3 5ₐ 1 5ᵦ

Algoritmo ESTABLE (Burbuja, Mergesort)

1 3 5ₐ 5ᵦ

5ₐ estaba antes que 5ᵦ al inicio y permanece antes al terminar. Conserva intacto el orden de llegada original.

Algoritmo INESTABLE (Quicksort, Shell)

1 3 5ᵦ 5ₐ

Al dar saltos o particiones, 5ᵦ se cruzó y quedó ubicado antes que 5ₐ. Aunque ambos valen 5, se alteró su orden relativo inicial.

3.2. Ordenamiento Burbuja (Bubble Sort)

Compara elementos adyacentes y los intercambia si están en el orden equivocado. Los valores más grandes "burbujean" hacia el final del array en cada pasada.

Tiempo Promedio: O(N²) - Muy Lento
Memoria (Espacio): O(1) - In-place
Estable: Sí

Uso: Solo con fines educativos o para arrays extremadamente pequeños. En C++, es muy ineficiente porque usa bucles anidados evaluando absolutamente todo una y otra vez.

3.3. Ordenamiento Shell (Shell Sort)

Mejora de la inserción. En lugar de comparar elementos adyacentes, compara elementos separados por un "hueco" (gap) que se va reduciendo hasta llegar a 1. Esto permite dar saltos largos.

Tiempo Promedio: O(N log N) a O(N^1.5)
Memoria (Espacio): O(1) - In-place
Estable: No

Comportamiento en Memoria: Sigue siendo In-place (no crea arrays nuevos), pero al dar "saltos", altera el orden original de datos duplicados (inestable).

Haz clic en Siguiente Paso para comenzar con Gap = 3.

3.4. Ordenamiento Rápido (Quicksort)

Utiliza la técnica "Divide y Vencerás". Elige un elemento llamado Pivote, y mueve todos los números menores a su izquierda y los mayores a su derecha. Luego repite el proceso recursivamente en cada mitad.

Tiempo Promedio: O(N log N) - Muy Rápido
Tiempo Peor Caso: O(N²)
Memoria (Espacio): O(log N) - En la pila (Stack)
Estable: No

Comportamiento en Memoria: El array se modifica In-place (no requiere arreglos paralelos gigantes). Sin embargo, al ser recursivo, cada llamada a la función consume un poco de memoria en el Stack de llamadas.

Haz clic en Siguiente Paso para elegir un Pivote y particionar.

3.5. Ordenamiento por Mezcla (Mergesort)

Divide el array por la mitad una y otra vez hasta tener elementos individuales. Luego, los va mezclando (merge) de vuelta pero de forma ordenada. Garantiza el mismo rendimiento sin importar qué tan desordenado esté el array.

Tiempo Garantizado: O(N log N) - Estable y Rápido
Memoria (Espacio): O(N) - Out-of-place
Estable: Sí

El Costo en Memoria: Su gran desventaja en C++ es que requiere memoria auxiliar. Para mezclar las mitades ordenadas, necesita crear un Array Temporal. Si ordenas 1 GB de datos, Mergesort consumirá 1 GB adicional de memoria RAM.

3.6. Ordenamiento en la Industria y Bases de Datos

¿Cómo ordenan sistemas gigantescos como PostgreSQL, MySQL o Google cuando los datos no caben en la memoria RAM?

1. External Merge Sort (Ordenamiento Externo)

Cuando un dataset (ej. 100 GB) supera la memoria RAM disponible (ej. 8 GB), Quicksort no puede usarse directamente porque no puede hacer intercambios aleatorios en disco duro.

  • Fase 1 (Generación de Runs): Se leen bloques de datos que sí caben en RAM (ej. de 4 GB), se ordenan en memoria con Quicksort y se guardan temporalmente en disco como archivos ordenados llamados Runs.
  • Fase 2 (K-Way Merge): Con varios runs en disco, se cargan pequeños búferes de lectura en RAM y se fusionan ordenadamente hacia el archivo final (exactamente el principio de Mergesort).

2. Índices B-Tree en Bases de Datos Relacionales

En motores SQL (PostgreSQL, MySQL, SQLite), ejecutar SELECT * FROM Estudiantes ORDER BY codigo; no ordena la tabla desde cero en cada consulta. En su lugar, el motor mantiene un Índice en Árbol B+ (B+Tree) donde las claves ya residen ordenadas en páginas de almacenamiento, permitiendo lecturas secuenciales ultrarrápidas.

3. Algoritmos Híbridos en Producción

En los compiladores y lenguajes profesionales casi nunca se usa un solo algoritmo puro; se combinan los mejores enfoques:

  • Introsort (C++ std::sort): Comienza con Quicksort por su velocidad in-place. Si la recursión se vuelve muy profunda (riesgo de caer en $O(N^2)$), conmuta automáticamente a Heapsort garantizando $O(N \log N)$. Si el subarreglo tiene menos de 16 elementos, conmuta a Insertion Sort.
  • Timsort (Python, Java, Android, Rust): Diseñado por Tim Peters. Aprovecha secuencias que ya vienen ordenadas en datos de la vida real (runs naturales) y las fusiona usando principios de Mergesort e Inserción.

Regla de Oro en la Industria

"Ordena una sola vez con un buen algoritmo ($O(N \log N)$), o indexa con un B-Tree, para que luego todas las búsquedas sean casi instantáneas ($O(\log N)$)."

3.7. Algoritmos de Búsqueda: Lineal y Binaria

El propósito principal de ordenar un array es acelerar drásticamente la búsqueda de información.

Búsqueda Lineal: O(N) — Datos sin ordenar
Búsqueda Binaria: O(log N) — Requiere Array Ordenado

La Diferencia Matemática

Si tienes 1,000,000 de registros:

  • Búsqueda Lineal: Recorre uno a uno desde el inicio. Peor caso: 1,000,000 de comparaciones.
  • Búsqueda Binaria: Descarta la mitad en cada paso ($medio = (inicio + fin) / 2$). Peor caso: ¡Solo 20 comparaciones! ($\log_2 1,000,000 \approx 19.9$).

¡Prueba el simulador de la derecha con el mismo número y compara la cantidad de pasos que toma cada una!

3.8. Caso Práctico de Búsqueda en C++ (Evaluación)

Implementación en consola de un caso típico para evaluación práctica en salas de cómputo: Sistema de Estudiantes con búsqueda lineal y binaria.

Caso: Registro de Notas de Estudiantes Unitrópico

En este ejercicio resolvemos el flujo completo evaluado en laboratorio: 1) Estructura de datos struct, 2) Búsqueda Lineal sobre datos desordenados, 3) Ordenamiento por código, y 4) Búsqueda Binaria para consultas ultrarrápidas.

#include <iostream>
#include <string>
using namespace std;

struct Estudiante {
    int codigo;
    string nombre;
    float nota;
};

// 1. Busqueda Lineal O(N): Funciona con el arreglo tal como viene (desordenado)
int busquedaLineal(Estudiante arr[], int n, int codigoBuscado, int &comparaciones) {
    comparaciones = 0;
    for (int i = 0; i < n; i++) {
        comparaciones++;
        if (arr[i].codigo == codigoBuscado) {
            return i; // Encontrado en indice i
        }
    }
    return -1; // No existe
}

// 2. Ordenamiento por Codigo (Burbuja optimizada con bandera)
void ordenarPorCodigo(Estudiante arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool huboCambio = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j].codigo > arr[j + 1].codigo) {
                Estudiante temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                huboCambio = true;
            }
        }
        if (!huboCambio) break; // Ya ordenado
    }
}

// 3. Busqueda Binaria O(log N): Requiere que arr[] este PREVIAMENTE ORDENADO
int busquedaBinaria(Estudiante arr[], int n, int codigoBuscado, int &comparaciones) {
    int inicio = 0;
    int fin = n - 1;
    comparaciones = 0;

    while (inicio <= fin) {
        comparaciones++;
        int medio = inicio + (fin - inicio) / 2; // Evita desbordamiento de enteros

        if (arr[medio].codigo == codigoBuscado) {
            return medio; // Encontrado
        }
        if (arr[medio].codigo < codigoBuscado) {
            inicio = medio + 1; // Descartar mitad izquierda
        } else {
            fin = medio - 1;    // Descartar mitad derecha
        }
    }
    return -1; // No encontrado
}

int main() {
    const int TOTAL = 5;
    Estudiante grupo[TOTAL] = {
        {1050, "Carlos Perez", 4.2},
        {1010, "Ana Gomez",    4.8},
        {1090, "Laura Rios",   3.9},
        {1030, "David Castro", 4.5},
        {1070, "Sofia Rojas",  3.5}
    };

    int codigoTarget = 1030;
    int comps = 0;

    cout << "--- 1. BUSQUEDA LINEAL (SIN ORDENAR) ---\n";
    int idxLin = busquedaLineal(grupo, TOTAL, codigoTarget, comps);
    if (idxLin != -1) {
        cout << "Estudiante: " << grupo[idxLin].nombre << " | Nota: " << grupo[idxLin].nota
             << " (Comparaciones: " << comps << ")\n\n";
    }

    cout << "--- 2. ORDENANDO POR CODIGO INSTITUCIONAL ---\n";
    ordenarPorCodigo(grupo, TOTAL);
    for (int i = 0; i < TOTAL; i++) {
        cout << "[" << grupo[i].codigo << "] " << grupo[i].nombre << "\n";
    }

    cout << "\n--- 3. BUSQUEDA BINARIA (SOBRE ARRAY ORDENADO) ---\n";
    int idxBin = busquedaBinaria(grupo, TOTAL, codigoTarget, comps);
    if (idxBin != -1) {
        cout << "Estudiante: " << grupo[idxBin].nombre << " | Nota: " << grupo[idxBin].nota
             << " (Comparaciones: " << comps << ")\n";
    }

    return 0;
}

2. Ordenamiento Shell (Shell Sort)

8. Shell Sort Clásico Avanzado

Planteamiento: Implementa Shell Sort dividiendo repetidamente el "gap" (espacio) a la mitad (N/2) hasta que el gap sea 1.

#include <iostream>
using namespace std;

int main() {
    int arr[] = {12, 34, 54, 2, 3};
    int n = 5;
    
    // El salto (gap) inicia a la mitad del array
    for (int gap = n/2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i += 1) {
            int temporal1 = arr[i];
            int j;
            for (j = i; j >= gap && arr[j - gap] > temporal1; j -= gap) {
                arr[j] = arr[j - gap];
            }
            arr[j] = temporal1;
        }
    }
    return 0;
}

3. Ordenamiento Rápido (Quicksort)

16. Función Partición de Quicksort Avanzado

Planteamiento: Crea la función particionar que elige el último elemento como Pivote y acomoda los menores a su izquierda. Retorna el índice final del pivote.

#include <iostream>
using namespace std;

int particionar(int arr[], int bajo, int alto) {
    int pivote1 = arr[alto];
    int i = (bajo - 1);
    
    for (int j = bajo; j <= alto - 1; j++) {
        if (arr[j] < pivote1) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[alto]);
    return (i + 1);
}

4. Ordenamiento por Mezcla (Mergesort)

23. Función Merge (Mezclar) Out-of-place Avanzado

Planteamiento: Escribe la función mezclar() que recibe dos mitades de un array y utiliza arreglos temporales (memoria auxiliar) para ordenarlas de vuelta en el array original.

#include <iostream>
using namespace std;

void mezclar(int arr[], int inicio, int medio, int final) {
    int n1 = medio - inicio + 1;
    int n2 = final - medio;
    
    // Memoria Auxiliar (Out-of-place)
    int izq[n1], der[n2];
    for (int i = 0; i < n1; i++) izq[i] = arr[inicio + i];
    for (int j = 0; j < n2; j++) der[j] = arr[medio + 1 + j];
    
    int i = 0, j = 0, k = inicio;
    while (i < n1 && j < n2) {
        if (izq[i] <= der[j]) { arr[k] = izq[i]; i++; }
        else { arr[k] = der[j]; j++; }
        k++;
    }
    while (i < n1) { arr[k] = izq[i]; i++; k++; }
    while (j < n2) { arr[k] = der[j]; j++; k++; }
}

#include <iostream>

void mezclar(int arr[], int inicio, int medio, int final); // Ejer. 23

void mergeSort(int arr[], int inicio, int final) {
    if (inicio >= final) return; // Caso base
    
    int medio = inicio + (final - inicio) / 2;
    
    // Divide y Venceras

5. Algoritmos de Búsqueda (Lineal y Binaria)

Búsqueda Binaria Recursiva Intermedio

Planteamiento: Implementa la versión recursiva de la búsqueda binaria en C++. Si el elemento central coincide, retorna el índice; si es menor, llama recursivamente a la mitad izquierda; si es mayor, a la mitad derecha.

#include <iostream>
using namespace std;

int busquedaBinariaRec(int arr[], int inicio, int fin, int valor) {
    if (inicio > fin) return -1; // Caso base: no encontrado

    int medio = inicio + (fin - inicio) / 2;

    if (arr[medio] == valor) return medio; // Caso base: encontrado

    if (valor < arr[medio]) {
        return busquedaBinariaRec(arr, inicio, medio - 1, valor); // Mitad izquierda
    } else {
        return busquedaBinariaRec(arr, medio + 1, fin, valor);     // Mitad derecha
    }
}

int main() {
    int ordenado[] = {10, 25, 32, 45, 58, 63, 77, 89, 94};
    int n = 9;
    int objetivo = 58;
    int idx = busquedaBinariaRec(ordenado, 0, n - 1, objetivo);
    if (idx != -1) cout << "Valor " << objetivo << " encontrado en indice " << idx;
    return 0;
}

Búsqueda en Colecciones con <algorithm> Básico

Planteamiento: Compara el uso de std::binary_search (retorna bool) con std::lower_bound (retorna la posición/iterador) de la biblioteca estándar de C++.

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {5, 12, 18, 25, 33, 47, 52};
    int dato = 25;

    // binary_search solo confirma existencia (true/false)
    if (binary_search(v.begin(), v.end(), dato)) {
        cout << dato << " existe en el vector.\n";
    }

    // lower_bound nos da la posicion exacta
    auto it = lower_bound(v.begin(), v.end(), dato);
    if (it != v.end() && *it == dato) {
        int indice = distance(v.begin(), it);
        cout << "Ubicado en la posicion (indice): " << indice << endl;
    }
    return 0;
}

Resumen y Mejores Prácticas

  • Burbuja: Lento (O(N²)) y puramente didáctico. In-place y Estable.
  • Shell Sort: Un gran avance (O(N log N) a O(N^1.5)). In-place pero Inestable por sus saltos largos.
  • Quicksort: El más veloz en memoria RAM promedio (O(N log N)). In-place e Inestable.
  • Mergesort: Tiempo O(N log N) garantizado y Estable, a costa de memoria auxiliar O(N) (Out-of-place).
  • Bases de Datos e Industria: Cuando los datos no caben en RAM (Big Data), se usa External Merge Sort en disco. Para evitar ordenar en cada consulta, los motores SQL crean Índices B-Tree.
  • Búsqueda Lineal vs. Binaria: Buscamos linealmente en datos desordenados (O(N)). Si el arreglo está ordenado, la Búsqueda Binaria reduce millones de operaciones a solo un puñado de pasos (O(log N)).
  • En C++ Moderno: En la práctica se usa std::sort() (Introsort: híbrido de Quick, Heap e Inserción) o std::stable_sort() (Mergesort) desde <algorithm>.
