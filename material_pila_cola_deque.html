Pilas, colas y deque en C++

Tres estructuras que se distinguen por por dónde entran y salen los datos.

Desde cero

  • Pila (LIFO): concepto, arreglo y lista enlazada
  • Cola (FIFO): concepto, arreglo circular y lista enlazada
  • Deque: doble extremo con lista doblemente enlazada

Con la biblioteca moderna

  • std::stack, std::queue y std::deque
  • Adaptadores de contenedor
  • Relación entre las tres y cuándo usar cada una

Cada tema tiene ejemplo en C++ y ejercicios. Avanza con las flechas del teclado o con los botones de abajo.

Pila (1/3): qué es una pila

LIFO: el último en entrar es el primero en salir

Una pila (stack) es una colección donde solo se puede entrar y salir por un extremo, llamado tope. Es como una pila de platos: solo puedes tomar o poner el de arriba.

Operación Qué hace Costo
push(x) Apila x en el tope O(1)
pop() Quita el elemento del tope O(1)
top() Consulta el tope sin quitarlo O(1)
empty(), size() Está vacía / cuántos hay O(1)

No se puede leer ni borrar un elemento del medio: si lo necesitas, primero hay que sacar los de arriba.

Cómo se comporta

push(10)   push(20)   push(30)   pop()      pop()

                       | 30 | <-- tope
            | 20 |     | 20 |     | 20 | <--   | 10 | <--
 | 10 | <--  | 10 |     | 10 |     | 10 |     +----+
 +----+     +----+     +----+     +----+
 
 sale 30, luego 20: el orden de salida es inverso al de entrada

Dónde aparece

  • Pila de llamadas: cada llamada a función se apila; por eso la recursividad es una pila implícita.
  • Deshacer (Ctrl+Z) y el botón «atrás» del navegador.
  • Revisar paréntesis balanceados y evaluar expresiones.
  • Recorrido en profundidad (DFS) de grafos.

Pila (2/3): implementarla desde cero

Con arreglo (tamaño fijo) o con lista enlazada (crece sola)

  • Con arreglo: tope guarda cuántos elementos hay. Apilar es datos[tope++] = x; desapilar es datos[--tope]. Hay que controlar que no esté llena (desbordamiento) ni vacía (subdesbordamiento).
  • Con lista enlazada: el tope es la cabeza. push es insertarInicio y pop es eliminarInicio: ambas son O(1) sin recorrer nada. Nunca se llena (mientras haya memoria).

¿Por qué la cabeza y no el final? En una lista simple, borrar el último nodo obliga a recorrer toda la lista (O(n)). En la cabeza todo es O(1).

En la clase de lista enlazada, cab es un atributo, así que los métodos no necesitan Nodo*&.

Pila con arreglo

class PilaArr {
    int* datos;
    int  cap;
    int  tope = 0;               // cantidad de elementos
public:
    PilaArr(int c = 10) : datos(new int[c]), cap(c) {}
    ~PilaArr() { delete[] datos; }
    PilaArr(const PilaArr&) = delete;
    PilaArr& operator=(const PilaArr&) = delete;

    bool vacia() const { return tope == 0; }
    bool llena() const { return tope == cap; }

    bool push(int x) {
        if (llena()) return false;
        datos[tope++] = x;
        return true;
    }
    bool pop(int& x) {           // devuelve el dato por parametro
        if (vacia()) return false;
        x = datos[--tope];
        return true;
    }
    bool top(int& x) const {
        if (vacia()) return false;
        x = datos[tope - 1];
        return true;
    }
};

Pila con lista enlazada (el tope es la cabeza)

class PilaLista {
    struct Nodo { int dato; Nodo* sig; };
    Nodo* tope = nullptr;
public:
    ~PilaLista() { while (tope) { Nodo* t = tope; tope = tope->sig; delete t; } }
    PilaLista() {}
    PilaLista(const PilaLista&) = delete;
    PilaLista& operator=(const PilaLista&) = delete;

    bool vacia() const { return tope == nullptr; }
    void push(int x)   { tope = new Nodo{x, tope}; }
    bool pop(int& x) {
        if (vacia()) return false;
        Nodo* t = tope;
        x = t->dato;
        tope = tope->sig;      // avanzar ANTES de borrar
        delete t;
        return true;
    }
};

Pila (3/3): ejercicios

Usan #include <iostream>, #include <stack>, #include <string> y using namespace std;.

  1. Invierte una cadena usando una pila.
    Ver solución 
    string invertir(const string& s) {
    stack<char> p;
    for (char c : s) p.push(c);
    string r;
    while (!p.empty()) {
        r += p.top();
        p.pop();
    }
    return r;
}
// invertir("hola")  ->  "aloh"
  2. Escribe bool balanceado(const string& s) que revise si los paréntesis (), [] y {} están bien cerrados.
    Ver solución 
    bool balanceado(const string& s) {
    stack<char> p;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            p.push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (p.empty()) return false;       // cierra sin abrir
            char a = p.top(); p.pop();
            if ((c == ')' && a != '(') ||
                (c == ']' && a != '[') ||
                (c == '}' && a != '{')) return false;
        }
    }
    return p.empty();                          // no deben sobrar abiertos
}
// "{[()]}" -> true     "([)]" -> false     "((" -> false
  3. Evalúa una expresión posfija de dígitos, por ejemplo "34+2*" (equivale a (3+4)*2).
    Ver solución 
    int evaluar(const string& expr) {
    stack<int> s;
    for (char c : expr) {
        if (isdigit(c)) {
            s.push(c - '0');
        } else {
            int b = s.top(); s.pop();      // el segundo operando sale primero
            int a = s.top(); s.pop();
            switch (c) {
                case '+': s.push(a + b); break;
                case '-': s.push(a - b); break;
                case '*': s.push(a * b); break;
                case '/': s.push(a / b); break;
            }
        }
    }
    return s.top();
}
// evaluar("34+2*")  ->  14

Cola (1/3): qué es una cola

FIFO: el primero en entrar es el primero en salir

Una cola (queue) tiene dos extremos con roles distintos: los datos entran por el final y salen por el frente. Es la fila de un banco.

Operación Qué hace Costo
push(x) (encolar) Agrega x al final O(1)
pop() (desencolar) Quita el elemento del frente O(1)
front(), back() Consulta el frente / el final O(1)
empty(), size() Está vacía / cuántos hay O(1)

Igual que la pila, no se accede a los del medio.

Cómo se comporta

sale <-- [10] [20] [30] <-- entra
         frente        final

push(40):   sale <-- [10] [20] [30] [40] <-- entra
pop():      sale <-- [20] [30] [40] <-- entra     (salió el 10)

el orden de salida es el MISMO orden de entrada

Dónde aparece

  • Turnos de atención y colas de impresión.
  • Planificación de procesos del sistema operativo.
  • Búferes (teclado, red, streaming) que se leen en el orden en que llegaron.
  • Recorrido en anchura (BFS) de grafos y árboles por niveles.

Cola (2/3): implementarla desde cero

Arreglo circular o lista enlazada con puntero al final

  • Arreglo ingenuo: si desencolas moviendo todos los elementos una posición, cada pop cuesta O(n). Mala idea.
  • Arreglo circular: se guarda frente y cant. El final está en (frente + cant) % cap. Al llegar al límite del arreglo se «da la vuelta» con el módulo: todo es O(1).
  • Lista enlazada: hace falta un puntero fin además de frente. Encolar enlaza después de fin; desencolar quita la cabeza. Sin fin, encolar tendría que recorrer toda la lista.

Caso borde: al desencolar el último nodo, hay que poner fin = nullptr también; si no, fin queda apuntando a un nodo liberado. 

frente --> [10|•] --> [20|•] --> [30|null] <-- fin

Cola circular con arreglo

class ColaCirc {
    int* d;
    int  cap, frente = 0, cant = 0;
public:
    ColaCirc(int c = 10) : d(new int[c]), cap(c) {}
    ~ColaCirc() { delete[] d; }
    ColaCirc(const ColaCirc&) = delete;
    ColaCirc& operator=(const ColaCirc&) = delete;

    bool vacia() const { return cant == 0; }

    bool encolar(int x) {
        if (cant == cap) return false;        // llena
        d[(frente + cant) % cap] = x;         // posicion del final
        cant++;
        return true;
    }
    bool desencolar(int& x) {
        if (cant == 0) return false;
        x = d[frente];
        frente = (frente + 1) % cap;          // da la vuelta
        cant--;
        return true;
    }
};

Cola con lista enlazada

class ColaLista {
    struct Nodo { int dato; Nodo* sig; };
    Nodo* frente = nullptr;
    Nodo* fin    = nullptr;
public:
    ColaLista() {}
    ~ColaLista() { int x; while (desencolar(x)) {} }
    ColaLista(const ColaLista&) = delete;
    ColaLista& operator=(const ColaLista&) = delete;

    void encolar(int x) {
        Nodo* n = new Nodo{x, nullptr};
        if (fin == nullptr) frente = fin = n;   // estaba vacia
        else { fin->sig = n; fin = n; }
    }
    bool desencolar(int& x) {
        if (frente == nullptr) return false;
        Nodo* t = frente;
        x = t->dato;
        frente = frente->sig;
        if (frente == nullptr) fin = nullptr;   // quedo vacia
        delete t;
        return true;
    }
};

Cola (3/3): ejercicios

Usan #include <iostream>, #include <queue>, #include <stack> y using namespace std;.

  1. Simula una fila: encola los números 1 al 5 y luego desencólalos mostrando cada uno.
    Ver solución 
    int main() {
    queue<int> q;
    for (int i = 1; i <= 5; i++) q.push(i);
    while (!q.empty()) {
        cout << q.front() << " ";    // leer ANTES de hacer pop
        q.pop();
    }
    return 0;                          // 1 2 3 4 5
}
  2. Invierte una queue<int> usando una pila auxiliar.
    Ver solución 
    void invertir(queue<int>& q) {
    stack<int> s;
    while (!q.empty()) {          // la cola pasa a la pila (se invierte el orden)
        s.push(q.front());
        q.pop();
    }
    while (!s.empty()) {          // la pila vuelve a la cola
        q.push(s.top());
        s.pop();
    }
}
// 1 2 3 4  ->  4 3 2 1
  3. Construye una cola usando dos pilas.
    Ver solución 
    class ColaConPilas {
    stack<int> entrada, salida;
    void pasar() {                       // solo si salida esta vacia
        if (salida.empty())
            while (!entrada.empty()) {
                salida.push(entrada.top());
                entrada.pop();
            }
    }
public:
    void encolar(int x) { entrada.push(x); }
    bool desencolar(int& x) {
        pasar();
        if (salida.empty()) return false;
        x = salida.top();
        salida.pop();
        return true;
    }
};
// Pasar de una pila a otra invierte el orden DOS veces: queda FIFO.
// Cada elemento se mueve a lo sumo una vez, asi que el costo
// amortizado de cada operacion es O(1).

Deque (1/3): qué es un deque

Double-ended queue: se entra y se sale por los dos extremos

Un deque (se lee «dec») permite insertar y quitar tanto por el frente como por el final. Es una cola y una pila al mismo tiempo.

Operación Qué hace Costo
push_front(x), push_back(x) Inserta por el frente / por el final O(1)
pop_front(), pop_back() Quita por el frente / por el final O(1)
front(), back() Consulta cada extremo O(1)
d[i], at(i) Acceso por posición (std::deque) O(1)
insert / erase en el medio Mueve los elementos de un lado O(n)

Cómo se comporta

push_front(5)  <--  [5] [10] [20] [30]  -->  push_back(40)
pop_front()    -->  [5] [10] [20] [30]  <--  pop_back()

            [10] [20] [30]
             ^            ^
          frente         final   (ambos extremos son de entrada y salida)

Dónde aparece

  • Palíndromos: comparar el primero con el último y avanzar hacia el centro.
  • Máximo/mínimo en una ventana deslizante.
  • Historial acotado: agregar al final y descartar lo más viejo por el frente.
  • Reparto de trabajo entre hilos (se toma de un extremo o del otro).

Deque (2/3): implementarlo y usarlo

Lista doblemente enlazada desde cero y std::deque

  • Con lista simple no alcanza: pop_back necesita llegar al penúltimo nodo y eso es O(n). Por eso cada nodo guarda también ant (el anterior).
  • La clase mantiene dos punteros: ini y fin. Al quedar vacía, ambos deben volver a nullptr.
  • std::deque no es una lista enlazada: guarda los datos en bloques de memoria y un índice de bloques. Por eso tiene acceso d[i] en O(1) y a la vez inserta en los dos extremos en O(1).
  • A diferencia de std::vector, no garantiza memoria contigua.

Insertar en el medio de un std::deque invalida los iteradores. Insertar en los extremos invalida los iteradores, pero no las referencias a los elementos.

Deque con lista doblemente enlazada

class Deque {
    struct Nodo { int dato; Nodo* ant; Nodo* sig; };
    Nodo* ini = nullptr;
    Nodo* fin = nullptr;
public:
    Deque() {}
    ~Deque() { while (ini) popFront(); }
    Deque(const Deque&) = delete;
    Deque& operator=(const Deque&) = delete;

    bool vacio() const { return ini == nullptr; }

    void pushFront(int x) {
        Nodo* n = new Nodo{x, nullptr, ini};
        if (ini) ini->ant = n; else fin = n;
        ini = n;
    }
    void pushBack(int x) {
        Nodo* n = new Nodo{x, fin, nullptr};
        if (fin) fin->sig = n; else ini = n;
        fin = n;
    }
    bool popFront() {
        if (!ini) return false;
        Nodo* t = ini;
        ini = ini->sig;
        if (ini) ini->ant = nullptr; else fin = nullptr;
        delete t;
        return true;
    }
    bool popBack() {
        if (!fin) return false;
        Nodo* t = fin;
        fin = fin->ant;                  // posible gracias a 'ant'
        if (fin) fin->sig = nullptr; else ini = nullptr;
        delete t;
        return true;
    }
};

std::deque

#include <deque>
deque<int> d = {20, 30};
d.push_front(10);              // 10 20 30
d.push_back(40);               // 10 20 30 40
cout << d[2];                  // 30 (acceso directo)
d.pop_front();                 // 20 30 40
d.pop_back();                  // 20 30

Deque (3/3): ejercicios

Usan #include <iostream>, #include <deque>, #include <vector>, #include <cctype> y using namespace std;.

  1. Escribe bool esPalindromo(const string& s) con un deque, ignorando espacios y mayúsculas.
    Ver solución 
    bool esPalindromo(const string& s) {
    deque<char> d;
    for (char c : s)
        if (isalpha(c)) d.push_back(tolower(c));
    while (d.size() > 1) {
        if (d.front() != d.back()) return false;
        d.pop_front();
        d.pop_back();
    }
    return true;
}
// "Anita lava la tina" -> true
  2. Rota un deque<int> k posiciones a la izquierda.
    Ver solución 
    void rotarIzq(deque<int>& d, int k) {
    if (d.empty()) return;
    k %= (int)d.size();
    while (k--) {
        d.push_back(d.front());    // el primero pasa al final
        d.pop_front();
    }
}
// {1,2,3,4,5} con k=2  ->  {3,4,5,1,2}
  3. Dado un arreglo y un tamaño de ventana k, devuelve el máximo de cada ventana en O(n). Pista: guarda índices en el deque, con valores decrecientes.
    Ver solución 
    vector<int> maxVentana(const vector<int>& a, int k) {
    deque<int> d;                  // indices; a[d.front()] es el maximo
    vector<int> r;
    for (int i = 0; i < (int)a.size(); i++) {
        if (!d.empty() && d.front() <= i - k)
            d.pop_front();                       // salio de la ventana
        while (!d.empty() && a[d.back()] <= a[i])
            d.pop_back();                        // ya no pueden ser maximo
        d.push_back(i);
        if (i >= k - 1) r.push_back(a[d.front()]);
    }
    return r;
}
// {1,3,-1,-3,5,3,6,7}, k=3  ->  {3,3,5,5,6,7}
// Cada indice entra y sale una sola vez: O(n).

Biblioteca moderna (1/2): std::stack y std::queue

Adaptadores: usan otro contenedor por dentro y muestran solo lo permitido

std::stack y std::queue son adaptadores de contenedor: envuelven un contenedor (por defecto un std::deque) y exponen únicamente las operaciones de la pila o de la cola.

  • No tienen iteradores ni []: no se puede recorrer sin vaciarlas. Es a propósito.
  • pop() no devuelve el elemento (es void). Se lee primero con top() o front() y luego se hace pop().
  • Llamar a top(), front() o pop() con la estructura vacía es comportamiento indefinido: revisa empty() antes.
  • Se pueden elegir otro contenedor base: stack<int, vector<int>> o queue<int, list<int>>.
  • priority_queue también es un adaptador, pero no es FIFO: siempre sale el mayor (usa un heap).

std::stack

#include <stack>
stack<int> s;
s.push(10);
s.push(20);
s.push(30);
cout << s.top() << endl;      // 30
s.pop();                       // quita el 30
cout << s.size() << endl;     // 2

while (!s.empty()) {           // vaciarla mostrando
    cout << s.top() << " ";
    s.pop();
}                              // 20 10

std::queue

#include <queue>
queue<int> q;
q.push(10);
q.push(20);
q.push(30);
cout << q.front() << endl;     // 10
cout << q.back()  << endl;     // 30
q.pop();                       // quita el 10

while (!q.empty()) {
    cout << q.front() << " ";
    q.pop();
}                              // 20 30

Biblioteca moderna (2/2): pasarlas a funciones

Son objetos: se pasan por referencia, no por valor

Como en std::list, aquí no hay punteros que cambiar, así que no hace falta referencia a puntero.

  • stack<int>& si la función la modifica (apila o desapila).
  • const stack<int>& no sirve para recorrerla: sin iteradores, la única forma de ver los elementos es sacándolos. Para mostrarla sin destruir la original, se pasa por valor (una copia) a propósito.
  • Por valor copia toda la estructura: úsalo solo cuando esa copia sea lo que quieres.
La función... Parámetro
Agrega o quita elementos stack<T>&, queue<T>&
Solo consulta el tope / frente / tamaño const stack<T>&
Necesita vaciar una copia para mostrar stack<T> (por valor)

Firmas y uso

void apilar(stack<int>& s, int x) {
    s.push(x);                       // cambia la pila de main
}

bool vacia(const stack<int>& s) {
    return s.empty();                // solo consulta
}

// copia a proposito: la original queda intacta
void mostrar(stack<int> copia) {
    while (!copia.empty()) {
        cout << copia.top() << " ";
        copia.pop();
    }
    cout << endl;
}

int main() {
    stack<int> s;
    apilar(s, 1);
    apilar(s, 2);
    apilar(s, 3);
    mostrar(s);                      // 3 2 1
    cout << s.size();                // 3: sigue completa
    return 0;
}

Relación entre pila, cola y deque (1/2)

Todas son una secuencia con acceso restringido a los extremos

Pila Cola Deque
Política LIFO FIFO Ambas, a elección
Entra por Tope Final Frente y final
Sale por Tope Frente Frente y final
Acceso al medio No No Sí en std::deque ([i])
Iteradores en STL No No Sí
Contenedor STL stack (adaptador) queue (adaptador) deque (contenedor)
Orden de salida Inverso al de entrada Igual al de entrada Depende del extremo

Mismo deque, tres comportamientos

DEQUE: [a] [b] [c] [d]
       ^               ^
    frente           final

PILA   usa solo UN extremo:
       push_back  /  pop_back

COLA   entra por un lado, sale por el otro:
       push_back  /  pop_front

DEQUE  usa los cuatro:
       push_front push_back pop_front pop_back

Idea central: pila y cola son un deque con menos operaciones permitidas. Restringir la interfaz no es una limitación: garantiza el orden de salida y evita usos indebidos.

Relación entre pila, cola y deque (2/2): implementación y elección

Qué hay por debajo y cuándo usar cada una

Una pila y una cola construidas sobre un deque

#include <deque>

class PilaD {
    deque<int> d;
public:
    void push(int x) { d.push_back(x); }
    void pop()       { d.pop_back(); }
    int  top() const { return d.back(); }
    bool empty() const { return d.empty(); }
};

class ColaD {
    deque<int> d;
public:
    void push(int x) { d.push_back(x); }
    void pop()       { d.pop_front(); }
    int  front() const { return d.front(); }
    bool empty() const { return d.empty(); }
};

// Es lo mismo que hace la STL:
// stack<int>  == stack<int, deque<int>>
// queue<int>  == queue<int, deque<int>>

Costo según la estructura base

Base Pila Cola
Arreglo / vector O(1) amortizado Mal: pop_front es O(n)
Lista simple (solo cabeza) O(1) en la cabeza Mal: falta fin
Lista con fin O(1) O(1)
Deque O(1) O(1)

¿Cuál uso?

Si necesitas... Usa
Deshacer, revertir, procesar lo más reciente primero, simular recursividad, DFS Pila
Respetar el orden de llegada, turnos, búferes, BFS Cola
Sacar o meter por ambos extremos, ventana deslizante, historial acotado, acceso por índice Deque
Que salga siempre el mayor o el menor, no el más antiguo priority_queue

Recorrido de un árbol o grafo: solo cambia la estructura

// Con PILA   -> recorrido en profundidad (DFS)
// Con COLA   -> recorrido en anchura   (BFS)

stack<int> pend;     // cambiar por queue<int> y push/top
pend.push(inicio);   // por push/front convierte DFS en BFS
while (!pend.empty()) {
    int u = pend.top(); pend.pop();
    // visitar u y agregar sus vecinos
}

Resumen

Tema Idea clave
Pila LIFO. push, pop, top por un solo extremo, todas O(1). Con lista enlazada, el tope es la cabeza.
Cola FIFO. Entra por el final, sale por el frente. Con arreglo, circular con %; con lista, hace falta el puntero fin.
Deque Entra y sale por ambos extremos. Con lista, doblemente enlazada (ant y sig). std::deque añade acceso por índice.
std::stack, std::queue Adaptadores sobre deque. Sin iteradores. pop() no devuelve el elemento: leer primero con top() o front().
Relación Pila y cola son un deque con operaciones restringidas. Lo que cambia es el orden de salida.
Elección Lo más reciente primero: pila. Orden de llegada: cola. Ambos extremos o índice: deque.

Errores comunes: llamar top(), front() o pop() con la estructura vacía, esperar que pop() devuelva el dato, olvidar fin = nullptr al vaciar una cola enlazada, implementar una cola con pop_front sobre un arreglo (O(n)) y confundir el orden de salida de la pila con el de la cola.
