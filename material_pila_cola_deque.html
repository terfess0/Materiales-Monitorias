Pila (1/6): qué es una pila

LIFO: el último en entrar es el primero en salir

Una pila (stack) es una colección donde solo se puede entrar y salir por un extremo, llamado tope. Es como una pila de platos: solo puedes poner o quitar el plato de arriba.

Operación Qué hace Costo
push(x) Apila x encima del tope O(1)
pop() Quita el elemento del tope O(1)
top() Consulta el tope sin quitarlo O(1)
empty(), size() Está vacía / cuántos hay O(1)

No se puede leer ni borrar un elemento del medio directamente: para llegar a él primero hay que sacar los que están arriba.

Cómo se comporta

push(10)   push(20)   push(30)   pop()      pop()

                       | 30 | <-- tope
            | 20 |     | 20 |     | 20 | <--  | 10 | <--
 | 10 | <-- | 10 |     | 10 |     | 10 |      +----+
 +----+     +----+     +----+     +----+

sale 30, luego 20: el orden de salida es INVERSO al de entrada

Dónde aparece

  • Invertir datos: todo lo que entra a una pila sale al revés.
  • Deshacer (Ctrl+Z) y el botón «atrás» del navegador.
  • Revisar paréntesis balanceados y evaluar expresiones.
  • Verificar si una palabra o secuencia es capicúa / palíndromo.

Pila (2/6): en crudo con struct Nodo

push, pop, top y recorrer desde cero

Con nodos enlazados, el tope es la cabeza de la lista:

  • Pila vacía: Nodo* tope = nullptr;
  • push: crea un nodo cuyo sig apunta al tope actual y mueve tope al nuevo nodo.
  • pop: guarda el nodo del tope en un temporal t, saca su dato en x, avanza tope = tope->sig y hace delete t.
  • ¿Por qué Nodo*& tope? Porque push y pop cambian a qué nodo apunta tope.
  • recorrer: usa un puntero auxiliar p = tope que avanza con p = p->sig sin mover tope.
tope --> [30|•] --> [20|•] --> [10|null]

Programa completo en crudo

#include <iostream>
using namespace std;

struct Nodo {
    int dato;
    Nodo* sig;
};

void push(Nodo*& tope, int x) {
    tope = new Nodo{x, tope};
}

bool pop(Nodo*& tope, int& x) {
    if (tope == nullptr) return false;
    Nodo* t = tope;
    x = t->dato;
    tope = tope->sig;           // avanzar ANTES de borrar
    delete t;
    return true;
}

void recorrer(const Nodo* tope) {
    for (const Nodo* p = tope; p != nullptr; p = p->sig)
        cout << p->dato << " -> ";
    cout << "null\n";
}

int main() {
    Nodo* pila = nullptr;
    push(pila, 10);
    push(pila, 20);
    push(pila, 30);
    recorrer(pila);             // 30 -> 20 -> 10 -> null

    int x;
    if (pop(pila, x)) cout << "Salio: " << x << endl; // 30
    recorrer(pila);             // 20 -> 10 -> null
    return 0;
}

Pila (3/6): buscar, revertir y capicúa (en crudo)

Funciones útiles sobre struct Nodo

  • buscar: recorre con p desde tope. Si halla x devuelve true. No mueve tope.
  • revertir: sacamos cada elemento con pop(tope, x) y lo apilamos con push(nueva, x) en otra pila. Al pasar de una pila a otra el orden se invierte; al final hacemos tope = nueva.
  • esCapicua: construimos una pila auxiliar rev apilando los datos de la original (queda en orden inverso) y comparamos nodo por nodo.
  • liberar: vacía todos los nodos con pop para no dejar fugas de memoria.
Original:  tope --> 1 -> 2 -> 3 -> 2 -> 1
Invertida: rev  --> 1 -> 2 -> 3 -> 2 -> 1
Coinciden todos ==> esCapicua devuelve true

Funciones sobre struct Nodo

bool buscar(const Nodo* tope, int x) {
    for (const Nodo* p = tope; p != nullptr; p = p->sig)
        if (p->dato == x) return true;
    return false;
}

void liberar(Nodo*& tope) {
    int x;
    while (pop(tope, x)) {}
}

void revertir(Nodo*& tope) {
    Nodo* nueva = nullptr;
    int x;
    while (pop(tope, x))
        push(nueva, x);         // al pasar a otra pila queda al revés
    tope = nueva;
}

bool esCapicua(const Nodo* tope) {
    Nodo* rev = nullptr;
    for (const Nodo* p = tope; p != nullptr; p = p->sig)
        push(rev, p->dato);     // rev queda invertida

    bool ok = true;
    for (const Nodo *a = tope, *b = rev; a != nullptr; a = a->sig, b = b->sig)
        if (a->dato != b->dato) { ok = false; break; }

    liberar(rev);
    return ok;
}

Pila (4/6): cómo se usa con librería (<stack>)

Declaración, operaciones básicas y paso a funciones

Con #include <stack> la pila ya viene lista y libera su memoria sola:

  • Declarar: stack<int> p; (o stack<char>, stack<string>, etc.).
  • Apilar: p.push(10);
  • Consultar el tope: p.top() devuelve el elemento de arriba sin quitarlo.
  • Desapilar: p.pop(); quita el tope, pero es void (no devuelve nada). Siempre se lee primero con p.top() y luego se hace p.pop().
  • Tamaño y vacía: p.size() y p.empty().
  • Pasar a funciones: usa stack<int>& (por referencia) si quieres modificar la original, o stack<int> (por valor) si quieres vaciar una copia sin dañar la de main.

Programa completo de uso básico con <stack>

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> p;

    // 1. Apilar elementos (push)
    p.push(10);
    p.push(20);
    p.push(30);

    // 2. Consultar tope y tamaño
    cout << "Tope actual: " << p.top() << endl;   // 30
    cout << "Cantidad: "    << p.size() << endl;  // 3

    // 3. Quitar un elemento (pop)
    p.pop();                                      // quita el 30
    cout << "Nuevo tope: "  << p.top() << endl;   // 20

    // 4. Vaciar la pila mostrando cada dato
    cout << "Restantes: ";
    while (!p.empty()) {
        cout << p.top() << " ";                   // 20 10
        p.pop();
    }
    cout << endl;
    return 0;
}

Pila (5/6): recorrer, buscar, revertir y capicúa con <stack>

Cómo implementar las mismas funciones usando la librería

Como std::stack no tiene iteradores ni for, todo se hace combinando top(), pop() y pilas auxiliares:

  • recorrer y buscar: reciben stack<int> copia por valor. Así sacamos los elementos de la copia y la pila de main queda intacta.
  • revertir: recibe stack<int>& p por referencia. Pasar de p -> a invierte, de a -> b vuelve al derecho, y de b -> p deja p invertida.
  • esCapicua: volcamos una copia en otra pila rev (que queda al revés) y comparamos p.top() == rev.top() paso a paso.

Funciones completas con std::stack

void recorrer(stack<int> copia) {         // por valor: copia
    while (!copia.empty()) {
        cout << copia.top() << " ";
        copia.pop();
    }
    cout << endl;
}

bool buscar(stack<int> copia, int x) {
    while (!copia.empty()) {
        if (copia.top() == x) return true;
        copia.pop();
    }
    return false;
}

void revertir(stack<int>& p) {            // por referencia: cambia p
    stack<int> a, b;
    while (!p.empty()) { a.push(p.top()); p.pop(); }
    while (!a.empty()) { b.push(a.top()); a.pop(); }
    while (!b.empty()) { p.push(b.top()); b.pop(); }
}

bool esCapicua(stack<int> p) {
    stack<int> copia = p, rev;
    while (!copia.empty()) {
        rev.push(copia.top());
        copia.pop();
    }
    while (!p.empty()) {
        if (p.top() != rev.top()) return false;
        p.pop();
        rev.pop();
    }
    return true;
}

Cola (1/6): qué es una cola

FIFO: el primero en entrar es el primero en salir

Una cola (queue) tiene dos extremos con roles distintos: los datos entran por el final y salen por el frente. Es la fila de un banco.

Operación Qué hace Costo
push(x) (encolar) Agrega x al final O(1)
pop() (desencolar) Quita el elemento del frente O(1)
front(), back() Consulta el frente / el final O(1)
empty(), size() Está vacía / cuántos hay O(1)

Igual que la pila, no se accede directamente a los elementos del medio.

Cómo se comporta

sale <-- [10] [20] [30] <-- entra
         frente        fin

push(40):   sale <-- [10] [20] [30] [40] <-- entra
pop():      sale <-- [20] [30] [40] <-- entra     (salió el 10)

el orden de salida es el MISMO orden de entrada

Dónde aparece

  • Turnos de atención y colas de impresión.
  • Planificación de procesos del sistema operativo.
  • Búferes que se procesan en el orden de llegada.
  • Recorrido en anchura (BFS) de grafos y árboles por niveles.

Cola (2/6): en crudo con struct Nodo

Dos punteros: frente (cabeza) y fin (último nodo)

Para que tanto encolar como desencolar sean O(1), mantenemos dos punteros:

  • Cola vacía: frente = nullptr; fin = nullptr;
  • push (encolar): crea un nodo al final. Si estaba vacía, tanto frente como fin apuntan al nuevo. Si no, se enlaza tras fin (fin->sig = nuevo) y se mueve fin = nuevo.
  • pop (desencolar): saca el nodo de frente. Caso borde importante: si al avanzar frente queda en nullptr, también hay que poner fin = nullptr.
frente --> [10|•] --> [20|•] --> [30|null] <-- fin

Programa completo en crudo

#include <iostream>
using namespace std;

struct Nodo {
    int dato;
    Nodo* sig;
};

void push(Nodo*& frente, Nodo*& fin, int x) {
    Nodo* nuevo = new Nodo{x, nullptr};
    if (frente == nullptr) frente = fin = nuevo;
    else { fin->sig = nuevo; fin = nuevo; }
}

bool pop(Nodo*& frente, Nodo*& fin, int& x) {
    if (frente == nullptr) return false;
    Nodo* t = frente;
    x = t->dato;
    frente = frente->sig;
    if (frente == nullptr) fin = nullptr; // quedó vacía
    delete t;
    return true;
}

void recorrer(const Nodo* frente) {
    for (const Nodo* p = frente; p != nullptr; p = p->sig)
        cout << p->dato << " -> ";
    cout << "null\n";
}

int main() {
    Nodo *frente = nullptr, *fin = nullptr;
    push(frente, fin, 10);
    push(frente, fin, 20);
    push(frente, fin, 30);
    recorrer(frente);             // 10 -> 20 -> 30 -> null

    int x;
    if (pop(frente, fin, x)) cout << "Salio: " << x << endl; // 10
    recorrer(frente);             // 20 -> 30 -> null
    return 0;
}

Cola (3/6): buscar, revertir y capicúa (en crudo)

Funciones útiles sobre frente y fin

  • buscar: recorre desde frente hasta nullptr con un puntero auxiliar p.
  • revertir: invierte las flechas sig de todos los nodos y actualiza frente y fin (el antiguo frente pasa a ser el nuevo fin).
  • esCapicua: mientras recorremos la cola, apilamos los datos en una pila cruda tope. Como la cola va al derecho y la pila al revés, basta compararlas elemento a elemento.
Cola (frente a fin): 1 -> 2 -> 3 -> 2 -> 1
Pila (tope a fondo): 1 -> 2 -> 3 -> 2 -> 1
Si coinciden todos ==> esCapicua devuelve true

Funciones sobre struct Nodo

bool buscar(const Nodo* frente, int x) {
    for (const Nodo* p = frente; p != nullptr; p = p->sig)
        if (p->dato == x) return true;
    return false;
}

void revertir(Nodo*& frente, Nodo*& fin) {
    Nodo* ant = nullptr;
    Nodo* act = frente;
    fin = frente;                   // el viejo frente queda de fin
    while (act != nullptr) {
        Nodo* sig = act->sig;
        act->sig = ant;
        ant = act;
        act = sig;
    }
    frente = ant;                   // el último pasa a ser el frente
}

bool esCapicua(const Nodo* frente) {
    Nodo* pila = nullptr;
    for (const Nodo* p = frente; p != nullptr; p = p->sig)
        pila = new Nodo{p->dato, pila}; // apilar cada dato

    bool ok = true;
    for (const Nodo* p = frente; p != nullptr; p = p->sig) {
        if (p->dato != pila->dato) ok = false;
        Nodo* t = pila;
        pila = pila->sig;
        delete t;
    }
    return ok;
}

Cola (4/6): cómo se usa con librería (<queue>)

Declaración, operaciones básicas y recorrido

Con #include <queue> no necesitas administrar los punteros frente ni fin:

  • Declarar: queue<int> q;
  • Encolar al final: q.push(10);
  • Consultar extremos: q.front() devuelve el primero de la fila y q.back() devuelve el último que llegó.
  • Desencolar del frente: q.pop(); quita el primero (es void: primero lee q.front() y luego haz q.pop()).
  • Tamaño y vacía: q.size() y q.empty().
  • Pasar a funciones: queue<int>& si la función modifica la cola original; queue<int> (por valor) si solo quieres vaciar una copia para mostrarla.

Programa completo de uso básico con <queue>

#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;

    // 1. Encolar elementos al final (push)
    q.push(10);
    q.push(20);
    q.push(30);

    // 2. Consultar frente, final y tamaño
    cout << "Frente: "   << q.front() << endl;    // 10
    cout << "Final: "    << q.back()  << endl;    // 30
    cout << "Cantidad: " << q.size()  << endl;    // 3

    // 3. Desencolar el primero (pop)
    q.pop();                                      // sale el 10
    cout << "Nuevo frente: " << q.front() << endl;// 20

    // 4. Vaciar la cola en orden de llegada
    cout << "Restantes: ";
    while (!q.empty()) {
        cout << q.front() << " ";                 // 20 30
        q.pop();
    }
    cout << endl;
    return 0;
}

Cola (5/6): recorrer, buscar, revertir y capicúa con <queue>

Implementación con la librería estándar

  • recorrer y buscar: reciben queue<int> copia por valor y sacan con copia.front() y copia.pop() sin tocar la cola original.
  • Truco sin copia: también puedes recorrer o modificar una cola dando exactamente n = q.size() pasos: sacas el front() y lo vuelves a meter al final con push().
  • revertir: se apoya en una stack<int>. Al pasar la cola a la pila y devolverla a la cola, queda invertida.
  • esCapicua: metemos los elementos en una pila auxiliar y comparamos q.front() == s.top().

Funciones completas con std::queue

#include <queue>
#include <stack>

void recorrer(queue<int> copia) {         // por valor: copia
    while (!copia.empty()) {
        cout << copia.front() << " ";
        copia.pop();
    }
    cout << endl;
}

bool buscar(queue<int> copia, int x) {
    while (!copia.empty()) {
        if (copia.front() == x) return true;
        copia.pop();
    }
    return false;
}

void revertir(queue<int>& q) {            // usa stack como auxiliar
    stack<int> s;
    while (!q.empty()) { s.push(q.front()); q.pop(); }
    while (!s.empty()) { q.push(s.top());   s.pop(); }
}

bool esCapicua(queue<int> q) {
    stack<int> s;
    queue<int> copia = q;
    while (!copia.empty()) {
        s.push(copia.front());
        copia.pop();
    }
    while (!q.empty()) {
        if (q.front() != s.top()) return false;
        q.pop();
        s.pop();
    }
    return true;
}

Deque (1/6): qué es un deque

Double-ended queue: se entra y se sale por los dos extremos

Un deque (se lee «dec») permite insertar y quitar tanto por el frente como por el final. Es una cola y una pila al mismo tiempo.

Operación Qué hace Costo
push_front(x), push_back(x) Inserta por el frente / por el final O(1)
pop_front(), pop_back() Quita por el frente / por el final O(1)
front(), back() Consulta cada extremo O(1)
d[i], at(i) Acceso por posición (std::deque) O(1)

Cómo se comporta

push_front(5)  <--  [5] [10] [20] [30]  -->  push_back(40)
pop_front()    -->  [5] [10] [20] [30]  <--  pop_back()

            [10] [20] [30]
             ^            ^
          frente         final   (ambos extremos son de entrada y salida)

Dónde aparece

  • Capicúas y palíndromos: comparar el primero con el último y avanzar hacia el centro sin usar memoria extra.
  • Rotar elementos hacia la izquierda o hacia la derecha.
  • Historial acotado: agregar al final y descartar lo más viejo por el frente.
  • Filas con prioridad VIP (entran por el frente) y turnos normales (entran por el final).

Deque (2/6): en crudo con struct NodoD

Lista doblemente enlazada con punteros ini y fin

  • ¿Por qué doble enlace? En una lista simple, quitar el último (popBack) obliga a recorrer hasta el penúltimo en O(n). Con ant (anterior) y sig (siguiente), ambos extremos operan en O(1).
  • Deque vacío: ini = nullptr; fin = nullptr;
  • Al insertar el primer nodo o al borrar el último, hay que actualizar tanto ini como fin.
null <-- [10] <==> [20] <==> [30] --> null
          ^                   ^
         ini                 fin

struct NodoD y operaciones por ambos extremos

#include <iostream>
using namespace std;

struct NodoD {
    int dato;
    NodoD* ant;
    NodoD* sig;
};

void pushFront(NodoD*& ini, NodoD*& fin, int x) {
    NodoD* n = new NodoD{x, nullptr, ini};
    if (ini != nullptr) ini->ant = n;
    else                fin = n;
    ini = n;
}

void pushBack(NodoD*& ini, NodoD*& fin, int x) {
    NodoD* n = new NodoD{x, fin, nullptr};
    if (fin != nullptr) fin->sig = n;
    else                ini = n;
    fin = n;
}

bool popFront(NodoD*& ini, NodoD*& fin, int& x) {
    if (ini == nullptr) return false;
    NodoD* t = ini;
    x = t->dato;
    ini = ini->sig;
    if (ini != nullptr) ini->ant = nullptr;
    else                fin = nullptr;
    delete t;
    return true;
}

bool popBack(NodoD*& ini, NodoD*& fin, int& x) {
    if (fin == nullptr) return false;
    NodoD* t = fin;
    x = t->dato;
    fin = fin->ant;
    if (fin != nullptr) fin->sig = nullptr;
    else                ini = nullptr;
    delete t;
    return true;
}

Deque (3/6): recorrer, buscar, revertir y capicúa (en crudo)

Funciones útiles sobre struct NodoD

  • recorrer: avanza desde ini con p = p->sig (y si quisieras recorrer al revés, empiezas en fin con p = p->ant).
  • buscar: busca el valor desde ini hasta nullptr.
  • revertir: acerca dos punteros (ini avanza y fin retrocede) intercambiando sus datos hasta que se encuentran en el centro.
  • esCapicua: compara ini->dato == fin->dato avanzando ini = ini->sig y retrocediendo fin = fin->ant al mismo tiempo.
ini --> [10] <=> [20] <=> [30] <=> [20] <=> [10] <-- fin
         10 == 10  y  20 == 20  ==>  esCapicua = true

Funciones sobre struct NodoD

void recorrer(const NodoD* ini) {
    for (const NodoD* p = ini; p != nullptr; p = p->sig)
        cout << p->dato << " <-> ";
    cout << "null\n";
}

bool buscar(const NodoD* ini, int x) {
    for (const NodoD* p = ini; p != nullptr; p = p->sig)
        if (p->dato == x) return true;
    return false;
}

void revertir(NodoD* ini, NodoD* fin) {
    while (ini != nullptr && ini != fin && ini->ant != fin) {
        int tmp = ini->dato;
        ini->dato = fin->dato;
        fin->dato = tmp;
        ini = ini->sig;
        fin = fin->ant;
    }
}

bool esCapicua(const NodoD* ini, const NodoD* fin) {
    while (ini != nullptr && ini != fin && ini->ant != fin) {
        if (ini->dato != fin->dato) return false;
        ini = ini->sig;
        fin = fin->ant;
    }
    return true;
}

Deque (4/6): cómo se usa con librería (<deque>)

Declaración, operaciones en ambos extremos y acceso por índice

A diferencia de stack y queue, std::deque (de #include <deque>) es un contenedor completo:

  • Insertar: d.push_front(x) (al inicio) y d.push_back(x) (al final).
  • Eliminar: d.pop_front() (quita el primero) y d.pop_back() (quita el último). Ambos son void.
  • Consultar extremos: d.front() y d.back().
  • Recorrer y acceder por índice: sí tiene d[i] y se puede recorrer directamente con for (int x : d) sin vaciarlo.
  • Pasar a funciones: const deque<int>& para solo leer (sin copiar), o deque<int>& si la función lo modifica.

Programa completo de uso básico con <deque>

#include <iostream>
#include <deque>
using namespace std;

int main() {
    deque<int> d = {20, 30};

    // 1. Insertar por ambos extremos
    d.push_front(10);                             // 10 20 30
    d.push_back(40);                              // 10 20 30 40

    // 2. Consultar extremos y por índice
    cout << "Frente: " << d.front() << endl;      // 10
    cout << "Final: "  << d.back()  << endl;      // 40
    cout << "En pos 2: " << d[2]    << endl;      // 30

    // 3. Quitar de ambos extremos
    d.pop_front();                                // quita el 10
    d.pop_back();                                 // quita el 40

    // 4. Recorrer con for normal (no se vacía)
    for (int x : d) cout << x << " ";             // 20 30
    cout << endl;
    return 0;
}

Deque (5/6): recorrer, buscar, revertir y capicúa con <deque>

Implementación con la librería estándar

  • recorrer y buscar: como std::deque sí permite for, reciben const deque<int>& d sin necesidad de copiar ni vaciar la estructura.
  • revertir: podemos intercambiar los extremos con índices o pasar los elementos a un deque auxiliar usando push_front.
  • esCapicua: recibe una copia deque<int> d y mientras d.size() > 1 compara d.front() == d.back(), quitando ambos extremos con pop_front() y pop_back().

Funciones completas con std::deque

#include <deque>

void recorrer(const deque<int>& d) {
    for (int x : d) cout << x << " ";
    cout << endl;
}

bool buscar(const deque<int>& d, int x) {
    for (int v : d)
        if (v == x) return true;
    return false;
}

void revertir(deque<int>& d) {
    deque<int> aux;
    while (!d.empty()) {
        aux.push_front(d.front());
        d.pop_front();
    }
    d = aux;
}

bool esCapicua(deque<int> d) {
    while (d.size() > 1) {
        if (d.front() != d.back()) return false;
        d.pop_front();
        d.pop_back();
    }
    return true;
}

Relación entre pila, cola y deque

Todas son secuencias con acceso controlado en los extremos

Pila Cola Deque
Política LIFO FIFO Ambas, a elección
En crudo Nodo* tope Nodo *frente, *fin NodoD *ini, *fin
Entra por Tope Final Frente y final
Sale por Tope Frente Frente y final
Librería STL std::stack std::queue std::deque
Recorrido en STL Vaciando copia Vaciando copia Directo con for / [i]
Orden de salida Inverso al de entrada Igual al de entrada Depende del extremo

Mismo deque, tres comportamientos

DEQUE: [a] [b] [c] [d]
        ^           ^
     frente       final

PILA   usa solo UN extremo:
       push_back  /  pop_back

COLA   entra por un lado, sale por el otro:
       push_back  /  pop_front

DEQUE  usa los cuatro:
       push_front push_back pop_front pop_back

Por debajo en la STL: tanto std::stack como std::queue son adaptadores construidos por defecto sobre un std::deque.

Resumen

Tema Idea clave
Pila en crudo struct Nodo { int dato; Nodo* sig; } con un solo puntero tope. push y pop reciben Nodo*& tope.
Cola en crudo Mismo struct Nodo pero con dos punteros: frente y fin. Al vaciarla, recordar poner fin = nullptr.
Deque en crudo struct NodoD { int dato; NodoD *ant, *sig; } con ini y fin para operar en O(1) por ambos extremos.
Con librería STL stack, queue y deque. En las tres, pop() no devuelve el dato: primero se consulta con top(), front() o back().
Recorrer y Buscar En crudo se usa un puntero auxiliar p sin mover el original. En std::stack y std::queue se pasa por valor (copia).
Revertir y Capicúa La pila invierte el orden; la cola lo conserva; el deque compara front() y back() hacia el centro sin estructuras extra.

Errores comunes: olvidar el & en Nodo*& al insertar o sacar, olvidar fin = nullptr al desencolar el último nodo, hacer delete t antes de avanzar el puntero, y llamar top(), front() o pop() con la estructura vacía.
