Arrays Unidimensionales (1D)

Imagina una calle con casas numeradas o un pastillero semanal. Todos los espacios están en línea recta, uno al lado del otro.

Concepto

Un array 1D es una lista finita y ordenada de elementos del mismo tipo (por ejemplo, todos enteros o todos textos).

  • Tamaño fijo: En los arrays estáticos de C++, debes definir su tamaño al crearlo.
  • Índices: En C++, siempre empezamos a contar desde 0.

for(int i = 0; i < 5; i++) {

    {1, 5, 9, 3}, // Fila 0

Arrays Multidimensionales (3D o más)

Imagina un Cubo de Rubik, o un edificio: Piso (z), Fila de apartamentos (y), Número de cuarto (x).

De la Teoría a la Práctica

A nivel de hardware, la memoria del computador sigue siendo una línea recta (1D). C++ hace la matemática internamente para traducir cubo[piso][fila][col] a una posición lineal.

Puedes crear arrays de 3, 4 o más dimensiones, pero ten cuidado: la memoria requerida crece exponencialmente.

  • int datos[10] = 10 enteros
  • int datos[10][10] = 100 enteros
  • int datos[10][10][10] = 1,000 enteros

En C++

// 3 Dimensiones (ej: 2 páginas, 3 filas, 4 columnas)
int cubo[2][3][4];

// Acceso específico
cubo[1][2][3] = 99;

// Recorrido requiere 3 for anidados
for(int p = 0; p < 2; p++) {
    for(int f = 0; f < 3; f++) {
        for(int c = 0; c < 4; c++) {
            cubo[p][f][c] = 0; // Limpiar cubo
        }
    }
}

Vectores (Arrays Dinámicos)

El problema del Array tradicional en C++ es que su tamaño no puede cambiar. Para solucionarlo, existe std::vector.

Beneficios del std::vector

  • Puede crecer o encogerse en tiempo de ejecución.Dinámico
  • Lleva la cuenta automática de su tamaño (v.size()).Inteligente
  • Se pasa fácilmente a funciones.Práctico

Requiere incluir la librería: #include <vector>

En C++

#include <iostream>
#include <vector>
using namespace std;

vector<int> v = {10, 20}; // Inicia con 2 datos

// Agregar un dato al final (crece automáticamente)
v.push_back(30); 

// Eliminar el último dato
v.pop_back();

// Saber cuántos elementos tiene
int cant = v.size();

Listas vs. Arrays

¿Cuándo usar un Array/Vector y cuándo usar una Lista (std::list)?

Array / std::vector

Memoria: Contigua (bloque único).

Ventaja: Acceso instantáneo. Si quieres la posición 1000, vas directo con v[1000].

Desventaja: Insertar o borrar en el medio es lento (hay que empujar todos los demás elementos).

Lista Doblemente Enlazada (std::list)

Memoria: Nodos esparcidos unidos por punteros.

Ventaja: Insertar o borrar datos en el medio es rapidísimo.

Desventaja: Acceso secuencial. No puedes hacer lista[1000], debes recorrerla desde el principio.

11. Insertar en el medio con insert() Avanzado

Planteamiento: Crea un vector {10, 30, 40}. Usa insert() y el iterador begin() para insertar el número 20 exactamente en la segunda posición (índice 1).

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {10, 30, 40};
    
    // v.begin() es la posicion 0. v.begin() + 1 es el indice 1.

}

24. Buscar un elemento con find() Avanzado

25. Máximo y Mínimo automático Avanzado

Planteamiento: No necesitas hacer un bucle para buscar el mayor o el menor. Usa max_element() y min_element() de la librería algorithm en un vector. (Nota: devuelven un iterador, añade un * al principio para obtener el valor).

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {45, 2, 88, 12};
    
    // Se usa el asterisco (*) para leer el valor del iterador
    int maximo = *max_element(v.begin(), v.end());
    int minimo = *min_element(v.begin(), v.end());
    
    cout << "Max: " << maximo << " | Min: " << minimo;
    return 0;
}

30. Reto Final: Vector de Notas Dinámico Avanzado

Planteamiento: Pide al usuario meter calificaciones hasta ingresar -1. Guarda en un vector. Ordena el vector de menor a mayor. Elimina la nota más baja usando erase(). Imprime el promedio de las notas restantes.

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<float> notas;
    float nota;
    
    cout << "Ingresa notas (-1 para fin):\n";
    while(cin >> nota && nota != -1) {
        notas.push_back(nota);
    }
    
    if(!notas.empty()) {
        sort(notas.begin(), notas.end());
        notas.erase(notas.begin()); // Elimina la mas baja
        
        float suma = 0;
        for(float n : notas) suma += n;
        
        cout << "Promedio sin la peor nota: " << suma / notas.size();
    }
    return 0;
}

Resumen

  • Arrays 1D: Conjunto ordenado y finito de variables en una sola línea (estáticos).
  • Arrays 2D (Matrices): "Array de arrays", ideal para cuadriculas, tableros o sistemas de coordenadas. Requiere dos índices.
  • Multidimensionales (3D+): Útiles para modelar el espacio, pero el consumo de memoria crece muy rápido.
  • std::vector: La versión moderna y dinámica del array en C++. Crece según lo necesites y conoce su propio tamaño.
  • <algorithm>: Utiliza siempre esta librería para no reinventar la rueda (sort, reverse, count).
