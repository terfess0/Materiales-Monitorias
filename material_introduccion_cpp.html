Material - Introducción a C++

Lo esencial del lenguaje: desde su historia y estructura básica, hasta variables, estructuras de control y funciones. La preparación y nivelación ideal antes de ver Estructuras de Datos.

El punto de partida

#include <iostream>
using namespace std;

int main() {
    cout << "Hola, estructuras de datos!";
    return 0;
}

Avanza con las flechas del teclado o los botones inferiores.

¿Qué es C++ y de dónde viene?

Creado por Bjarne Stroustrup en 1979 como una extensión del lenguaje C para incluir Programación Orientada a Objetos.

Lenguaje Compilado
El código que escribes (.cpp) no lo entiende directamente la computadora. Necesita un Compilador (como GCC o MinGW) que traduzca tu código a lenguaje máquina (.exe) de una sola vez antes de ejecutarse. Esto lo hace rapidísimo.
Tipado Estático
A diferencia de lenguajes dinámicos (como Python o JavaScript), en C++ debes declarar obligatoriamente el tipo de dato de una variable antes de usarla, y no puedes cambiar ese tipo después.
¿Para qué se usa?
Desarrollo de videojuegos (Unreal Engine), sistemas operativos, navegadores web, motores de bases de datos y, por supuesto, para aprender y construir Estructuras de Datos, gracias a su alto control sobre la memoria.

Estructura de un Programa Simple

Todo programa en C++ tiene piezas fundamentales que siempre deben estar presentes.

// 1. Librerias
#include <iostream>

// 2. Espacio de nombres
using namespace std;

// 3. Funcion principal
int main() {
    
    // 4. Instrucciones
    cout << "Iniciando...";
    
    // 5. Retorno
    return 0;
}
  • 1. #include <iostream>
    Le dice al compilador que incluya herramientas de entrada y salida (input/output stream) para leer del teclado e imprimir en pantalla.
  • 2. using namespace std;
    Nos ahorra escribir std:: antes de comandos comunes como cout o cin.
  • 3. int main() { ... }
    Es el punto de arranque de TODO programa en C++. El sistema operativo busca esta función para empezar a ejecutar.
  • 5. return 0;
    Avisa al sistema operativo que el programa terminó con éxito (cero errores).

Variables y Tipos de Datos

Al ser de tipado estático, C++ necesita saber qué vas a guardar en la caja (variable) antes de crearla.

Tipos Básicos

  • int: Números enteros (10, -5, 0).
  • float / double: Números con decimales (3.14, -0.5).
  • char: Un solo carácter ('A', 'z', '8'). Va entre comillas simples.
  • bool: Lógico, verdadero (true / 1) o falso (false / 0).
  • string: Texto ("Hola Mundo"). Requiere #include <string> y va en comillas dobles.

Declaración en Código

// Sintaxis: TipoDeDato NombreVariable = Valor;

int numero1 = 25;
float decimal1 = 9.99;
char letraEntrada = 'S';
bool estadoActivo = true;
string nombreUsuario = "Juan";

// Declaracion sin inicializar
int numero2; 
numero2 = 50; // Asignacion posterior

Entrada y Salida (I/O)

Para que el programa sea interactivo, necesitamos comunicarnos con el usuario. C++ usa "flujos" (streams).

Salida de datos: cout

Significa Character Output. Usa el operador de inserción << para enviar datos a la pantalla.

int numero1 = 10;
// Imprime texto y variables combinadas
cout << "El valor es: " << numero1 << endl;
// 'endl' genera un salto de linea (Enter)

Entrada de datos: cin

Significa Character Input. Usa el operador de extracción >> para leer datos del teclado y guardarlos en variables.

int entrada1;
cout << "Escribe un numero: ";
cin >> entrada1; // El programa se pausa y espera
cout << "Escribiste: " << entrada1;

Control: Condicionales (if / else)

Permiten que el programa tome decisiones basándose en operaciones lógicas (==, !=, <,>, <=,>=, &&, ||).

Sintaxis Básica

int numero1 = 15;

if (numero1 > 10) {
    cout << "Es mayor que 10";
} else if (numero1 == 10) {
    cout << "Es igual a 10";
} else {
    cout << "Es menor que 10";
}

Operadores Lógicos

Se usan para combinar varias condiciones en un solo if:

  • AND lógico (&&): Todas deben ser verdaderas.
  • OR lógico (||): Al menos una debe ser verdadera.
int edadEntrada = 20;
bool tieneBoleto = true;

if (edadEntrada >= 18 && tieneBoleto == true) {
    cout << "Puede pasar.";
}

Control: Ciclos (for / while)

Sirven para repetir un bloque de código. Son la base fundamental para poder recorrer Estructuras de Datos como Arrays y Listas.

Bucle for

Úsalo cuando sepas **exactamente** cuántas veces quieres repetir algo (ej: recorrer 10 casillas de un arreglo).

// Estructura: for(inicio; condicion; incremento)

for (int iterador1 = 0; iterador1 < 5; iterador1++) {
    cout << "Vuelta numero: " << iterador1 << endl;
}
// El iterador1 va de 0 a 4. 
// iterador1++ significa "sumar 1 cada vez".

Bucle while

Úsalo cuando la repetición dependa de una condición dinámica (ej: seguir pidiendo datos "mientras" el usuario no escriba 0).

int entrada1 = 1;

while (entrada1 != 0) {
    cout << "Ingresa 0 para salir: ";
    cin >> entrada1;
}
cout << "Terminado.";

Funciones (Modularidad)

Para no escribir todo el código de un tirón dentro del main, creamos funciones separadas. Reciben parámetros y pueden o no retornar un resultado.

Función que Retorna valor

// 1. Tipo de retorno: int
// 2. Nombre: sumarNumeros
// 3. Parametros: parametro1, parametro2

int sumarNumeros(int parametro1, int parametro2) {
    int resultado1 = parametro1 + parametro2;
    return resultado1; // Devuelve el dato
}

int main() {
    int suma = sumarNumeros(5, 10);
    cout << suma; // Imprime 15
    return 0;
}

Función sin Retorno (void)

// "void" significa vacio/nada. 
// Hace una accion pero no devuelve un valor matematico.

void mostrarSaludo(string parametroNombre) {
    cout << "Hola, " << parametroNombre << endl;
}

int main() {
    mostrarSaludo("Estudiante");
    // No usamos variables para atrapar un "return"
    return 0;
}

Paso de Parámetros: Valor vs Referencia

Cuando una función recibe datos en C++, existen dos formas de trabajar con ellos: hacer una copia o compartir la casilla original en memoria.

Paso por Valor

La función recibe una copia independiente en otro espacio de la memoria.

  • Aislamiento: Las modificaciones dentro de la función solo alteran la copia. La variable en main() no cambia.
  • Analogía sencilla: Es como entregar una fotocopia; los apuntes o rayones que hagas en la copia no alteran el documento original.
  • ¿Cuándo usarlo?: Para datos primitivos pequeños (int, float, char, bool) de solo lectura.

Paso por Referencia

La función recibe un enlace directo (un alias o apodo) a la casilla original de memoria.

  • Misma casilla: No se duplica memoria. Cualquier cambio dentro de la función modifica directamente la variable en main().
  • Analogía sencilla: Es como compartir un documento en línea; si alguien escribe o borra, todos ven el cambio de inmediato.
  • ¿Cuándo usarlo?: Cuando necesites que la función devuelva o modifique datos en main(), o al pasar estructuras grandes.

Criterio para elegir: Si quieres proteger el dato original para que nadie lo toque, usa valor. Si necesitas que la función guarde o altere el resultado en la misma variable, usa referencia.

Paso por Valor

Es el comportamiento por defecto en C++. La función recibe una copia independiente del valor original.

Código de Ejemplo

void duplicar(int x) {
    x = x * 2; // Modifica unicamente su copia local 'x'
}

int main() {
    int numero = 10;
    duplicar(numero); // Envia el valor 10
    cout << "Valor final: " << numero; // Imprime 10
    return 0;
}

Al no colocar &, la función crea una casilla nueva en memoria y clona el número 10.

Cualquier operación sobre x se queda en su propia casilla. La variable numero en main() jamás se modifica.

Paso por Referencia (&)

Al agregar & al parámetro, este comparte la misma casilla en memoria que la variable original (un alias directo).

Código de Ejemplo

void duplicar(int &x) {
    x = x * 2; // Modifica directamente la casilla original
}

int main() {
    int numero = 10;
    duplicar(numero); // Envia la referencia
    cout << "Valor final: " << numero; // Imprime 20
    return 0;
}

Con &x, la función no reserva una nueva casilla en memoria. x es solo otro apodo para la casilla original.

Cualquier cambio que haga la función afecta directamente a numero en main().

Formas de Referencia: const & y Punteros

Para situaciones donde requieres optimizar rendimiento sin sacrificar seguridad, C++ provee variantes especializadas.

1. Referencia Constante (const &)

Pasa la referencia para no duplicar memoria, pero con const prohíbe cualquier modificación accidental. 

void imprimir(const string &texto) {
    // texto = "otro"; // ERROR: El compilador lo impide
    cout << texto;
}

int main() {
    string mensaje = "Texto largo o estructura pesada";
    imprimir(mensaje); // Cero copias y 100% seguro
    return 0;
}
  • Cero copias: Máxima velocidad al pasar string, arreglos o estructuras.
  • Seguridad: El compilador garantiza que la función solo puede leer el dato.

2. Paso por Puntero (*) [Estilo C]

La función recibe explícitamente la dirección física de memoria mediante el operador &. 

void duplicar(int *ptr) {
    if (ptr != nullptr) {
        *ptr = (*ptr) * 2; // Accede al valor con '*'
    }
}

int main() {
    int numero = 10;
    duplicar(&numero); // Pasamos direccion con '&'
    cout << numero; // Imprime 20
    return 0;
}
  • Dirección explícita: Requiere & al llamar y * al manipular el valor.
  • Permite nulos: Puede recibir nullptr cuando el parámetro es opcional.

20. Forzando salidas: break y continue Avanzado

#include <iostream>

int main() {
    for (int iterador1 = 1; iterador1 <= 10; iterador1++) {
        if (iterador1 == 5) {

28. Intercambiar dos variables (Swap) Intermedio

Planteamiento: Crea una función void intercambiar(int &a, int &b) que intercambie los valores de dos enteros usando una variable auxiliar. En main, inicializa int x = 4, y = 8;, llama a la función e imprime los valores antes y después.

#include <iostream>
using namespace std;

void intercambiar(int &a, int &b) {
    int temporal = a;
    a = b;
    b = temporal;
}

int main() {
    int x = 4, y = 8;
    cout << "Antes: x=" << x << ", y=" << y << endl;
    intercambiar(x, y);
    cout << "Despues: x=" << x << ", y=" << y << endl; // x=8, y=4
    return 0;
}

31. Reto: Validador de Contraseña Iterativo Avanzado

Planteamiento: La clave correcta es 999. Usa un bucle while para pedir la clave. Usa una variable intentos1 = 3 que baje cada que falla. Si llega a 0, bloquea.

#include <iostream>
using namespace std;

int main() {
    int entradaClave1 = 0;
    int intentos1 = 3;
    
    while (entradaClave1 != 999 && intentos1 > 0) {
        cout << "Ingresa PIN (" << intentos1 << " intentos restantes): ";
        cin >> entradaClave1;
        intentos1--; // Resta un intento
    }
    
    if (entradaClave1 == 999) {
        cout << "Bienvenido";
    } else {
        cout << "Sistema bloqueado";
    }
    return 0;
}

33. Reto: Generador de Secuencia Avanzado

Planteamiento: Pide al usuario cuántos números quiere generar (cantidad1). Usa un bucle for que imprima los múltiplos de 5 tantas veces como el usuario haya pedido.

#include <iostream>
using namespace std;

int main() {
    int cantidad1;

    cin >> cantidad1;

}

Resumen del Lenguaje Base

  • Tipado Fuerte: En C++ toda variable necesita declarar de qué tipo es (int, float, bool, char) antes de guardar un dato.
  • I/O: Usamos la librería <iostream> con cin >> para capturar datos y cout << para imprimirlos.
  • Control: if / else toma decisiones. for repite un número exacto de veces, y while repite mientras haya una condición cumplida.
  • Funciones: Trozos de código con un nombre específico (void o con return) que reciben parámetros, permitiendo reutilizar lógica.
  • Paso por Valor vs Referencia: Por valor se trabaja con una copia protegida (la original en main no cambia); por referencia (&, const & o punteros *) se accede a la variable original sin duplicar memoria.
  • El siguiente paso: Sabiendo guardar datos en variables y usar bucles, estás 100% listo para almacenar grandes cantidades de datos usando Arrays y Vectores.
