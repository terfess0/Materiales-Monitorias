4.1.1 Archivos: concepto (1/2)

Qué es un archivo y cómo se usa en C++

Un archivo es un conjunto de datos con un nombre, guardado en el disco. Los datos de las variables viven en la RAM y se pierden al cerrar el programa; los de un archivo permanecen.

En C++ se trabaja con flujos de la biblioteca <fstream>:

  • ofstream: escribir en un archivo.
  • ifstream: leer de un archivo.
  • fstream: leer y escribir.

Se usan igual que cout y cin. Todo archivo sigue 4 pasos:

  1. Abrir
  2. Verificar que se abrió
  3. Leer o escribir
  4. Cerrar

Ejemplo: escribir y leer un archivo

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ofstream f("saludo.txt");      // 1. abrir
    if (!f.is_open()) {            // 2. verificar
        cout << "No se pudo abrir";
        return 1;
    }
    f << "Hola archivo" << endl;   // 3. escribir
    f.close();                     // 4. cerrar

    ifstream g("saludo.txt");      // ahora leerlo
    string linea;
    getline(g, linea);
    cout << linea;
    g.close();
    return 0;
}

Salida

Hola archivo

4.1.2 Tipos de archivos (1/3): texto y binario

Según cómo se guardan los datos

  • Archivo de texto: guarda caracteres legibles, organizados en líneas. Se abre con el Bloc de notas. Ej: .txt, .csv.
  • Archivo binario: guarda los bytes tal como están en memoria. No es legible, pero es compacto y permite guardar estructuras completas. Ej: .dat.

Según cómo se accede a los datos:

  • Secuencial: se lee en orden, del primer dato al último.
  • Aleatorio (directo): se salta a cualquier posición. Requiere registros de tamaño fijo.

Ejemplo: el mismo número en texto y en binario

int n = 123456;

// Texto: un byte por cada dígito (6 bytes)
ofstream t("num.txt");
t << n;
t.close();

// Binario: los 4 bytes del int (sizeof(int))
ofstream b("num.dat", ios::binary);
b.write(reinterpret_cast<char*>(&n), sizeof(n));
b.close();

En el binario se usa write con la dirección de la variable y su tamaño.

4.1.2 Tipos de archivos (2/3): modos de apertura

El segundo parámetro de la apertura indica qué se quiere hacer

Modo Qué hace
ios::in Lectura. Falla si no existe.
ios::out Escritura. Si existe, borra todo su contenido.
ios::app Escribe al final, conserva lo anterior.
ios::trunc Vacía el archivo al abrirlo.
ios::ate Deja el cursor al final al abrir.
ios::binary Modo binario.

Los modos se combinan con |. Por defecto, ofstream usa ios::out e ifstream usa ios::in.

Ejemplos en C++

// Escribir (borra lo anterior)
ofstream a("datos.txt");

// Agregar al final
ofstream b("datos.txt", ios::app);

// Binario para agregar
ofstream c("datos.dat", ios::binary | ios::app);

// Leer y escribir en binario
fstream d("datos.dat",
          ios::binary | ios::in | ios::out);

4.1.3 Archivos de texto (1/3): escribir y agregar

Se usan los mismos operadores que cout

En un archivo de texto cada dato se escribe con <<, igual que en pantalla. El salto de línea se escribe con endl o "\n".

  • Si el archivo ya existe, ofstream lo sobrescribe.
  • Con ios::app los datos nuevos se escriben al final.
  • Siempre se cierra con close().

Escribir (crea o sobrescribe)

ofstream salida("notas.txt");
salida << "Ana " << 4.5 << "\n";
salida << "Luis " << 3.8 << endl;
salida.close();

Agregar al final

ofstream salida("notas.txt", ios::app);
salida << "Marta 4.2\n";
salida.close();

Contenido de notas.txt

Ana 4.5
Luis 3.8
Marta 4.2

4.1.3 Archivos de texto (2/3): leer

Línea por línea o dato por dato

  • getline(archivo, linea) lee una línea completa, con espacios.
  • archivo >> dato lee hasta el siguiente espacio.
  • Para recorrer todo el archivo, la lectura va dentro de la condición del while.

Error común: while (!f.eof()) hace una vuelta de más, porque eof() solo se activa después de intentar leer más allá del final.

Un archivo CSV separa los valores con comas. Se parte cada línea con stringstream y getline(ss, x, ',').

Leer por líneas

ifstream entrada("notas.txt");
string linea;
while (getline(entrada, linea)) {
    cout << linea << endl;
}
entrada.close();

Leer por campos

string nombre;
float nota;
while (entrada >> nombre >> nota) {
    cout << nombre << " -> " << nota << endl;
}

Leer una línea CSV (requiere <sstream>)

// linea = "Ana,4.5"
stringstream ss(linea);
string nombre, nota;
getline(ss, nombre, ',');   // hasta la coma
getline(ss, nota);          // el resto

4.1.4 Eliminación (1/3): borrar, renombrar y vaciar

Operaciones sobre el archivo completo

"Eliminar" puede significar tres cosas distintas:

  • Borrar el archivo del disco: remove("nombre"). Devuelve 0 si lo logró.
  • Cambiarle el nombre: rename("viejo", "nuevo").
  • Vaciar su contenido sin borrarlo: abrirlo con ios::trunc.

Antes de borrar o renombrar, el archivo debe estar cerrado. Se necesita <cstdio>.

Borrar un archivo

#include <cstdio>

if (remove("viejo.txt") == 0)
    cout << "Eliminado";
else
    cout << "No se pudo eliminar";

Renombrar y vaciar

rename("a.txt", "b.txt");          // a.txt ahora es b.txt

ofstream f("b.txt", ios::trunc);   // b.txt queda vacio
f.close();

4.1.4 Eliminación (2/3): quitar un dato de adentro

Con un archivo temporal

Un archivo no permite "borrar en medio". Para quitar una línea se hace esto:

  1. Abrir el original para leer y un archivo temp.txt para escribir.
  2. Copiar al temporal todas las líneas menos la que se quiere eliminar.
  3. Cerrar los dos archivos.
  4. Borrar el original con remove.
  5. Renombrar el temporal con el nombre del original.

Ejemplo: eliminar "Marta".

datos.txt     temp.txt
Ana     ->    Ana
Luis    ->    Luis
Marta   (se omite)
Pedro   ->    Pedro

Programa en C++

ifstream in("datos.txt");
ofstream out("temp.txt");
string linea;

while (getline(in, linea)) {
    if (linea != "Marta")        // copia todo menos Marta
        out << linea << "\n";
}

in.close();
out.close();                     // cerrar antes de remove
remove("datos.txt");             // borra el original
rename("temp.txt", "datos.txt"); // el temporal toma su lugar

4.2.1 Registros: concepto (1/3)

Un struct guardado en un archivo binario

Un registro es un conjunto de campos que describen una cosa: un producto, un estudiante, un empleado. En C++ se declara con un struct.

Un archivo de registros es un archivo binario donde se guardan registros del mismo tamaño, uno tras otro.

Importante: los campos de texto se declaran como char nombre[20] y no como string. Un string guarda internamente un puntero, y al escribirlo en el archivo se guardaría una dirección y no el texto.

Este struct se usa en todos los ejemplos y ejercicios que siguen.

El registro

struct Producto {
    int   codigo;
    char  nombre[20];
    float precio;
    bool  activo;      // se usa al eliminar (4.2.5)
};

Guardar un registro y leerlo

Producto p = {1001, "Cuaderno", 3500.5f, true};

ofstream out("productos.dat", ios::binary);
out.write(reinterpret_cast<char*>(&p), sizeof(p));
out.close();

Producto r;
ifstream in("productos.dat", ios::binary);
in.read(reinterpret_cast<char*>(&r), sizeof(r));
cout << r.codigo << " " << r.nombre << " " << r.precio;

4.2.1 Registros: concepto (2/3)

Tamaño, posición y cantidad de registros

Como todos los registros miden lo mismo, se pueden calcular posiciones:

  • Tamaño de un registro: sizeof(Producto). Siempre se usa sizeof; no se suman los campos a mano, porque el compilador puede agregar bytes de relleno.
  • Posición en bytes del registro número pos (desde 0): pos * sizeof(Producto).
  • Cantidad de registros: tamaño del archivo en bytes dividido entre sizeof(Producto).

Contar los registros de un archivo

ifstream f("productos.dat", ios::binary);
f.seekg(0, ios::end);          // cursor al final
long bytes = f.tellg();        // tamano total en bytes
int total = bytes / sizeof(Producto);
cout << "Registros: " << total;

Listar todos los registros (lectura secuencial)

ifstream in("productos.dat", ios::binary);
Producto p;
while (in.read(reinterpret_cast<char*>(&p), sizeof(p))) {
    cout << p.codigo << " | " << p.nombre
         << " | " << p.precio << endl;
}

4.2.2 Inserción (1/3): al final y en una posición

Agregar registros nuevos

Insertar es agregar un registro al archivo. Las dos formas más simples:

  • Al final: se abre con ios::app y se escribe. Es la forma más usada.
  • En una posición existente: se salta con seekp y se escribe. Esto reemplaza el registro que estaba allí, así que sirve para modificar.

Con fstream en modo in | out el archivo ya debe existir.

Insertar al final

Producto p = {1002, "Lapiz", 800.0f, true};

ofstream out("productos.dat", ios::binary | ios::app);
out.write(reinterpret_cast<char*>(&p), sizeof(p));
out.close();

Escribir en la posición 2 (reemplaza)

fstream f("productos.dat",
          ios::binary | ios::in | ios::out);
f.seekp(2 * sizeof(Producto), ios::beg);
f.write(reinterpret_cast<char*>(&p), sizeof(p));
f.close();

4.2.2 Inserción (2/3): ordenada por código

Mantener el archivo ordenado

Un archivo no puede "abrir un hueco" como un arreglo. Para insertar en orden se usa un archivo temporal:

  1. Copiar al temporal los registros con código menor al nuevo.
  2. Escribir el registro nuevo.
  3. Copiar los registros restantes.
  4. Borrar el original y renombrar el temporal.

Ejemplo: insertar el código 1020.

est.dat           temp.dat
1003      ->      1003
1007      ->      1007
          nuevo   1020
1025      ->      1025
1031      ->      1031

Programa en C++

void insertarOrdenado(Producto nuevo) {
    ifstream in("productos.dat", ios::binary);
    ofstream out("temp.dat", ios::binary);
    Producto p;
    bool puesto = false;

    while (in.read(reinterpret_cast<char*>(&p), sizeof(p))) {
        if (!puesto && nuevo.codigo < p.codigo) {
            out.write(reinterpret_cast<char*>(&nuevo), sizeof(nuevo));
            puesto = true;
        }
        out.write(reinterpret_cast<char*>(&p), sizeof(p));
    }
    if (!puesto)   // el nuevo es el mayor o el archivo estaba vacio
        out.write(reinterpret_cast<char*>(&nuevo), sizeof(nuevo));

    in.close();
    out.close();
    remove("productos.dat");
    rename("temp.dat", "productos.dat");
}

4.2.3 Búsqueda secuencial (1/2)

Leer registro por registro desde el inicio

Se leen los registros uno por uno, desde el primero, comparando la clave (por ejemplo, el código) hasta encontrarla o llegar al final del archivo.

  • Funciona aunque el archivo esté desordenado.
  • Mejor caso: 1 lectura. Peor caso: N lecturas, es decir O(N).
  • Conviene que la función devuelva la posición del registro (o -1 si no existe), porque luego se puede usar para modificarlo o eliminarlo.
  • Se ignoran los registros inactivos (eliminados lógicamente, tema 4.2.5).

Programa en C++

// Devuelve la posicion del registro, o -1 si no existe
int buscarPorCodigo(int codigo) {
    ifstream in("productos.dat", ios::binary);
    if (!in) return -1;          // el archivo no existe
    Producto p;
    int pos = 0;
    while (in.read(reinterpret_cast<char*>(&p), sizeof(p))) {
        if (p.activo && p.codigo == codigo)
            return pos;          // encontrado
        pos++;
    }
    return -1;                   // llego al final
}

int main() {
    int c;
    cout << "Codigo: ";
    cin >> c;
    int pos = buscarPorCodigo(c);
    if (pos == -1) cout << "No existe";
    else           cout << "Esta en la posicion " << pos;
    return 0;
}

4.2.4 Búsqueda de acceso aleatorio (1/3)

Saltar directo a un registro

Como los registros miden lo mismo, se puede saltar directamente al registro número pos sin leer los anteriores. El cursor se mueve con:

  • seekg(bytes, ios::beg): para leer desde esa posición.
  • seekp(bytes, ios::beg): para escribir en esa posición.

La posición en bytes es pos * sizeof(Producto). El costo es una sola lectura: O(1).

Comparación: para llegar al registro 500 con búsqueda secuencial se leen 500 registros; con acceso aleatorio, uno.

Leer el registro número pos

bool leerEnPosicion(int pos, Producto &p) {
    ifstream in("productos.dat", ios::binary);
    if (!in) return false;
    in.seekg(pos * sizeof(Producto), ios::beg);
    if (!in.read(reinterpret_cast<char*>(&p), sizeof(p)))
        return false;       // posicion fuera del archivo
    return true;
}

Escribir (modificar) el registro número pos

bool escribirEnPosicion(int pos, const Producto &p) {
    fstream f("productos.dat",
              ios::binary | ios::in | ios::out);
    if (!f) return false;
    f.seekp(pos * sizeof(Producto), ios::beg);
    f.write(reinterpret_cast<const char*>(&p), sizeof(p));
    return true;
}

4.2.4 Búsqueda de acceso aleatorio (2/3)

Aprovechar el salto para buscar por código

Búsqueda binaria sobre el archivo. Si el archivo está ordenado por código (ver inserción ordenada), se hace seekg al registro del medio y se descarta la mitad en cada paso, igual que en un arreglo. Costo: O(log N).

Dirección directa. Si los códigos son consecutivos (1000, 1001, 1002...), el registro de código c se guarda en la posición c - 1000. Así se encuentra con un solo salto, sin buscar:

int pos = codigo - 1000;
in.seekg(pos * sizeof(Producto), ios::beg);

Búsqueda binaria en el archivo

int busquedaBinaria(int codigo) {
    ifstream in("productos.dat", ios::binary);
    if (!in) return -1;
    in.seekg(0, ios::end);
    int total = in.tellg() / sizeof(Producto);

    int inicio = 0, fin = total - 1;
    Producto p;
    while (inicio <= fin) {
        int medio = inicio + (fin - inicio) / 2;
        in.seekg(medio * sizeof(Producto), ios::beg);
        in.read(reinterpret_cast<char*>(&p), sizeof(p));
        if (p.codigo == codigo) return medio;
        if (p.codigo < codigo) inicio = medio + 1;
        else                   fin = medio - 1;
    }
    return -1;
}

4.2.5 Eliminación de registros (1/3): lógica

Marcar el registro como eliminado

En un archivo de registros no se puede quitar uno del medio. Hay dos estrategias. La primera es la eliminación lógica:

  1. Se busca la posición del registro.
  2. Se lee el registro y se pone activo = false.
  3. Se escribe de vuelta en la misma posición.

El registro sigue ocupando espacio, pero todas las búsquedas y listados ignoran los inactivos.

Ventaja: es rápida y se puede deshacer. Desventaja: el archivo no se hace más pequeño.

Programa en C++ (usa las funciones de 4.2.3 y 4.2.4)

void eliminarLogico(int codigo) {
    int pos = buscarPorCodigo(codigo);
    if (pos == -1) {
        cout << "No existe";
        return;
    }
    Producto p;
    leerEnPosicion(pos, p);
    p.activo = false;                // marca de borrado
    escribirEnPosicion(pos, p);
    cout << "Producto eliminado";
}

Antes y después (campo activo)

1003 activo=1        1003 activo=1
1007 activo=1        1007 activo=1
1012 activo=1  -->   1012 activo=0
1020 activo=1        1020 activo=1

4.2.5 Eliminación de registros (2/3): física

Compactar el archivo

La eliminación física reescribe el archivo sin los registros inactivos, usando un archivo temporal:

  1. Leer cada registro del original.
  2. Si está activo, escribirlo en temp.dat.
  3. Cerrar los dos archivos.
  4. Borrar el original y renombrar el temporal.

Recupera el espacio, pero recorre todo el archivo: O(N). Por eso se hace de vez en cuando y no en cada eliminación.

est.dat              temp.dat
1003 activo=1  ->   1003
1007 activo=1  ->   1007
1012 activo=0   (se omite)
1020 activo=1  ->   1020

Programa en C++

void compactar() {
    ifstream in("productos.dat", ios::binary);
    ofstream out("temp.dat", ios::binary);
    Producto p;
    while (in.read(reinterpret_cast<char*>(&p), sizeof(p))) {
        if (p.activo)                // copia solo los vigentes
            out.write(reinterpret_cast<char*>(&p), sizeof(p));
    }
    in.close();
    out.close();
    remove("productos.dat");
    rename("temp.dat", "productos.dat");
}

Ejemplo de lectura y escritura de archivos

Programa con menú que reúne todo lo anterior

Este programa maneja un archivo binario de productos con un menú. Cada opción usa un tema de la guía:

  • Insertar: al final, sin repetir códigos (4.2.2).
  • Listar: lectura secuencial (4.2.1).
  • Buscar: búsqueda secuencial (4.2.3) y lectura en una posición (4.2.4).
  • Eliminar: eliminación lógica (4.2.5).
  • Compactar: eliminación física con archivo temporal (4.2.5).

Pruébalo así: inserta 3 productos, elimina uno, lista (el eliminado no aparece), compacta y vuelve a listar.

#include <iostream>
#include <fstream>
#include <cstdio>
using namespace std;

struct Producto {
    int   codigo;
    char  nombre[20];
    float precio;
    bool  activo;
};

const char* ARCHIVO = "productos.dat";

int buscarPorCodigo(int codigo) {
    ifstream in(ARCHIVO, ios::binary);
    if (!in) return -1;
    Producto p;
    int pos = 0;
    while (in.read(reinterpret_cast<char*>(&p), sizeof(p))) {
        if (p.activo && p.codigo == codigo) return pos;
        pos++;
    }
    return -1;
}

bool leerEnPosicion(int pos, Producto &p) {
    ifstream in(ARCHIVO, ios::binary);
    if (!in) return false;
    in.seekg(pos * sizeof(Producto), ios::beg);
    return (bool)in.read(reinterpret_cast<char*>(&p), sizeof(p));
}

bool escribirEnPosicion(int pos, const Producto &p) {
    fstream f(ARCHIVO, ios::binary | ios::in | ios::out);
    if (!f) return false;
    f.seekp(pos * sizeof(Producto), ios::beg);
    f.write(reinterpret_cast<const char*>(&p), sizeof(p));
    return true;
}

void insertar() {
    Producto p;
    cout << "Codigo: ";  cin >> p.codigo;
    if (buscarPorCodigo(p.codigo) != -1) {
        cout << "Ese codigo ya existe.\n";
        return;
    }
    cout << "Nombre: ";  cin.ignore(); cin.getline(p.nombre, 20);
    cout << "Precio: ";  cin >> p.precio;
    p.activo = true;
    ofstream out(ARCHIVO, ios::binary | ios::app);
    out.write(reinterpret_cast<char*>(&p), sizeof(p));
    cout << "Guardado.\n";
}

void listar() {
    ifstream in(ARCHIVO, ios::binary);
    Producto p;
    int mostrados = 0;
    while (in.read(reinterpret_cast<char*>(&p), sizeof(p))) {
        if (p.activo) {
            cout << p.codigo << " | " << p.nombre
                 << " | " << p.precio << "\n";
            mostrados++;
        }
    }
    if (mostrados == 0) cout << "(sin registros)\n";
}

void buscar() {
    int codigo;
    cout << "Codigo: ";  cin >> codigo;
    int pos = buscarPorCodigo(codigo);
    Producto p;
    if (pos != -1 && leerEnPosicion(pos, p))
        cout << "Posicion " << pos << ": " << p.nombre
             << ", precio " << p.precio << "\n";
    else
        cout << "No existe.\n";
}

void eliminar() {
    int codigo;
    cout << "Codigo a eliminar: ";  cin >> codigo;
    int pos = buscarPorCodigo(codigo);
    Producto p;
    if (pos == -1 || !leerEnPosicion(pos, p)) {
        cout << "No existe.\n";
        return;
    }
    p.activo = false;
    escribirEnPosicion(pos, p);
    cout << "Eliminado (logico).\n";
}

void compactar() {
    ifstream in(ARCHIVO, ios::binary);
    ofstream out("temp.dat", ios::binary);
    Producto p;
    while (in.read(reinterpret_cast<char*>(&p), sizeof(p)))
        if (p.activo)
            out.write(reinterpret_cast<char*>(&p), sizeof(p));
    in.close();
    out.close();
    remove(ARCHIVO);
    rename("temp.dat", ARCHIVO);
    cout << "Archivo compactado.\n";
}

int main() {
    int op;
    do {
        cout << "\n1.Insertar 2.Listar 3.Buscar "
             << "4.Eliminar 5.Compactar 0.Salir\n> ";
        cin >> op;
        switch (op) {
            case 1: insertar();  break;
            case 2: listar();    break;
            case 3: buscar();    break;
            case 4: eliminar();  break;
            case 5: compactar(); break;
        }
    } while (op != 0);
    return 0;
}

Manipulación de archivos: compresor (1/3)

Compresión RLE (Run-Length Encoding)

Un compresor reduce el tamaño de un archivo eliminando repetición. RLE reemplaza cada racha de caracteres iguales por la cantidad y el carácter:

AAAABBBCC   ->   4A3B2C

Algoritmo:

  1. Leer el archivo carácter por carácter.
  2. Si el carácter es igual al anterior, aumentar el contador.
  3. Si es distinto, escribir contador y carácter anterior, y empezar una racha nueva.
  4. Al terminar, escribir la última racha.

Funciona bien con datos muy repetitivos. Con texto que casi no repite letras, el resultado puede ser más grande que el original.

Compresor en C++

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream in("original.txt");
    ofstream out("comprimido.txt");
    char actual, anterior = 0;
    int cuenta = 0;

    while (in.get(actual)) {         // get lee tambien espacios
        if (cuenta > 0 && actual == anterior) {
            cuenta++;                // sigue la racha
        } else {
            if (cuenta > 0) out << cuenta << anterior;
            anterior = actual;
            cuenta = 1;
        }
    }
    if (cuenta > 0) out << cuenta << anterior;   // ultima racha
    return 0;
}

Manipulación de archivos: descompresor (2/3)

Recuperar el archivo original

Para descomprimir se hace el camino inverso: leer la cantidad, leer el carácter y escribirlo esa cantidad de veces.

4A3B2C   ->   AAAABBBCC

Limitación: esta versión simple no funciona si el texto original contiene dígitos, porque no se puede distinguir un dígito de una cantidad. Los compresores reales (ZIP, 7z) usan métodos más completos, como Huffman y LZ77.

Descompresor en C++

#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ifstream in("comprimido.txt");
    ofstream out("restaurado.txt");
    int cuenta;
    char c;

    while (in >> cuenta) {      // lee la cantidad
        in.get(c);               // lee el caracter que sigue
        for (int i = 0; i < cuenta; i++)
            out.put(c);          // lo repite 'cuenta' veces
    }
    return 0;
}

Prueba: comprime un texto, descomprímelo y comprueba que restaurado.txt es igual a original.txt.

Resumen

Tema Idea clave en C++
Archivo (4.1.1) ofstream, ifstream, fstream. Abrir, verificar, leer o escribir, cerrar.
Tipos (4.1.2) Texto (legible) y binario (ios::binary). Modos: in, out, app, trunc.
Texto (4.1.3) << y getline. La lectura va dentro del while, no eof().
Eliminación (4.1.4) remove, rename, ios::trunc. Quitar un dato: copiar a un temporal.
Registro (4.2.1) struct con char[], write/read y sizeof.
Inserción (4.2.2) Al final con ios::app; ordenada con archivo temporal.
Secuencial (4.2.3) Leer uno por uno: O(N). Devuelve la posición o -1.
Aleatorio (4.2.4) seekg/seekp con pos * sizeof: O(1). Binaria si está ordenado.
Eliminar registro (4.2.5) Lógica (activo = false) o física (compactar).
Manipulación Copiar, cifrar y comprimir (RLE) leyendo y escribiendo carácter por carácter.

Errores comunes: no verificar is_open(), no cerrar el archivo antes de remove o rename, guardar string en archivos binarios y sumar a mano los tamaños de un struct.
