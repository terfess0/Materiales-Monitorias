4. Archivos y Registros en C++

Concepto y tipos de archivos, archivos de texto, eliminación, registros (inserción, búsqueda secuencial, búsqueda de acceso aleatorio y eliminación), sistemas de archivos, formatos, compresores y relación con listas.

¿Por qué estudiar archivos?

Las variables y estructuras que has visto hasta ahora viven en la memoria RAM y desaparecen al cerrar el programa. Los archivos permiten que los datos persistan en el disco: notas, inventarios, configuraciones, imágenes, bases de datos. Todo programa real los usa.

Avanza con las flechas del teclado o los botones inferiores.

4.1.1. Concepto de Archivo

Un archivo es una colección de datos relacionados, con un nombre, almacenada en memoria secundaria (disco duro, SSD, USB). A diferencia de la RAM, la información no se pierde al apagar el equipo.

Memoria RAM Archivo en disco
Persistencia Volátil: se pierde al cerrar Permanente
Velocidad Muy rápida Más lenta
Capacidad Limitada (GB) Muy grande (TB)
Ejemplo en C++ int, arreglos, struct ofstream, ifstream

Flujos (streams) en C++

C++ trabaja con archivos mediante flujos: un canal por donde fluyen los datos entre el programa y el archivo. Se incluye la biblioteca <fstream>:

  • ofstream (output): escribir en un archivo.
  • ifstream (input): leer de un archivo.
  • fstream: leer y escribir en el mismo flujo.

Se usan igual que cout y cin: archivo << dato; y archivo >> dato;

Ciclo de vida de un archivo

#include <fstream>
using namespace std;

ofstream f("datos.txt");   // 1. abrir
if (!f.is_open()) return 1; // 2. verificar
f << "Hola" << endl;      // 3. escribir
f.close();                 // 4. cerrar

4.1.2. Tipos de Archivos

Los archivos se pueden clasificar según cómo se guardan los datos y según cómo se accede a ellos.

Por contenido

  • Archivos de texto: guardan caracteres legibles (ASCII/UTF-8) organizados en líneas terminadas en \n. Se pueden abrir con el Bloc de notas. Ej: .txt, .csv, .cpp.
  • Archivos binarios: guardan los bytes tal como están en memoria. No son legibles, pero son compactos y rápidos. Ej: .dat, .exe, .png.

Ejemplo: el entero 123456 ocupa 6 bytes en un archivo de texto (un byte por dígito) y solo 4 bytes en uno binario (sizeof(int)).

Por forma de acceso

  • Secuencial: se lee en orden, del primer dato al último. Para llegar al registro 500 hay que pasar por los 499 anteriores.
  • Aleatorio (directo): se salta directamente a cualquier posición con seekg/seekp. Requiere registros de tamaño fijo.
  • Indexado: usa un archivo/índice auxiliar que dice en qué posición está cada clave (idea base de las bases de datos).

Modos de apertura (ios::)

Modo Significado Si el archivo existe Si no existe
ios::in Lectura Lo abre Falla
ios::out Escritura Borra todo el contenido Lo crea
ios::app Agregar al final Conserva y escribe al final Lo crea
ios::trunc Vaciar al abrir Borra el contenido Lo crea
ios::ate Cursor al final al abrir Conserva Depende
ios::binary Modo binario (se combina con |) ios::binary | ios::in | ios::out

Por defecto ofstream usa ios::out e ifstream usa ios::in. Con fstream debes indicar el modo.

4.1.3. Archivos de Texto

Se manejan con los mismos operadores de cout/cin. Las tres operaciones básicas son escribir, agregar y leer.

1. Escribir (crea o sobrescribe)

ofstream salida("notas.txt");
salida << "Ana " << 4.5 << "\n";
salida << "Luis " << 3.8 << endl;
salida.close();

2. Agregar al final (no borra lo anterior)

ofstream salida("notas.txt", ios::app);
salida << "Marta 4.2\n";
salida.close();

3. Leer línea por línea

ifstream entrada("notas.txt");
if (!entrada.is_open()) {
    cout << "No se pudo abrir\n";
    return 1;
}
string linea;
while (getline(entrada, linea)) {
    cout << linea << endl;
}
entrada.close();

4. Leer por campos con >>

string nombre; float nota;
while (entrada >> nombre >> nota) {
    cout << nombre << " -> " << nota << endl;
}

El operador >> separa por espacios; getline lee la línea completa (con espacios).

Error clásico: while(!f.eof())

eof() solo se activa después de intentar leer más allá del final, así que el ciclo procesa una vez de más. La forma correcta es usar la lectura como condición: while (getline(f, linea)).

5. Archivos CSV (valores separados por coma)

#include <sstream>
// linea = "Ana,4.5"
stringstream ss(linea);
string nombre, nota;
getline(ss, nombre, ',');  // lee hasta la coma
getline(ss, nota);         // lee el resto
Método Indica
is_open() El archivo se abrió bien
eof() Se llegó al final
fail() Falló una lectura/escritura
clear() Limpia las banderas de error

4.1.4. Eliminación

Eliminar puede significar cosas distintas: borrar el archivo completo, vaciar su contenido o quitar solo un dato de adentro. Un archivo no permite "borrar en medio", por eso se usa un archivo temporal.

1. Eliminar el archivo completo

#include <cstdio>
if (remove("viejo.txt") == 0)
    cout << "Eliminado\n";
else
    cout << "No se pudo eliminar\n";

Devuelve 0 si tuvo éxito. Cierra el archivo (close()) antes de eliminarlo. En C++17 también existe std::filesystem::remove.

2. Renombrar y vaciar

rename("a.txt", "b.txt");              // renombrar
ofstream f("b.txt", ios::trunc);       // vaciar contenido
f.close();

3. Eliminar un dato de adentro

ifstream in("datos.txt");
ofstream out("temp.txt");
string linea;
while (getline(in, linea)) {
    if (linea != "Marta")       // copia todo menos el objetivo
        out << linea << "\n";
}
in.close(); out.close();
remove("datos.txt");            // borra el original
rename("temp.txt", "datos.txt");// el temporal pasa a ser el original

4.2.1. Registros: Concepto

Un registro es un conjunto de campos (de distintos tipos) que describen una entidad: un estudiante, un producto, un empleado. En C++ se representa con un struct. Un archivo de registros es una secuencia de registros del mismo tamaño.

struct Estudiante {
    int   codigo;       // 4 bytes
    char  nombre[30];   // 30 bytes
    float nota;         // 4 bytes
    bool  activo;       // 1 byte
};

Estudiante e = {1010, "Ana Gomez", 4.8f, true};

// Guardar el registro completo en binario
ofstream f("est.dat", ios::binary);
f.write(reinterpret_cast<char*>(&e), sizeof(e));
f.close();

// Leerlo
Estudiante r;
ifstream g("est.dat", ios::binary);
g.read(reinterpret_cast<char*>(&r), sizeof(r));

¿Por qué char nombre[30] y no string?

Un string guarda internamente un puntero a memoria dinámica. Si lo escribes con write, guardas la dirección y no el texto, y al leerlo el programa falla. Para archivos binarios los campos deben tener tamaño fijo: char[], int, float, bool.

Un registro en memoria (con relleno)

El compilador agrega bytes de relleno (padding) para alinear los campos. Por eso sizeof(Estudiante) normalmente da 44 y no 39. Usa siempre sizeof, nunca sumes tú los tamaños.

Fórmulas clave del archivo de registros

  • Posición en bytes: pos * sizeof(Estudiante)
  • Cantidad de registros: tamaño_en_bytes / sizeof(Estudiante)
  • Leer/escribir 1 registro: read / write con reinterpret_cast<char*>
// Contar registros de un archivo
ifstream f("est.dat", ios::binary);
f.seekg(0, ios::end);          // cursor al final
long bytes = f.tellg();        // tamaño total
int total = bytes / sizeof(Estudiante);

4.2.2. Inserción de Registros

Insertar es agregar un registro nuevo. Hay tres formas, según dónde se quiera colocar.

A. Al final (la más simple) O(1)

ofstream f("est.dat", ios::binary | ios::app);
f.write(reinterpret_cast<char*>(&e), sizeof(e));

B. En una posición existente (sobrescribe)

fstream f("est.dat", ios::binary | ios::in | ios::out);
f.seekp(pos * sizeof(e), ios::beg);   // saltar a la posición
f.write(reinterpret_cast<char*>(&e), sizeof(e));

Reemplaza el registro que estaba allí. fstream con in|out exige que el archivo ya exista.

C. Ordenada por clave O(N)

Un archivo no puede "abrir un hueco" como un arreglo. Se copia al temporal: primero los menores, luego el nuevo, luego el resto; después se reemplaza el original.

while (in.read((char*)&p, sizeof(p))) {
    if (!puesto && nuevo.codigo < p.codigo) {
        out.write((char*)&nuevo, sizeof(nuevo));
        puesto = true;
    }
    out.write((char*)&p, sizeof(p));
}
if (!puesto) out.write((char*)&nuevo, sizeof(nuevo));

Buena práctica: evitar claves duplicadas

Antes de insertar, busca el código con una búsqueda secuencial. Si ya existe, rechaza la inserción.

4.2.3. Búsqueda Secuencial

Se leen los registros uno por uno desde el principio, comparando la clave, hasta encontrarla o llegar al final del archivo. Funciona aunque el archivo esté desordenado.

Peor caso: N lecturas — O(N)
Mejor caso: 1 lectura
// Devuelve la posición del registro, o -1
int buscarSecuencial(int codigo) {
    ifstream f("est.dat", ios::binary);
    if (!f) return -1;            // no existe el archivo
    Estudiante e;
    int pos = 0;
    while (f.read(reinterpret_cast<char*>(&e), sizeof(e))) {
        if (e.activo && e.codigo == codigo)
            return pos;           // encontrado
        pos++;
    }
    return -1;                    // llegó al final
}

Ventajas: simple, no requiere orden. Desventaja: con millones de registros es lenta, porque cada lectura va al disco. Devolver la posición (y no el registro) permite luego modificar o eliminar con acceso aleatorio.

4.2.4. Búsqueda de Acceso Aleatorio

Con registros de tamaño fijo se puede saltar directamente a cualquier posición sin leer los anteriores. El cursor del archivo se mueve con seekg (lectura) y seekp (escritura).

Acceso por posición: O(1)
Binaria sobre archivo ordenado: O(log N)
// Leer el registro número 'pos' (desde 0)
bool leerEnPosicion(int pos, Estudiante &e) {
    ifstream f("est.dat", ios::binary);
    if (!f) return false;
    f.seekg(pos * sizeof(Estudiante), ios::beg);
    if (!f.read(reinterpret_cast<char*>(&e), sizeof(e)))
        return false;             // posición fuera del archivo
    return true;
}

Tres formas de aprovecharlo

  • Por número de registro: "dame el registro 5".
  • Dirección directa por clave: si los códigos son 1000, 1001, 1002..., la posición es codigo - 1000.
  • Búsqueda binaria en el archivo: si está ordenado por código, se hace seekg al registro medio y se descarta la mitad, igual que en arreglos.
// Binaria sobre archivo ordenado
int inicio = 0, fin = total - 1;
while (inicio <= fin) {
    int medio = inicio + (fin - inicio) / 2;
    f.seekg(medio * sizeof(e), ios::beg);
    f.read((char*)&e, sizeof(e));
    if (e.codigo == buscado) return medio;
    if (e.codigo < buscado) inicio = medio + 1;
    else fin = medio - 1;
}
return -1;

Bajo cada caja aparece su desplazamiento en bytes (con sizeof = 44).

4.2.5. Eliminación de Registros

Como en un archivo no se puede quitar un registro del medio, hay dos estrategias: lógica (marcarlo como borrado) y física (reescribir el archivo sin él).

Eliminación lógica rápida

Se agrega un campo bool activo. Para "borrar" se pone en false y se reescribe ese registro en su lugar. Todas las búsquedas y listados ignoran los inactivos.

int pos = buscarSecuencial(codigo);
Estudiante e;
leerEnPosicion(pos, e);
e.activo = false;                 // marca de borrado
fstream f("est.dat", ios::binary | ios::in | ios::out);
f.seekp(pos * sizeof(e), ios::beg);
f.write((char*)&e, sizeof(e));

Ventaja: rápida y reversible. Desventaja: el archivo no se achica.

Eliminación física (compactar) O(N)

ifstream in("est.dat", ios::binary);
ofstream out("temp.dat", ios::binary);
Estudiante e;
while (in.read((char*)&e, sizeof(e)))
    if (e.activo)                 // copia solo los vigentes
        out.write((char*)&e, sizeof(e));
in.close(); out.close();
remove("est.dat");
rename("temp.dat", "est.dat");

Se suele hacer de vez en cuando para recuperar espacio.

Sistemas de Archivos y Formatos

¿Quién decide dónde se guarda cada archivo en el disco, y cómo sabe el sistema qué tipo de archivo es?

¿Qué es un sistema de archivos?

Es la estructura con que el sistema operativo organiza los datos en un disco: dónde están los archivos, su tamaño, fechas, permisos y cuáles bloques están libres.

Sistema Se usa en
FAT32 / exFAT USB, tarjetas SD
NTFS Windows
ext4 Linux
APFS macOS / iOS

Componentes: directorios (carpetas), metadatos (inodos o entradas), bloques de datos y un mapa de bloques libres. "Formatear" un disco es crear estas estructuras vacías.

Creación de un archivo dentro del sistema

Formatos de archivo

La extensión (.pdf, .png) es solo una etiqueta. El formato real lo define cómo están organizados los bytes. Muchos formatos inician con una firma llamada número mágico:

Formato Primeros bytes (hex)
PDF 25 50 44 46 (%PDF)
PNG 89 50 4E 47
ZIP / DOCX 50 4B (PK)
JPEG FF D8 FF

Texto plano: TXT, CSV, JSON, XML (legibles, fáciles de intercambiar). Binarios: DAT, imágenes, audio, ejecutables (compactos y rápidos).

Explorar el sistema de archivos desde C++17

#include <filesystem>
namespace fs = std::filesystem;

fs::create_directory("copias");          // crear carpeta
if (fs::exists("notas.txt"))
    cout << fs::file_size("notas.txt") << " bytes\n";
for (auto& item : fs::directory_iterator("."))
    cout << item.path().filename().string() << endl;

Compila con -std=c++17.

Manipulación de Archivos: Compresores y Listas

Compresión RLE (Run-Length Encoding)

Un compresor reduce el tamaño del archivo eliminando repetición. RLE reemplaza una racha de caracteres iguales por cantidad + carácter:

AAAABBBCC  →  4A3B2C

ifstream in("original.txt");
ofstream out("comprimido.txt");
char actual, anterior = 0;
int cuenta = 0;
while (in.get(actual)) {
    if (cuenta > 0 && actual == anterior) {
        cuenta++;                         // sigue la racha
    } else {
        if (cuenta > 0) out << cuenta << anterior;
        anterior = actual;
        cuenta = 1;
    }
}
if (cuenta > 0) out << cuenta << anterior;

Funciona bien con datos muy repetitivos (imágenes simples). Si el texto casi no repite letras, ¡el archivo puede crecer! Esta versión simple falla si el texto contiene dígitos. Compresores reales (ZIP, 7z) usan Huffman y LZ77.

Otras manipulaciones típicas

  • Copiar un archivo (leer y escribir carácter a carácter).
  • Convertir formatos (texto ↔ binario, CSV → registros).
  • Encriptar con un desplazamiento (cifrado César) sobre cada byte.
  • Partir / unir archivos grandes.

Archivos y Listas: la misma idea en dos lugares

Las operaciones que ya practicaste con listas existen igual en un archivo de registros. Cambia dónde viven los datos (RAM vs disco):

Operación Lista / arreglo Archivo de registros
Representación struct + arreglo o nodos struct + registros fijos
Creación Lista vacía n = 0 ofstream crea el archivo
Inserción Corrimiento / punteros app o archivo temporal
Eliminación Corrimiento / enlazar Marca lógica o compactar
Modificación a[i] = x seekp + write
Búsqueda Recorrer la lista Secuencial o seekg

Los punteros no se pueden guardar (cambian en cada ejecución). Se guardan los datos y al cargar se reconstruyen los nodos:

        out << p->dato << "\n";

Caso Práctico: Registro de Estudiantes con Archivo Binario

Programa de consola con menú que integra todo: inserción, búsqueda secuencial, acceso aleatorio, modificación, eliminación lógica y compactación (eliminación física).

#include <iostream>
#include <fstream>
#include <cstdio>
using namespace std;

struct Estudiante {
    int   codigo;
    char  nombre[30];
    float nota;
    bool  activo;          // true = vigente, false = eliminado (borrado logico)
};

const char* ARCHIVO = "estudiantes.dat";

// ---------- BUSQUEDA SECUENCIAL: devuelve la posicion o -1 ----------
int buscarSecuencial(int codigo) {
    ifstream f(ARCHIVO, ios::binary);
    if (!f) return -1;
    Estudiante e;
    int pos = 0;
    while (f.read(reinterpret_cast<char*>(&e), sizeof(e))) {
        if (e.activo && e.codigo == codigo) return pos;
        pos++;
    }
    return -1;
}

// ---------- ACCESO ALEATORIO ----------
bool leerEnPosicion(int pos, Estudiante &e) {
    ifstream f(ARCHIVO, ios::binary);
    if (!f) return false;
    f.seekg(pos * sizeof(Estudiante), ios::beg);
    if (!f.read(reinterpret_cast<char*>(&e), sizeof(e))) return false;
    return true;
}

bool escribirEnPosicion(int pos, const Estudiante &e) {
    fstream f(ARCHIVO, ios::binary | ios::in | ios::out);
    if (!f) return false;
    f.seekp(pos * sizeof(Estudiante), ios::beg);
    f.write(reinterpret_cast<const char*>(&e), sizeof(e));
    return true;
}

// ---------- INSERCION AL FINAL ----------
void insertar() {
    Estudiante e;
    cout << "Codigo: "; cin >> e.codigo;
    if (buscarSecuencial(e.codigo) != -1) {
        cout << "Ese codigo ya existe.\n";
        return;
    }
    cout << "Nombre: "; cin.ignore(); cin.getline(e.nombre, 30);
    cout << "Nota: ";   cin >> e.nota;
    e.activo = true;
    ofstream f(ARCHIVO, ios::binary | ios::app);
    f.write(reinterpret_cast<char*>(&e), sizeof(e));
    cout << "Registro guardado.\n";
}

// ---------- LISTAR (lectura secuencial) ----------
void listar() {
    ifstream f(ARCHIVO, ios::binary);
    Estudiante e;
    int pos = 0, mostrados = 0;
    while (f.read(reinterpret_cast<char*>(&e), sizeof(e))) {
        if (e.activo) {
            cout << "[" << pos << "] " << e.codigo << " | "
                 << e.nombre << " | " << e.nota << "\n";
            mostrados++;
        }
        pos++;
    }
    if (mostrados == 0) cout << "(sin registros)\n";
}

void buscar() {
    int codigo;
    cout << "Codigo a buscar: "; cin >> codigo;
    int pos = buscarSecuencial(codigo);
    Estudiante e;
    if (pos != -1 && leerEnPosicion(pos, e))
        cout << "Encontrado en posicion " << pos << ": "
             << e.nombre << ", nota " << e.nota << "\n";
    else
        cout << "No existe.\n";
}

// ---------- MODIFICAR (seekp en su lugar) ----------
void modificarNota() {
    int codigo; float nueva;
    cout << "Codigo: "; cin >> codigo;
    int pos = buscarSecuencial(codigo);
    Estudiante e;
    if (pos == -1 || !leerEnPosicion(pos, e)) { cout << "No existe.\n"; return; }
    cout << "Nueva nota: "; cin >> nueva;
    e.nota = nueva;
    escribirEnPosicion(pos, e);
    cout << "Nota actualizada.\n";
}

// ---------- ELIMINACION LOGICA ----------
void eliminar() {
    int codigo;
    cout << "Codigo a eliminar: "; cin >> codigo;
    int pos = buscarSecuencial(codigo);
    Estudiante e;
    if (pos == -1 || !leerEnPosicion(pos, e)) { cout << "No existe.\n"; return; }
    e.activo = false;
    escribirEnPosicion(pos, e);
    cout << "Registro eliminado (logico).\n";
}

// ---------- ELIMINACION FISICA: compactar con archivo temporal ----------
void compactar() {
    ifstream in(ARCHIVO, ios::binary);
    ofstream out("temp.dat", ios::binary);
    Estudiante e;
    while (in.read(reinterpret_cast<char*>(&e), sizeof(e)))
        if (e.activo) out.write(reinterpret_cast<char*>(&e), sizeof(e));
    in.close(); out.close();
    remove(ARCHIVO);
    rename("temp.dat", ARCHIVO);
    cout << "Archivo compactado.\n";
}

int main() {
    int op;
    do {
        cout << "\n1.Insertar 2.Listar 3.Buscar 4.Modificar nota "
             << "5.Eliminar 6.Compactar 0.Salir\n> ";
        cin >> op;
        switch (op) {
            case 1: insertar();      break;
            case 2: listar();        break;
            case 3: buscar();        break;
            case 4: modificarNota(); break;
            case 5: eliminar();      break;
            case 6: compactar();     break;
        }
    } while (op != 0);
    return 0;
}

int main() {

int busquedaBinariaArchivo(int codigo) {
    ifstream in("productos.dat", ios::binary);
    if (!in) return -1;
    in.seekg(0, ios::end);
    long bytes = in.tellg();
    int total = bytes / sizeof(Producto);

    int inicio = 0, fin = total - 1;
    Producto p;
    while (inicio <= fin) {
        int medio = inicio + (fin - inicio) / 2;
        in.seekg(medio * sizeof(Producto), ios::beg);
        in.read(reinterpret_cast<char*>(&p), sizeof(p));
        if (p.codigo == codigo) return medio;
        if (p.codigo < codigo) inicio = medio + 1;
        else                   fin = medio - 1;
    }
    return -1;
}

34. Guardar y cargar una lista enlazada Avanzado

struct Nodo { int dato; Nodo* sig; };

void insertarFinal(Nodo*& cab, int x) {
    Nodo* nuevo = new Nodo{x, nullptr};
    if (cab == nullptr) { cab = nuevo; return; }
    Nodo* p = cab;
    while (p->sig != nullptr) p = p->sig;
    p->sig = nuevo;
}

void guardarLista(Nodo* cab, const char* nom) {
    ofstream out(nom);
    for (Nodo* p = cab; p != nullptr; p = p->sig)
        out << p->dato << "\n";
}

Nodo* cargarLista(const char* nom) {
    ifstream in(nom);
    Nodo* cab = nullptr;
    int x;
    while (in >> x) insertarFinal(cab, x);
    return cab;
}

void liberar(Nodo*& cab) {
    while (cab != nullptr) {
        Nodo* t = cab; cab = cab->sig; delete t;
    }
}

int main() {
    Nodo* lista = nullptr;
    insertarFinal(lista, 10); insertarFinal(lista, 20); insertarFinal(lista, 30);
    guardarLista(lista, "lista.txt");
    liberar(lista);                          // la lista desaparece de la RAM
    lista = cargarLista("lista.txt");        // vuelve desde el disco
    for (Nodo* p = lista; p; p = p->sig) cout << p->dato << " ";
    liberar(lista);
    return 0;
}

Resumen y Mejores Prácticas

  • Archivo: datos persistentes en disco. En C++ se usan flujos: ofstream (escribir), ifstream (leer), fstream (ambos). Ciclo: abrir, verificar, operar, cerrar.
  • Tipos: de texto (legibles, por líneas) y binarios (bytes exactos, compactos). Por acceso: secuencial, aleatorio e indexado.
  • Texto: getline y >> para leer, ios::app para agregar. Usa la lectura como condición del ciclo, nunca while(!eof()).
  • Eliminación: remove() borra el archivo, ios::trunc lo vacía y, para quitar un dato de adentro, se copia a un archivo temporal, se hace remove del original y rename del temporal.
  • Registros: struct de tamaño fijo (char[], no string), guardados con write/read y reinterpret_cast. Usa siempre sizeof.
  • Inserción: al final (ios::app, O(1)), en posición (seekp) u ordenada (reescritura con temporal, O(N)).
  • Búsqueda secuencial: O(N), no requiere orden. Acceso aleatorio: seekg(pos * sizeof(...)) en O(1); con archivo ordenado se aplica búsqueda binaria en O(log N).
  • Eliminación de registros: lógica (campo activo, rápida) y física (compactar, recupera espacio).
  • Sistemas de archivos y formatos: el sistema operativo gestiona directorios, metadatos y bloques; el formato real se identifica por su estructura interna (número mágico), no por la extensión.
  • Errores comunes: no verificar is_open(), olvidar close() antes de remove/rename, guardar string en binarios, mezclar lectura y escritura sin seekg/seekp y sumar a mano los tamaños de un struct.
