3.1 Tipos de ordenamiento (1/3): ¿qué es ordenar?

Concepto y orden ascendente o descendente

Ordenar es reorganizar los elementos de una lista (arreglo) siguiendo un criterio.

  • Ascendente: de menor a mayor (1, 2, 5, 9) o de la A a la Z.
  • Descendente: de mayor a menor (9, 5, 2, 1) o de la Z a la A.

Los métodos que veremos son:

  • Burbuja y Shell: comparan e intercambian elementos.
  • Quicksort y Mergesort: dividen el arreglo en partes más pequeñas y las resuelven (divide y vencerás).

Antes de verlos, C++ ya trae un método listo: sort.

Ejemplo en C++

#include <iostream>
#include <algorithm>
#include <functional>
using namespace std;

int main() {
    int a[] = {5, 2, 9, 1};

    sort(a, a + 4);                  // ascendente
    for (int x : a) cout << x << " ";
    cout << endl;

    sort(a, a + 4, greater<int>());  // descendente
    for (int x : a) cout << x << " ";
    return 0;
}

Salida

1 2 5 9
9 5 2 1

3.1 Tipos de ordenamiento (2/3): memoria y estabilidad

Dos formas de clasificar los métodos

Por uso de memoria

  • En el lugar (in-place): ordenan dentro del mismo arreglo, sin copiarlo. Ejemplos: Burbuja, Shell, Quicksort.
  • Con memoria extra: necesitan un arreglo auxiliar del mismo tamaño. Ejemplo: Mergesort.

Por estabilidad

  • Estable: si dos elementos son iguales, mantienen su orden original. Ejemplos: Burbuja, Mergesort.
  • Inestable: pueden cambiar el orden de los iguales. Ejemplos: Shell, Quicksort.

Esto importa al ordenar registros: si ordenas estudiantes por nota, los que tienen la misma nota deberían seguir en el orden en que llegaron.

Ejemplo en C++: orden estable por nota

#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

struct Est { string nombre; int nota; };

bool porNota(Est a, Est b) { return a.nota < b.nota; }

int main() {
    Est v[] = {{"Ana", 5}, {"Beto", 3}, {"Carla", 5}};

    stable_sort(v, v + 3, porNota);   // estable

    for (Est e : v)
        cout << e.nombre << " " << e.nota << endl;
    return 0;
}

Salida

Beto 3
Ana 5
Carla 5

Ana y Carla tienen nota 5 y Ana sigue antes que Carla: el orden estable se conservó.

3.2 Burbuja (1/3): idea del método

Bubble Sort

Recorre el arreglo comparando pares vecinos. Si están en mal orden, los intercambia.

Después de cada pasada, el mayor de los elementos que faltan por ordenar queda en su lugar al final, como una burbuja que sube.

Pasos del algoritmo:

  1. Comparar a[j] con a[j+1].
  2. Si a[j] > a[j+1], intercambiarlos.
  3. Repetir hasta el final del arreglo (una pasada).
  4. Repetir las pasadas hasta que todo quede ordenado.

Tiempo O(N²). En el lugar. Estable.

Una sola pasada en C++

int a[] = {40, 10, 30, 20};
int n = 4;

for (int j = 0; j < n - 1; j++) {
    if (a[j] > a[j + 1]) {
        swap(a[j], a[j + 1]);
    }
}
// Después de una pasada: 10 30 20 40

El 40, que era el mayor, ya quedó al final.

3.2 Burbuja (2/3): algoritmo completo

Con dos ciclos: pasadas y comparaciones

Seguimiento con {40, 10, 30, 20}:

Pasada 1: 10 30 20 40
Pasada 2: 10 20 30 40
Pasada 3: 10 20 30 40  (sin cambios, termina)
  • El ciclo externo i cuenta las pasadas.
  • El ciclo interno j compara pares; cada pasada llega una posición antes (n - i - 1).
  • La variable hubo permite terminar antes si ya no hay intercambios.

Programa completo

#include <iostream>
#include <algorithm>
using namespace std;

void burbuja(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool hubo = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                hubo = true;
            }
        }
        if (!hubo) break;
    }
}

int main() {
    int a[] = {40, 10, 30, 20};
    burbuja(a, 4);
    for (int x : a) cout << x << " ";   // 10 20 30 40
    return 0;
}

3.3 Shell (1/3): idea del método

Shell Sort

Shell mejora el ordenamiento por inserción. En vez de comparar solo vecinos, compara elementos separados por un salto (gap).

El salto empieza grande y se reduce a la mitad hasta llegar a 1. Así los elementos se acercan rápido a su lugar y la última pasada (gap = 1) ya encuentra el arreglo casi ordenado.

Pasos del algoritmo:

  1. Calcular gap = n / 2.
  2. Ordenar por inserción los elementos que están a distancia gap.
  3. Reducir gap = gap / 2.
  4. Repetir hasta terminar con gap = 1.

Mejor que Burbuja. En el lugar. Inestable.

Los saltos para n = 8, en C++

int n = 8;

for (int gap = n / 2; gap > 0; gap /= 2) {
    cout << "gap = " << gap << endl;
}

Salida

gap = 4
gap = 2
gap = 1

3.3 Shell (2/3): algoritmo completo

Inserción con saltos

Seguimiento con {50, 20, 40, 10}:

gap = 2: compara posiciones 0-2 y 1-3
         40 20 50 10
         40 10 50 20
gap = 1: inserción normal
         10 20 40 50
  • Con gap = 2, el 50 y el 40 se intercambian de una vez aunque no son vecinos.
  • Con gap = 1 el arreglo ya está casi ordenado y termina rápido.

Programa completo

#include <iostream>
using namespace std;

void shell(int a[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int temp = a[i];
            int j = i;
            while (j >= gap && a[j - gap] > temp) {
                a[j] = a[j - gap];
                j -= gap;
            }
            a[j] = temp;
        }
    }
}

int main() {
    int a[] = {50, 20, 40, 10};
    shell(a, 4);
    for (int x : a) cout << x << " ";   // 10 20 40 50
    return 0;
}

3.4 Quicksort (1/3): idea del método

Divide y vencerás

Quicksort elige un elemento llamado pivote y reorganiza el arreglo:

  • Los menores al pivote quedan a su izquierda.
  • Los mayores quedan a su derecha.

El pivote queda en su posición final. Luego se repite lo mismo, con recursividad, en la parte izquierda y en la derecha.

Pasos del algoritmo:

  1. Elegir el pivote (aquí, el último elemento).
  2. Particionar: menores a la izquierda, mayores a la derecha.
  3. Aplicar Quicksort a la parte izquierda y a la derecha.
  4. Si una parte tiene 0 o 1 elementos, ya está ordenada.

Promedio O(N log N), peor caso O(N²). En el lugar. Inestable.

La función que particiona, en C++

int particionar(int a[], int bajo, int alto) {
    int pivote = a[alto];
    int i = bajo - 1;

    for (int j = bajo; j < alto; j++) {
        if (a[j] < pivote) {
            i++;
            swap(a[i], a[j]);
        }
    }
    swap(a[i + 1], a[alto]);  // pivote a su lugar
    return i + 1;             // posición del pivote
}

Devuelve la posición final del pivote.

3.4 Quicksort (2/3): algoritmo completo

Partición más recursividad

Seguimiento con {35, 50, 15, 20}:

Pivote = 20
35 no es menor, 50 no es menor
15 es menor: se mueve al inicio
15 50 35 20
Pivote a su lugar:
15 20 35 50
Izquierda {15}: listo
Derecha {35, 50}: se ordena igual

Cada llamada recursiva trabaja sobre una parte más pequeña. El caso base es bajo >= alto.

Programa completo

#include <iostream>
#include <algorithm>
using namespace std;

int particionar(int a[], int bajo, int alto) {
    int pivote = a[alto];
    int i = bajo - 1;
    for (int j = bajo; j < alto; j++) {
        if (a[j] < pivote) {
            i++;
            swap(a[i], a[j]);
        }
    }
    swap(a[i + 1], a[alto]);
    return i + 1;
}

void quickSort(int a[], int bajo, int alto) {
    if (bajo < alto) {
        int p = particionar(a, bajo, alto);
        quickSort(a, bajo, p - 1);
        quickSort(a, p + 1, alto);
    }
}

int main() {
    int a[] = {35, 50, 15, 20};
    quickSort(a, 0, 3);
    for (int x : a) cout << x << " ";   // 15 20 35 50
    return 0;
}

3.5 Mergesort (1/3): idea del método

Dividir y mezclar

Mergesort divide el arreglo por la mitad una y otra vez hasta que cada parte tiene un solo elemento (que ya está ordenado). Después mezcla las partes de dos en dos, de forma ordenada.

Pasos del algoritmo:

  1. Dividir el arreglo en dos mitades.
  2. Ordenar cada mitad con Mergesort (recursividad).
  3. Mezclar las dos mitades ya ordenadas en un solo arreglo ordenado.

La mezcla compara el primer elemento de cada mitad y toma el menor. Para eso copia las mitades en arreglos temporales (memoria extra).

Siempre O(N log N). Usa memoria extra O(N). Estable.

La función que mezcla, en C++

void mezclar(int a[], int ini, int med, int fin) {
    vector<int> izq(a + ini, a + med + 1);
    vector<int> der(a + med + 1, a + fin + 1);

    int i = 0, j = 0, k = ini;
    while (i < izq.size() && j < der.size()) {
        if (izq[i] <= der[j]) a[k++] = izq[i++];
        else                  a[k++] = der[j++];
    }
    while (i < izq.size()) a[k++] = izq[i++];
    while (j < der.size()) a[k++] = der[j++];
}

Los vectores izq y der son la memoria extra.

3.5 Mergesort (2/3): algoritmo completo

Recursividad más mezcla

Seguimiento con {38, 27, 43, 3}:

Dividir:  [38 27] [43 3]
Dividir:  [38] [27] [43] [3]
Mezclar:  [27 38] [3 43]
Mezclar:  [3 27 38 43]

El caso base es ini >= fin: una parte con un solo elemento no necesita ordenarse.

Programa completo

#include <iostream>
#include <vector>
using namespace std;

void mezclar(int a[], int ini, int med, int fin) {
    vector<int> izq(a + ini, a + med + 1);
    vector<int> der(a + med + 1, a + fin + 1);
    int i = 0, j = 0, k = ini;
    while (i < izq.size() && j < der.size()) {
        if (izq[i] <= der[j]) a[k++] = izq[i++];
        else                  a[k++] = der[j++];
    }
    while (i < izq.size()) a[k++] = izq[i++];
    while (j < der.size()) a[k++] = der[j++];
}

void mergeSort(int a[], int ini, int fin) {
    if (ini >= fin) return;
    int med = (ini + fin) / 2;
    mergeSort(a, ini, med);
    mergeSort(a, med + 1, fin);
    mezclar(a, ini, med, fin);
}

int main() {
    int a[] = {38, 27, 43, 3};
    mergeSort(a, 0, 3);
    for (int x : a) cout << x << " ";   // 3 27 38 43
    return 0;
}

Resumen

Método Idea Tiempo Memoria extra Estable
Burbuja Compara vecinos e intercambia O(N²) No Sí
Shell Inserción con saltos (gap) Mejor que O(N²) No No
Quicksort Pivote y partición O(N log N) promedio No No
Mergesort Dividir y mezclar O(N log N) Sí Sí

En C++ se usa sort en la práctica y stable_sort cuando se necesita conservar el orden de los iguales.
