Concepto y nodo (1/3): qué es una lista enlazada

Datos unidos por punteros

Una lista enlazada es una colección de nodos. Cada nodo guarda un dato y la dirección del siguiente nodo.

  • Un puntero llamado cabeza (cab) apunta al primer nodo.
  • El último nodo apunta a nullptr.
  • Una lista vacía es cab == nullptr.

Frente a un arreglo: los nodos no están juntos en memoria, se crean con new cuando se necesitan, y insertar o borrar no obliga a mover los demás elementos. A cambio, no se puede saltar a la posición 5 directamente: hay que recorrer desde la cabeza.

cab --> [10|•] --> [20|•] --> [30|null]

Nodo y lista de 3 elementos, hecha a mano

#include <iostream>
using namespace std;

struct Nodo {
    int   dato;
    Nodo* sig;       // direccion del siguiente nodo
};

int main() {
    Nodo* cab = nullptr;               // lista vacia

    Nodo* a = new Nodo{10, nullptr};   // crear nodos
    Nodo* b = new Nodo{20, nullptr};
    Nodo* c = new Nodo{30, nullptr};

    a->sig = b;                        // enlazarlos
    b->sig = c;
    cab = a;                           // la cabeza es el primero

    for (Nodo* p = cab; p != nullptr; p = p->sig)
        cout << p->dato << " ";        // 10 20 30
    return 0;
}

Con un puntero se accede a un campo con ->: p->dato es lo mismo que (*p).dato.

Concepto y nodo (2/3): puntero, referencia y referencia a puntero

Qué recibe la función y qué puede cambiar

Cuando pasas cab a una función, hay tres opciones:

  • Nodo* p (puntero por valor): la función recibe una copia de la dirección. Puede leer los nodos y cambiar sus datos (p->dato = 5), pero si hace p = otro, solo cambia su copia.
  • Nodo*& cab (referencia a puntero): la función recibe la misma variable cab con otro nombre. Si cambia cab, cambia también el de quien llamó.
  • Nodo** cab (puntero a puntero): es la forma de C para lo mismo. Obliga a escribir *cab en todas partes. En C++ se prefiere Nodo*&.

Regla: si la función puede cambiar a quién apunta la cabeza (lista vacía, insertar o borrar el primero), usa Nodo*&. Si solo recorre o modifica nodos que ya existen, basta Nodo*.

El error típico: insertar al inicio con puntero por valor

// MAL: cab es una copia
void insertarInicioMal(Nodo* cab, int x) {
    Nodo* nuevo = new Nodo{x, cab};
    cab = nuevo;       // cambia solo la copia local
}

// BIEN: cab es la variable original
void insertarInicio(Nodo*& cab, int x) {
    cab = new Nodo{x, cab};
}

int main() {
    Nodo* l1 = nullptr;
    insertarInicioMal(l1, 5);
    // l1 sigue en nullptr: el nodo se perdio (fuga de memoria)

    Nodo* l2 = nullptr;
    insertarInicio(l2, 5);
    // l2 ahora apunta al nodo con 5
    return 0;
}
main:   cab ---> [10|•] ---> null

f(Nodo* cab)    cab' es una COPIA de la direccion
                cambiar cab' no cambia cab

f(Nodo*& cab)   cab' ES cab (otro nombre)
                cambiar cab' cambia cab

Concepto y nodo (3/3): ¿cuál uso en cada operación?

Guía rápida para decidir el parámetro

La función... Parámetro Ejemplos
Solo lee la lista const Nodo* cab mostrar, contar
Recorre y devuelve un nodo, o cambia datos de nodos Nodo* cab buscar
Ya tiene el nodo y trabaja desde él Nodo* p insertarDespues
Puede cambiar la cabeza Nodo*& cab insertarInicio, insertarFinal, eliminar, liberar, invertir
Devuelve un dato por parámetro int& x obtener el dato de la cabeza
Estilo C (no recomendado) Nodo** cab igual que Nodo*&

El int x que se va a insertar se pasa por valor: la función solo necesita su valor.

Recorrer, contar y buscar (1/2)

La cabeza no cambia, así que se pasa por valor

Para recorrer se usa un puntero auxiliar p que empieza en la cabeza y avanza con p = p->sig hasta llegar a nullptr.

  • Nunca se mueve cab mismo: se perdería el inicio de la lista. Se usa una copia (p).
  • Como la función no cambia la cabeza, el parámetro es Nodo* (o const Nodo* si solo lee).
  • buscar devuelve el puntero al nodo, o nullptr si no lo encuentra.

Mostrar, contar y buscar

void mostrar(const Nodo* cab) {
    for (const Nodo* p = cab; p != nullptr; p = p->sig)
        cout << p->dato << " -> ";
    cout << "null" << endl;
}

int contar(const Nodo* cab) {
    int n = 0;
    for (const Nodo* p = cab; p != nullptr; p = p->sig)
        n++;
    return n;
}

Nodo* buscar(Nodo* cab, int x) {
    for (Nodo* p = cab; p != nullptr; p = p->sig)
        if (p->dato == x) return p;
    return nullptr;
}

// uso
Nodo* n = buscar(cab, 20);
if (n != nullptr) n->dato = 25;   // cambiar el dato del nodo

Cambiar n->dato funciona con puntero por valor: se modifica el nodo, no la cabeza.

    // Nodo*& porque al final la cabeza pasa a ser el ultimo nodo
void invertir(Nodo*& cab) {
    Nodo* ant = nullptr;
    Nodo* act = cab;
    while (act != nullptr) {
        Nodo* sig = act->sig;   // guardar el siguiente
        act->sig = ant;         // apuntar hacia atras
        ant = act;
        act = sig;
    }
    cab = ant;                  // nueva cabeza
}
// 10 -> 20 -> 30   queda   30 -> 20 -> 10

Insertar (1/3): al inicio y al final

Ambas pueden cambiar la cabeza, así que usan Nodo*&

Al inicio:

  1. Crear el nodo nuevo, con sig apuntando a la cabeza actual.
  2. La cabeza pasa a ser el nodo nuevo.

Es la operación más rápida: no recorre nada.

Al final:

  1. Crear el nodo nuevo con sig = nullptr.
  2. Si la lista está vacía, el nuevo es la cabeza. Aquí cambia cab: por eso se necesita Nodo*&.
  3. Si no, recorrer hasta el último nodo y enlazarlo.

Programa en C++

void insertarInicio(Nodo*& cab, int x) {
    cab = new Nodo{x, cab};
}

void insertarFinal(Nodo*& cab, int x) {
    Nodo* nuevo = new Nodo{x, nullptr};
    if (cab == nullptr) {       // lista vacia: cambia cab
        cab = nuevo;
        return;
    }
    Nodo* p = cab;
    while (p->sig != nullptr)   // llegar al ultimo
        p = p->sig;
    p->sig = nuevo;
}

int main() {
    Nodo* cab = nullptr;
    insertarFinal(cab, 20);
    insertarFinal(cab, 30);
    insertarInicio(cab, 10);
    mostrar(cab);               // 10 -> 20 -> 30 -> null
    return 0;
}

Insertar (2/3): después de un nodo, en una posición y ordenada

Cuándo basta Nodo* y cuándo hace falta Nodo*&

  • Después de un nodo p: el nodo ya existe y la cabeza no cambia. Basta Nodo* p. Se enlaza primero el nuevo con el siguiente y después p con el nuevo.
  • En una posición: si la posición es 0 cambia la cabeza, por eso usa Nodo*&. Si no, se avanza hasta el nodo anterior.
  • Ordenada: se inserta antes del primer elemento mayor. Si el nuevo es menor que la cabeza (o la lista está vacía) cambia la cabeza: Nodo*&.

Orden importante al enlazar: primero nuevo->sig, después p->sig. Al revés se pierde el resto de la lista.

Programa en C++

void insertarDespues(Nodo* p, int x) {
    if (p == nullptr) return;
    p->sig = new Nodo{x, p->sig};
}

bool insertarEnPosicion(Nodo*& cab, int pos, int x) {
    if (pos < 0) return false;
    if (pos == 0) {                 // cambia la cabeza
        cab = new Nodo{x, cab};
        return true;
    }
    Nodo* p = cab;
    for (int i = 0; i < pos - 1 && p != nullptr; i++)
        p = p->sig;                 // nodo anterior a pos
    if (p == nullptr) return false; // posicion fuera de la lista
    p->sig = new Nodo{x, p->sig};
    return true;
}

void insertarOrdenado(Nodo*& cab, int x) {
    if (cab == nullptr || x < cab->dato) {
        cab = new Nodo{x, cab};     // va primero
        return;
    }
    Nodo* p = cab;
    while (p->sig != nullptr && p->sig->dato < x)
        p = p->sig;
    p->sig = new Nodo{x, p->sig};
}

Eliminar (1/3): el primero y por valor

Pueden cambiar la cabeza, así que usan Nodo*&

Eliminar el primero:

  1. Guardar el nodo en un puntero temporal t.
  2. Mover la cabeza al siguiente.
  3. delete t.

Eliminar por valor:

  1. Si la lista está vacía, no hay nada que hacer.
  2. Si el valor está en la cabeza, se elimina el primero (cambia cab).
  3. Si no, se busca el nodo anterior al que se quiere borrar, se salta el nodo (p->sig = t->sig) y se hace delete t.

Programa en C++

void eliminarInicio(Nodo*& cab) {
    if (cab == nullptr) return;
    Nodo* t = cab;
    cab = cab->sig;          // la cabeza avanza
    delete t;                // liberar el nodo
}

bool eliminarValor(Nodo*& cab, int x) {
    if (cab == nullptr) return false;
    if (cab->dato == x) {    // esta en la cabeza
        eliminarInicio(cab);
        return true;
    }
    Nodo* p = cab;
    while (p->sig != nullptr && p->sig->dato != x)
        p = p->sig;          // p = nodo anterior
    if (p->sig == nullptr) return false;   // no esta
    Nodo* t = p->sig;
    p->sig = t->sig;         // saltar el nodo
    delete t;
    return true;
}

Eliminar (2/3): liberar la memoria

Todo new necesita su delete

Cada nodo creado con new se debe liberar con delete. Si el programa termina o pierde la cabeza sin hacerlo, hay una fuga de memoria.

  • Al borrar un nodo, primero se guarda lo que se necesita (t->sig) y después se hace delete t. Leer t->sig después del delete es un error.
  • liberar usa Nodo*& para que, al terminar, la cab de quien llamó quede en nullptr y no apunte a memoria ya liberada.
  • Se llama a liberar(cab) al final de main.

Liberar toda la lista

void liberar(Nodo*& cab) {
    while (cab != nullptr) {
        Nodo* t = cab;
        cab = cab->sig;      // avanzar ANTES de borrar
        delete t;
    }
}   // al salir, cab == nullptr

int main() {
    Nodo* cab = nullptr;
    insertarFinal(cab, 1);
    insertarFinal(cab, 2);
    insertarFinal(cab, 3);
    mostrar(cab);
    liberar(cab);
    mostrar(cab);            // null (lista vacia)
    return 0;
}

Error: usar el nodo después de borrarlo

delete t;
cab = t->sig;     // MAL: t ya no existe

Lista dentro de una clase (1/2)

Si la cabeza es un atributo, ya no se pasa como parámetro

Al encapsular la lista en una class, la cabeza cab es un atributo privado. Los métodos pueden cambiarla directamente, así que desaparece el problema de pasar Nodo*&.

  • El usuario de la clase llama lista.insertarFinal(5) y no ve punteros.
  • El destructor libera los nodos solo, al terminar el objeto.
  • Se prohíbe copiar la lista (= delete): una copia compartiría los mismos nodos y se liberarían dos veces.
  • Dentro de los métodos, el recorrido sigue usando un puntero auxiliar p.

Programa en C++

class Lista {
    struct Nodo {
        int   dato;
        Nodo* sig;
    };
    Nodo* cab = nullptr;      // atributo de la clase

public:
    Lista() {}
    ~Lista() { limpiar(); }
    Lista(const Lista&) = delete;
    Lista& operator=(const Lista&) = delete;

    void insertarInicio(int x) {
        cab = new Nodo{x, cab};
    }

    void insertarFinal(int x) {
        Nodo* nuevo = new Nodo{x, nullptr};
        if (cab == nullptr) { cab = nuevo; return; }
        Nodo* p = cab;
        while (p->sig != nullptr) p = p->sig;
        p->sig = nuevo;
    }

    void mostrar() const {
        for (Nodo* p = cab; p != nullptr; p = p->sig)
            cout << p->dato << " ";
        cout << endl;
    }

    void limpiar() {
        while (cab != nullptr) {
            Nodo* t = cab;
            cab = cab->sig;
            delete t;
        }
    }
};

int main() {
    Lista l;
    l.insertarFinal(2);
    l.insertarInicio(1);
    l.mostrar();           // 1 2
    return 0;
}   // el destructor libera los nodos

Biblioteca moderna: std::list (1/3)

La lista ya hecha, con memoria automática

std::list (de <list>) es una lista doblemente enlazada: cada nodo conoce al anterior y al siguiente. Ya trae todas las operaciones:

  • Sin new, sin delete y sin punteros: la memoria se libera sola.
  • Insertar y borrar al inicio y al final es inmediato.
  • Se recorre con for (int x : l).

std::forward_list (de <forward_list>) es la versión simplemente enlazada, igual que la que construimos, pero más ligera. No tiene size() ni push_back(); inserta y borra con insert_after y erase_after.

Operaciones básicas

#include <iostream>
#include <list>
using namespace std;

int main() {
    list<int> l;
    l.push_back(20);
    l.push_back(30);
    l.push_front(10);            // 10 20 30

    for (int x : l) cout << x << " ";
    cout << endl;

    cout << l.size()  << endl;    // 3
    cout << l.front() << endl;    // 10
    cout << l.back()  << endl;    // 30

    l.pop_front();               // 20 30
    l.pop_back();                // 20
    l.push_back(5);              // 20 5
    l.remove(20);                // borra los nodos con valor 20
    l.push_back(8);              // 5 8
    l.reverse();                 // 8 5
    l.sort();                    // 5 8
    cout << (l.empty() ? "vacia" : "con datos");
    l.clear();                   // vacia la lista
    return 0;
}

Biblioteca moderna: std::list (2/3)

Iteradores y paso a funciones

Para insertar, borrar o buscar en el medio se usa un iterador: un objeto que se comporta como un puntero a un nodo.

  • l.begin() apunta al primero y l.end() está después del último.
  • *it es el dato. ++it avanza.
  • l.insert(it, x) inserta antes de it.
  • it = l.erase(it) borra ese nodo y devuelve el siguiente. Tras borrar, el iterador viejo ya no sirve.
  • find(l.begin(), l.end(), x) (de <algorithm>) devuelve un iterador; si no lo halla, devuelve l.end().

Referencias aquí: la lista es un objeto, así que no hace falta referencia a puntero. list<int>& si la función la modifica, y const list<int>& si solo la lee. Por valor se copiaría toda la lista.

Iteradores

list<int> l = {10, 20, 30, 40};

auto it = l.begin();
advance(it, 2);              // avanzar 2 (de <iterator>)
l.insert(it, 99);            // 10 20 99 30 40

it = find(l.begin(), l.end(), 20);
if (it != l.end())
    it = l.erase(it);        // 10 99 30 40, it apunta a 99

Paso a funciones

void mostrar(const list<int>& l) {
    for (int x : l) cout << x << " ";
    cout << endl;
}

void agregar(list<int>& l, int x) {
    l.push_back(x);          // cambia la lista de main
}

// Recorrer con iterador y borrar los pares
for (auto it = l.begin(); it != l.end(); ) {
    if (*it % 2 == 0) it = l.erase(it);
    else              ++it;
}

    Ver solución 
    void ordenarSinRepetidos(list<int>& l) {
    l.sort();      // unique solo quita repetidos que estan juntos
    l.unique();
}

int main() {
    list<int> l = {4, 1, 4, 2, 1, 3};

}

Resumen

Tema Idea clave
Nodo struct Nodo { int dato; Nodo* sig; }. La lista vacía es cab == nullptr.
Puntero por valor Nodo* Copia de la dirección. Sirve para recorrer y cambiar datos de nodos, no para cambiar la cabeza.
Referencia a puntero Nodo*& La misma variable cab. Obligatoria si la función puede cambiar la cabeza (insertar, eliminar, liberar, invertir).
Recorrer Puntero auxiliar p = p->sig. Nunca mover cab.
Insertar Enlazar primero el nuevo con lo que sigue y después el anterior con el nuevo.
Eliminar Guardar el nodo en t, saltarlo y hacer delete t. No usar t después.
Clase La cabeza es atributo: los métodos la cambian sin referencias. Destructor y copia prohibida.
std::list Sin punteros ni delete. Iteradores para el medio. list<int>& al pasarla a funciones.

Errores comunes: usar Nodo* en lugar de Nodo*& al insertar o borrar el primero, mover cab al recorrer, olvidar delete, y leer un nodo después de borrarlo.
