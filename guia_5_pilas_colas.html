Pila (1/2): concepto y std::stack

LIFO: el último en entrar es el primero en salir

Una pila solo se toca por un extremo, el tope. Es como una pila de platos: se pone encima y se saca de encima.

Operación Qué hace
push(x) Pone x en el tope
pop() Quita el tope (no devuelve nada)
top() Lee el tope sin quitarlo
empty() ¿Está vacía?
size() Cantidad de elementos 
  |  30  |  <- tope (sale primero)
  |  20  |
  |  10  |  <- fondo (entró primero)

Usos: deshacer (Ctrl+Z), llamadas a funciones, revisar paréntesis.

Programa completo con std::stack

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> pila;

    pila.push(10);
    pila.push(20);
    pila.push(30);

    cout << "Tope: " << pila.top() << endl;       // 30
    cout << "Tamano: " << pila.size() << endl;    // 3

    pila.pop();                                      // quita el 30
    cout << "Nuevo tope: " << pila.top() << endl;  // 20

    // Vaciar la pila mostrando cada elemento
    while (!pila.empty()) {
        cout << pila.top() << " ";                 // 20 10
        pila.pop();
    }
    cout << endl;
    cout << "Vacia? " << (pila.empty() ? "si" : "no");
    return 0;
}

Antes de top() o pop() siempre se comprueba que no esté vacía; hacerlo con la pila vacía es un error.

Pila (2/2): con lista enlazada

Lo mismo que std::stack, pero con nodos y funciones afuera

  • Cada nodo guarda un dato y un puntero siguiente al nodo de abajo.
  • tope es un puntero al primer nodo. Pila vacía: tope == nullptr.
  • El último nodo (el fondo) apunta a nullptr.
  • Las funciones reciben Nodo*& tope (referencia al puntero) cuando cambian el tope: apilar y desapilar.
  • apilar: crear el nodo, hacer que apunte al tope actual y luego mover el tope al nodo nuevo. El orden importa.
  • desapilar: guardar el tope en aux, mover el tope al siguiente y hacer delete aux.
  • No existe "pila llena": crece mientras haya memoria.
Librería Nuestra función
push(x) apilar(tope, x)
pop() desapilar(tope)
top() verTope(tope)
empty() vacia(tope)
size() tamano(tope) 
tope -> [30|•] -> [20|•] -> [10|nullptr]

apilar(tope, 40):
tope -> [40|•] -> [30|•] -> [20|•] -> [10|nullptr]

Programa completo

#include <iostream>
using namespace std;

struct Nodo {
    int dato;
    Nodo* siguiente;
};

bool vacia(Nodo* tope) {
    return tope == nullptr;
}

void apilar(Nodo*& tope, int x) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = x;
    nuevo->siguiente = tope;     // el nuevo apunta al antiguo tope
    tope = nuevo;                // el nuevo pasa a ser el tope
}

int verTope(Nodo* tope) {
    return tope->dato;           // la pila no debe estar vacia
}

void desapilar(Nodo*& tope) {    // la pila no debe estar vacia
    Nodo* aux = tope;
    tope = tope->siguiente;      // el tope baja un nodo
    delete aux;                  // liberar el nodo quitado
}

int tamano(Nodo* tope) {
    int n = 0;
    Nodo* aux = tope;
    while (aux != nullptr) {
        n++;
        aux = aux->siguiente;
    }
    return n;
}

int main() {
    Nodo* tope = nullptr;        // pila vacia

    apilar(tope, 10);
    apilar(tope, 20);
    apilar(tope, 30);

    cout << "Tope: " << verTope(tope) << endl;       // 30
    cout << "Tamano: " << tamano(tope) << endl;     // 3

    desapilar(tope);                                  // quita el 30
    cout << "Nuevo tope: " << verTope(tope) << endl;  // 20

    // Vaciar la pila mostrando cada elemento
    while (!vacia(tope)) {
        cout << verTope(tope) << " ";               // 20 10
        desapilar(tope);
    }
    cout << endl;
    cout << "Vacia? " << (vacia(tope) ? "si" : "no");
    return 0;
}

Recorrer una pila (1/2): std::stack

No tiene índices: se saca de a uno y se usa una pila auxiliar

Con std::stack no hay for sobre sus elementos. Hay dos trucos:

  • Solo mirar: pasar la pila por valor (stack<T> copia). La función trabaja con una copia y la original queda intacta.
  • Reemplazar un dato: pasar la pila por referencia (stack<T>&), pasar todo a una pila auxiliar cambiando el dato buscado, y luego devolver todo a la original. Al pasar dos veces el orden se restaura. 
original (tope primero): Marta Luis Ana
 -> a aux, cambiando Luis
aux      (tope primero): Ana Luis' Marta
 -> de vuelta a la original
original (tope primero): Marta Luis' Ana

Programa completo: mostrar y reemplazar un campo

#include <iostream>
#include <stack>
#include <string>
using namespace std;

struct Estudiante {
    string nombre;
    float  nota;
};

// Por VALOR: trabaja con una copia
void mostrar(stack<Estudiante> copia) {
    cout << "Pila (tope primero):" << endl;
    while (!copia.empty()) {
        cout << "  " << copia.top().nombre << " "
             << copia.top().nota << endl;
        copia.pop();
    }
}

// Por REFERENCIA: modifica la pila original
bool reemplazarNota(stack<Estudiante>& p, const string& nombre, float nueva) {
    stack<Estudiante> aux;
    bool hallado = false;

    while (!p.empty()) {                 // ida: original -> aux
        Estudiante e = p.top();
        p.pop();
        if (!hallado && e.nombre == nombre) {
            e.nota = nueva;              // cambiar el campo
            hallado = true;
        }
        aux.push(e);
    }
    while (!aux.empty()) {               // vuelta: aux -> original
        p.push(aux.top());
        aux.pop();
    }
    return hallado;
}

int main() {
    stack<Estudiante> pila;
    pila.push({"Ana", 4.2f});
    pila.push({"Luis", 3.5f});
    pila.push({"Marta", 4.5f});

    mostrar(pila);
    if (reemplazarNota(pila, "Luis", 4.8f))
        cout << "Nota de Luis actualizada" << endl;
    mostrar(pila);
    return 0;
}

Recorrer una pila (2/2): lista enlazada

Un puntero auxiliar va de nodo en nodo, sin sacar nada

Con nodos no hace falta pila auxiliar ni copia: basta un puntero aux que empieza en el tope y avanza con aux = aux->siguiente hasta llegar a nullptr. 

Nodo* aux = tope;
while (aux != nullptr) {
    // aux->dato es el elemento actual
    aux = aux->siguiente;
}
  • Recorre del tope al fondo.
  • Mostrar: se imprime aux->dato.
  • Reemplazar un campo: se asigna directamente: aux->dato.nota = nueva;
  • Si la función solo mira o cambia un campo (no mueve el tope), el puntero se puede pasar por valor: Nodo* tope. Con Nodo*& solo cuando cambia el propio tope.
  • Nunca se usa tope para recorrer: se perdería el inicio de la pila. Se recorre con aux.

Programa completo: mostrar y reemplazar un campo

#include <iostream>
#include <string>
using namespace std;

struct Estudiante {
    string nombre;
    float  nota;
};

struct Nodo {
    Estudiante dato;
    Nodo* siguiente;
};

void apilar(Nodo*& tope, const Estudiante& e) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = e;
    nuevo->siguiente = tope;
    tope = nuevo;
}

void desapilar(Nodo*& tope) {
    Nodo* aux = tope;
    tope = tope->siguiente;
    delete aux;
}

void mostrar(Nodo* tope) {
    cout << "Pila (tope primero):" << endl;
    Nodo* aux = tope;
    while (aux != nullptr) {
        cout << "  " << aux->dato.nombre << " "
             << aux->dato.nota << endl;
        aux = aux->siguiente;
    }
}

bool reemplazarNota(Nodo* tope, const string& nombre, float nueva) {
    Nodo* aux = tope;
    while (aux != nullptr) {
        if (aux->dato.nombre == nombre) {
            aux->dato.nota = nueva;     // cambiar el campo
            return true;
        }
        aux = aux->siguiente;
    }
    return false;
}

int main() {
    Nodo* tope = nullptr;
    apilar(tope, {"Ana", 4.2f});
    apilar(tope, {"Luis", 3.5f});
    apilar(tope, {"Marta", 4.5f});

    mostrar(tope);
    if (reemplazarNota(tope, "Luis", 4.8f))
        cout << "Nota de Luis actualizada" << endl;
    mostrar(tope);

    while (tope != nullptr)              // liberar la memoria
        desapilar(tope);
    return 0;
}

Salida

Pila (tope primero):
  Marta 4.5
  Luis 3.5
  Ana 4.2
Nota de Luis actualizada
Pila (tope primero):
  Marta 4.5
  Luis 4.8
  Ana 4.2

  2. Escribe una función que muestre la suma y el mayor de una pila de enteros sin destruirla. Pista: recórrela con un puntero auxiliar.
    Ver solución 
    #include <iostream>
using namespace std;

struct Nodo {
    int dato;
    Nodo* siguiente;
};

void apilar(Nodo*& tope, int x) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = x;
    nuevo->siguiente = tope;
    tope = nuevo;
}

    Nodo* aux = tope;
    tope = tope->siguiente;
    delete aux;
}

    int n = 0;
    for (Nodo* aux = tope; aux != nullptr; aux = aux->siguiente) n++;
    return n;
}

void resumen(Nodo* tope) {
    if (tope == nullptr) return;
    int suma = 0, mayor = tope->dato;
    Nodo* aux = tope;
    while (aux != nullptr) {
        suma += aux->dato;
        if (aux->dato > mayor) mayor = aux->dato;
        aux = aux->siguiente;
    }
    cout << "Suma: " << suma << "  Mayor: " << mayor << endl;
}

int main() {
    Nodo* tope = nullptr;
    apilar(tope, 4); apilar(tope, 9); apilar(tope, 2);
    resumen(tope);                       // Suma: 15  Mayor: 9
    cout << "Sigue con " << tamano(tope) << " elementos";   // 3

    while (tope != nullptr) desapilar(tope);
    return 0;
}
  3. Elimina todas las apariciones de un valor en una pila, manteniendo el orden de los demás. Pista: pila auxiliar y referencia.
    Ver solución 
    #include <iostream>
using namespace std;

struct Nodo {
    int dato;
    Nodo* siguiente;
};

void apilar(Nodo*& tope, int x) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = x;
    nuevo->siguiente = tope;
    tope = nuevo;
}

void desapilar(Nodo*& tope) {
    Nodo* aux = tope;
    tope = tope->siguiente;
    delete aux;
}

void eliminarValor(Nodo*& tope, int x) {
    Nodo* aux = nullptr;                 // pila auxiliar
    while (tope != nullptr) {
        if (tope->dato != x) apilar(aux, tope->dato);
        desapilar(tope);
    }
    while (aux != nullptr) {             // devolver en el orden original
        apilar(tope, aux->dato);
        desapilar(aux);
    }
}

int main() {
    Nodo* tope = nullptr;
    int datos[] = {1, 2, 3, 2, 5};
    for (int d : datos) apilar(tope, d);

    eliminarValor(tope, 2);

    while (tope != nullptr) {
        cout << tope->dato << " ";     // 5 3 1
        desapilar(tope);
    }
    return 0;
}

Cola (1/2): concepto y std::queue

FIFO: el primero en entrar es el primero en salir

Una cola tiene dos extremos: se entra por el final y se sale por el frente. Es la fila de un banco.

Operación Qué hace
push(x) Agrega x al final
pop() Quita el del frente (no devuelve nada)
front() Lee el del frente
back() Lee el del final
empty(), size() Vacía y cantidad 
salida <- [10] [20] [30] <- entrada
          frente       final

Usos: cola de impresión, turnos de atención, procesos del sistema operativo.

Programa completo con std::queue

#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> turnos;

    turnos.push("Cliente A");     // encolar
    turnos.push("Cliente B");
    turnos.push("Cliente C");

    cout << "Frente: " << turnos.front() << endl;   // Cliente A
    cout << "Final: "  << turnos.back()  << endl;   // Cliente C
    cout << "En fila: " << turnos.size() << endl;    // 3

    turnos.pop();                 // atiende a Cliente A
    cout << "Siguiente: " << turnos.front() << endl; // Cliente B

    // Atender a todos en orden de llegada
    while (!turnos.empty()) {
        cout << "Atendiendo a " << turnos.front() << endl;
        turnos.pop();
    }
    return 0;
}

Cola (2/2): con lista enlazada

Lo mismo que std::queue, pero con nodos y funciones afuera

  • Mismo nodo de la pila: dato y siguiente.
  • Se usan dos punteros: frente (primer nodo, por donde sale) y fin (último nodo, por donde entra).
  • Cola vacía: frente == nullptr.
  • encolar: crear el nodo con siguiente = nullptr y engancharlo detrás de fin. Si la cola estaba vacía, el nuevo es también el frente.
  • desencolar: guardar el frente en aux, avanzar frente y delete aux. Si la cola quedó vacía, fin también debe volver a nullptr.
  • Las funciones que cambian la cola reciben Nodo*& frente, Nodo*& fin.
Librería Nuestra función
push(x) encolar(frente, fin, x)
pop() desencolar(frente, fin)
front() verFrente(frente)
back() verFin(fin)
empty(), size() vacia(frente), tamano(frente) 
frente -> [10|•] -> [20|•] -> [30|nullptr] <- fin

encolar(frente, fin, 40):
frente -> [10|•] -> [20|•] -> [30|•] -> [40|nullptr] <- fin

Programa completo

#include <iostream>
using namespace std;

struct Nodo {
    int dato;
    Nodo* siguiente;
};

bool vacia(Nodo* frente) {
    return frente == nullptr;
}

void encolar(Nodo*& frente, Nodo*& fin, int x) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = x;
    nuevo->siguiente = nullptr;
    if (fin == nullptr)            // cola vacia
        frente = nuevo;
    else
        fin->siguiente = nuevo;    // enganchar detras del ultimo
    fin = nuevo;
}

int verFrente(Nodo* frente) {
    return frente->dato;           // la cola no debe estar vacia
}

int verFin(Nodo* fin) {
    return fin->dato;              // la cola no debe estar vacia
}

void desencolar(Nodo*& frente, Nodo*& fin) {   // no debe estar vacia
    Nodo* aux = frente;
    frente = frente->siguiente;
    if (frente == nullptr)         // se quedo sin elementos
        fin = nullptr;
    delete aux;
}

int tamano(Nodo* frente) {
    int n = 0;
    Nodo* aux = frente;
    while (aux != nullptr) {
        n++;
        aux = aux->siguiente;
    }
    return n;
}

int main() {
    Nodo* frente = nullptr;        // cola vacia
    Nodo* fin = nullptr;

    encolar(frente, fin, 10);
    encolar(frente, fin, 20);
    encolar(frente, fin, 30);

    cout << "Frente: " << verFrente(frente) << endl;   // 10
    cout << "Final: "  << verFin(fin) << endl;         // 30
    cout << "En fila: " << tamano(frente) << endl;    // 3

    desencolar(frente, fin);                            // sale el 10
    cout << "Siguiente: " << verFrente(frente) << endl; // 20

    // Atender a todos en orden de llegada
    while (!vacia(frente)) {
        cout << "Atendiendo a " << verFrente(frente) << endl;
        desencolar(frente, fin);
    }
    return 0;
}

Recorrer una cola (1/2): std::queue

Se rota: sacar el del frente y volver a meterlo al final

Con std::queue tampoco hay índices. Se hace una rotación completa:

  1. Guardar la cantidad inicial n = size().
  2. Repetir n veces: tomar el frente, pop(), revisar o cambiar el dato y hacer push() otra vez.

Después de n vueltas, todos fueron visitados y la cola queda en el mismo orden.

Para solo mirar, también sirve pasar la cola por valor (una copia).

frente -> Ana, Luis, Marta
vuelta 1: Ana   sale y entra -> Luis, Marta, Ana
vuelta 2: Luis  se cambia   -> Marta, Ana, Luis'
vuelta 3: Marta sale y entra -> Ana, Luis', Marta

Programa completo: mostrar y reemplazar un campo

#include <iostream>
#include <queue>
#include <string>
using namespace std;

struct Estudiante {
    string nombre;
    float  nota;
};

// Por VALOR: trabaja con una copia
void mostrar(queue<Estudiante> copia) {
    cout << "Cola (frente primero):" << endl;
    while (!copia.empty()) {
        cout << "  " << copia.front().nombre << " "
             << copia.front().nota << endl;
        copia.pop();
    }
}

// Por REFERENCIA: rotacion completa
bool reemplazarNota(queue<Estudiante>& c, const string& nombre, float nueva) {
    bool hallado = false;
    int n = c.size();                 // cantidad inicial
    for (int i = 0; i < n; i++) {
        Estudiante e = c.front();
        c.pop();
        if (e.nombre == nombre) {
            e.nota = nueva;           // cambiar el campo
            hallado = true;
        }
        c.push(e);                    // vuelve a entrar por el final
    }
    return hallado;
}

int main() {
    queue<Estudiante> cola;
    cola.push({"Ana", 4.2f});
    cola.push({"Luis", 3.5f});
    cola.push({"Marta", 4.5f});

    mostrar(cola);
    if (reemplazarNota(cola, "Luis", 4.8f))
        cout << "Nota de Luis actualizada" << endl;
    mostrar(cola);
    return 0;
}

Recorrer una cola (2/2): lista enlazada

Un puntero auxiliar va del frente hasta nullptr

Igual que con la pila, pero se empieza en el frente. No hace falta rotar ni copiar nada.

Nodo* aux = frente;
while (aux != nullptr) {
    // aux->dato es el elemento actual
    aux = aux->siguiente;
}
  • Recorre del frente al final, en el orden de llegada.
  • Para mostrar, se imprime aux->dato.
  • Para reemplazar un campo, se asigna directamente: aux->dato.nota = nueva;
  • Para estas funciones basta pasar Nodo* frente por valor, porque no se cambia ni el frente ni el fin.
  • No se mueve frente para recorrer: se perdería la cola. Se recorre con aux.

Programa completo: mostrar y reemplazar un campo

#include <iostream>
#include <string>
using namespace std;

struct Estudiante {
    string nombre;
    float  nota;
};

struct Nodo {
    Estudiante dato;
    Nodo* siguiente;
};

void encolar(Nodo*& frente, Nodo*& fin, const Estudiante& e) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = e;
    nuevo->siguiente = nullptr;
    if (fin == nullptr)
        frente = nuevo;
    else
        fin->siguiente = nuevo;
    fin = nuevo;
}

void desencolar(Nodo*& frente, Nodo*& fin) {
    Nodo* aux = frente;
    frente = frente->siguiente;
    if (frente == nullptr)
        fin = nullptr;
    delete aux;
}

void mostrar(Nodo* frente) {
    cout << "Cola (frente primero):" << endl;
    Nodo* aux = frente;
    while (aux != nullptr) {
        cout << "  " << aux->dato.nombre << " "
             << aux->dato.nota << endl;
        aux = aux->siguiente;
    }
}

bool reemplazarNota(Nodo* frente, const string& nombre, float nueva) {
    Nodo* aux = frente;
    while (aux != nullptr) {
        if (aux->dato.nombre == nombre) {
            aux->dato.nota = nueva;     // cambiar el campo
            return true;
        }
        aux = aux->siguiente;
    }
    return false;
}

int main() {
    Nodo* frente = nullptr;
    Nodo* fin = nullptr;
    encolar(frente, fin, {"Ana", 4.2f});
    encolar(frente, fin, {"Luis", 3.5f});
    encolar(frente, fin, {"Marta", 4.5f});

    desencolar(frente, fin);                 // sale Ana
    encolar(frente, fin, {"Pedro", 3.9f});

    if (reemplazarNota(frente, "Luis", 4.8f))
        cout << "Nota de Luis actualizada" << endl;
    mostrar(frente);                         // Luis 4.8, Marta 4.5, Pedro 3.9

    while (frente != nullptr)                // liberar la memoria
        desencolar(frente, fin);
    return 0;
}

  1. Suma los elementos de una cola sin destruirla, recorriéndola con un puntero auxiliar.
    Ver solución 
    #include <iostream>
using namespace std;

struct Nodo {
    int dato;
    Nodo* siguiente;
};

    nuevo->dato = x;

Aplicaciones con pila

Dos problemas clásicos, con nodos de char

1. Paréntesis balanceados. Cada símbolo que abre se apila. Cada símbolo que cierra debe coincidir con el tope: si no coincide, o la pila está vacía, está mal. Al final, la pila debe quedar vacía.

"{[()]}"  -> balanceado
"(]"      -> no
"(("      -> no (sobra un parentesis)

2. Decimal a binario. Se divide entre 2 y se apila cada residuo (como carácter '0' o '1'). Al desapilar salen en el orden correcto, porque el último residuo es el primer dígito.

13 / 2 = 6  residuo 1
 6 / 2 = 3  residuo 0
 3 / 2 = 1  residuo 1
 1 / 2 = 0  residuo 1
al desapilar: 1 1 0 1

Programa completo

#include <iostream>
#include <string>
using namespace std;

struct Nodo {
    char dato;
    Nodo* siguiente;
};

bool vacia(Nodo* tope) {
    return tope == nullptr;
}

void apilar(Nodo*& tope, char x) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = x;
    nuevo->siguiente = tope;
    tope = nuevo;
}

char verTope(Nodo* tope) {
    return tope->dato;
}

void desapilar(Nodo*& tope) {
    Nodo* aux = tope;
    tope = tope->siguiente;
    delete aux;
}

void liberar(Nodo*& tope) {
    while (!vacia(tope)) desapilar(tope);
}

bool balanceado(const string& s) {
    Nodo* tope = nullptr;
    bool ok = true;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            apilar(tope, c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (vacia(tope)) { ok = false; break; }
            char t = verTope(tope);
            desapilar(tope);
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) { ok = false; break; }
        }
    }
    if (!vacia(tope)) ok = false;      // sobraron simbolos abiertos
    liberar(tope);
    return ok;
}

string decimalABinario(int n) {
    if (n == 0) return "0";
    Nodo* tope = nullptr;
    while (n > 0) {
        apilar(tope, (char)('0' + n % 2));
        n /= 2;
    }
    string bin;
    while (!vacia(tope)) {
        bin += verTope(tope);
        desapilar(tope);
    }
    return bin;
}

int main() {
    cout << balanceado("{[()]}") << endl;   // 1 (si)
    cout << balanceado("(]") << endl;       // 0 (no)
    cout << decimalABinario(13) << endl;    // 1101
    return 0;
}

Aplicación con pila y cola: palíndromo

Una pila y una cola, ambas con el mismo struct Nodo

Se mete cada letra en una pila y en una cola. La pila las entrega de atrás hacia adelante y la cola de adelante hacia atrás. Si todas coinciden, la palabra se lee igual en los dos sentidos.

"reconocer"
pila entrega: r e c o n o c e r
cola entrega: r e c o n o c e r  -> iguales

"casa"
pila entrega: a s a c
cola entrega: c a s a  -> distintos

Se necesitan los dos punteros de la cola (frente, fin) y el puntero de la pila (tope). Se recorren completas para liberar la memoria, aunque ya se sepa la respuesta.

Programa completo

#include <iostream>
#include <string>
using namespace std;

struct Nodo {
    char dato;
    Nodo* siguiente;
};

void apilar(Nodo*& tope, char x) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = x;
    nuevo->siguiente = tope;
    tope = nuevo;
}

void desapilar(Nodo*& tope) {
    Nodo* aux = tope;
    tope = tope->siguiente;
    delete aux;
}

void encolar(Nodo*& frente, Nodo*& fin, char x) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = x;
    nuevo->siguiente = nullptr;
    if (fin == nullptr) frente = nuevo;
    else fin->siguiente = nuevo;
    fin = nuevo;
}

void desencolar(Nodo*& frente, Nodo*& fin) {
    Nodo* aux = frente;
    frente = frente->siguiente;
    if (frente == nullptr) fin = nullptr;
    delete aux;
}

bool esPalindromo(const string& s) {
    Nodo* tope = nullptr;
    Nodo* frente = nullptr;
    Nodo* fin = nullptr;
    for (char c : s) {
        apilar(tope, c);
        encolar(frente, fin, c);
    }
    bool igual = true;
    while (tope != nullptr) {
        if (tope->dato != frente->dato) igual = false;
        desapilar(tope);
        desencolar(frente, fin);
    }
    return igual;
}

int main() {
    cout << esPalindromo("reconocer") << endl;   // 1
    cout << esPalindromo("casa") << endl;        // 0
    return 0;
}

Aplicación con cola: turnos (Round Robin)

Un nodo cuyo dato es un struct Proceso

Cada proceso recibe un tiempo máximo llamado quantum. Si no termina, vuelve al final de la cola con el tiempo que le falta. Así todos avanzan por turnos.

A(5) B(3) C(8), quantum 3
A ejecuto 3, resta 2   (vuelve a la cola)
B termino (3)
C ejecuto 3, resta 5   (vuelve a la cola)
A termino (2)
C ejecuto 3, resta 2   (vuelve a la cola)
C termino (2)

El dato del nodo puede ser cualquier tipo, incluso un struct. Reencolar es sacar el frente y volver a llamar a encolar con el proceso actualizado.

Programa completo

#include <iostream>
#include <string>
using namespace std;

struct Proceso {
    string nombre;
    int    tiempo;
};

struct Nodo {
    Proceso dato;
    Nodo* siguiente;
};

void encolar(Nodo*& frente, Nodo*& fin, const Proceso& p) {
    Nodo* nuevo = new Nodo;
    nuevo->dato = p;
    nuevo->siguiente = nullptr;
    if (fin == nullptr) frente = nuevo;
    else fin->siguiente = nuevo;
    fin = nuevo;
}

void desencolar(Nodo*& frente, Nodo*& fin) {
    Nodo* aux = frente;
    frente = frente->siguiente;
    if (frente == nullptr) fin = nullptr;
    delete aux;
}

void roundRobin(Nodo*& frente, Nodo*& fin, int quantum) {
    while (frente != nullptr) {
        Proceso p = frente->dato;
        desencolar(frente, fin);
        if (p.tiempo > quantum) {
            p.tiempo -= quantum;
            cout << p.nombre << " ejecuto " << quantum
                 << ", resta " << p.tiempo << endl;
            encolar(frente, fin, p);      // vuelve al final
        } else {
            cout << p.nombre << " termino (" << p.tiempo << ")" << endl;
        }
    }
}

int main() {
    Nodo* frente = nullptr;
    Nodo* fin = nullptr;
    encolar(frente, fin, {"A", 5});
    encolar(frente, fin, {"B", 3});
    encolar(frente, fin, {"C", 8});
    roundRobin(frente, fin, 3);
    return 0;
}

Resumen

Pila (LIFO) Cola (FIFO)
Entra por El tope El final
Sale por El tope El frente
Con librería stack: push, pop, top queue: push, pop, front, back
Con lista enlazada Un puntero tope. apilar: el nuevo apunta al tope y pasa a ser el tope. desapilar: el tope baja al siguiente y se hace delete Dos punteros frente y fin. encolar: se engancha detrás de fin. desencolar: el frente avanza y, si queda vacía, fin = nullptr
Estructura struct Nodo { dato; Nodo* siguiente; } y las funciones van afuera, recibiendo Nodo*& cuando cambian el tope, el frente o el fin
Recorrer con librería Pila auxiliar o copia por valor Rotación n veces o copia por valor
Recorrer con lista aux = tope y aux = aux->siguiente hasta nullptr aux = frente y aux = aux->siguiente hasta nullptr
Reemplazar un campo aux->dato.campo = nuevo; (o sacar y reinsertar con la librería)

Errores comunes: usar verTope o verFrente con la estructura vacía (nullptr), olvidar la & en Nodo*& al cambiar tope, frente o fin, no poner fin = nullptr al vaciar la cola, perder la lista por mover tope o frente al recorrer en vez de usar aux, y olvidar el delete al sacar un nodo.
