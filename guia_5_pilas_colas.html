Pila (1/3): concepto y std::stack

LIFO: el último en entrar es el primero en salir

Una pila solo se toca por un extremo, el tope. Es como una pila de platos: se pone encima y se saca de encima.

Operación Qué hace
push(x) Pone x en el tope
pop() Quita el tope (no devuelve nada)
top() Lee el tope sin quitarlo
empty() ¿Está vacía?
size() Cantidad de elementos 
  |  30  |  <- tope (sale primero)
  |  20  |
  |  10  |  <- fondo (entró primero)

Usos: deshacer (Ctrl+Z), llamadas a funciones, revisar paréntesis.

Programa completo con std::stack

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> pila;

    pila.push(10);
    pila.push(20);
    pila.push(30);

    cout << "Tope: " << pila.top() << endl;       // 30
    cout << "Tamano: " << pila.size() << endl;    // 3

    pila.pop();                                      // quita el 30
    cout << "Nuevo tope: " << pila.top() << endl;  // 20

    // Vaciar la pila mostrando cada elemento
    while (!pila.empty()) {
        cout << pila.top() << " ";                 // 20 10
        pila.pop();
    }
    cout << endl;
    cout << "Vacia? " << (pila.empty() ? "si" : "no");
    return 0;
}

Antes de top() o pop() siempre se comprueba que no esté vacía; hacerlo con la pila vacía es un error.

Pila (2/3): con un arreglo, sin librería

Un arreglo y una variable tope

  • El arreglo guarda los datos y tiene un tamaño máximo MAX.
  • tope es el índice del último dato. Vacía: tope == -1.
  • push: sube el tope y guarda ahí el dato.
  • pop: lee el dato del tope y baja el tope.
  • Llena: tope == MAX - 1. Si se intenta un push así, hay desbordamiento (overflow).
  • Los métodos devuelven true o false para avisar si pudieron; el dato sale por el parámetro int& x (referencia).
MAX = 5, despues de 3 push:
indice:  0    1    2    3    4
dato:   [10] [20] [30]  .    .
                  ^ tope = 2

Programa completo

#include <iostream>
using namespace std;

const int MAX = 5;

struct Pila {
    int datos[MAX];
    int tope = -1;                 // -1 = vacia

    bool vacia() const { return tope == -1; }
    bool llena() const { return tope == MAX - 1; }

    bool push(int x) {
        if (llena()) return false; // desbordamiento
        tope++;
        datos[tope] = x;
        return true;
    }

    bool pop(int& x) {
        if (vacia()) return false; // nada que sacar
        x = datos[tope];
        tope--;
        return true;
    }

    bool top(int& x) const {
        if (vacia()) return false;
        x = datos[tope];
        return true;
    }
};

int main() {
    Pila p;
    for (int i = 1; i <= 6; i++) {          // el 6.o no cabe
        if (p.push(i * 10)) cout << "push " << i * 10 << endl;
        else cout << "Pila llena, no cabe " << i * 10 << endl;
    }
    int x;
    p.top(x);
    cout << "Tope: " << x << endl;            // 50
    while (p.pop(x))
        cout << "pop " << x << endl;         // 50 40 30 20 10
    return 0;
}

Pila (3/3): con un vector

El final del vector hace de tope

Un vector ya se comporta como una pila si solo se usa su final:

Pila Vector
push(x) push_back(x)
pop() pop_back()
top() back()
empty() empty()
size() size()
  • No tiene límite MAX: crece solo.
  • Como es un vector, sí se puede recorrer con un for, cosa que std::stack no permite.

Programa completo

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> pila;               // el final es el tope

    pila.push_back(10);             // push
    pila.push_back(20);
    pila.push_back(30);

    cout << "Tope: " << pila.back() << endl;      // 30
    pila.pop_back();                                 // pop
    cout << "Tamano: " << pila.size() << endl;   // 2

    // Recorrer del tope al fondo sin sacar nada
    for (int i = (int)pila.size() - 1; i >= 0; i--)
        cout << pila[i] << " ";                 // 20 10
    cout << endl;

    pila.clear();                                    // vaciar
    cout << (pila.empty() ? "vacia" : "con datos");
    return 0;
}

Recorrer una pila (1/3): std::stack

No tiene índices: se saca de a uno y se usa una pila auxiliar

Con std::stack no hay for sobre sus elementos. Hay dos trucos:

  • Solo mirar: pasar la pila por valor (stack<T> copia). La función trabaja con una copia y la original queda intacta.
  • Reemplazar un dato: pasar la pila por referencia (stack<T>&), pasar todo a una pila auxiliar cambiando el dato buscado, y luego devolver todo a la original. Al pasar dos veces el orden se restaura. 
original (tope primero): Marta Luis Ana
 -> a aux, cambiando Luis
aux      (tope primero): Ana Luis' Marta
 -> de vuelta a la original
original (tope primero): Marta Luis' Ana

Programa completo: mostrar y reemplazar un campo

#include <iostream>
#include <stack>
#include <string>
using namespace std;

struct Estudiante {
    string nombre;
    float  nota;
};

// Por VALOR: trabaja con una copia
void mostrar(stack<Estudiante> copia) {
    cout << "Pila (tope primero):" << endl;
    while (!copia.empty()) {
        cout << "  " << copia.top().nombre << " "
             << copia.top().nota << endl;
        copia.pop();
    }
}

// Por REFERENCIA: modifica la pila original
bool reemplazarNota(stack<Estudiante>& p, const string& nombre, float nueva) {
    stack<Estudiante> aux;
    bool hallado = false;

    while (!p.empty()) {                 // ida: original -> aux
        Estudiante e = p.top();
        p.pop();
        if (!hallado && e.nombre == nombre) {
            e.nota = nueva;              // cambiar el campo
            hallado = true;
        }
        aux.push(e);
    }
    while (!aux.empty()) {               // vuelta: aux -> original
        p.push(aux.top());
        aux.pop();
    }
    return hallado;
}

int main() {
    stack<Estudiante> pila;
    pila.push({"Ana", 4.2f});
    pila.push({"Luis", 3.5f});
    pila.push({"Marta", 4.5f});

    mostrar(pila);
    if (reemplazarNota(pila, "Luis", 4.8f))
        cout << "Nota de Luis actualizada" << endl;
    mostrar(pila);
    return 0;
}

Recorrer una pila (2/3): vector o arreglo

Se recorre con índices y se modifica en el lugar

Si la pila es un vector o un arreglo, se puede recorrer directamente, sin pila auxiliar.

  • Del tope al fondo: for (int i = tope; i >= 0; i--). Con vector, tope es size() - 1.
  • Reemplazar un campo: pila[i].nota = 4.8f;
  • Con for (auto& e : pila) la & es lo que hace que e sea el elemento original. Sin ella, e es una copia y el cambio se pierde.

Misma idea con la pila de arreglo (tema 2/3)

for (int i = p.tope; i >= 0; i--)
    if (p.datos[i].nombre == "Luis")
        p.datos[i].nota = 4.8f;

Esto rompe la regla de "solo se toca el tope", pero sirve para entender cómo se guardan los datos.

Programa completo con vector

#include <iostream>
#include <vector>
#include <string>
using namespace std;

struct Estudiante {
    string nombre;
    float  nota;
};

int main() {
    vector<Estudiante> pila;
    pila.push_back({"Ana", 4.2f});
    pila.push_back({"Luis", 3.5f});
    pila.push_back({"Marta", 4.5f});

    // 1. Recorrer del tope al fondo
    cout << "Antes:" << endl;
    for (int i = (int)pila.size() - 1; i >= 0; i--)
        cout << "  " << pila[i].nombre << " " << pila[i].nota << endl;

    // 2. Reemplazar un campo (auto& = el elemento original)
    for (auto& e : pila)
        if (e.nombre == "Luis")
            e.nota = 4.8f;

    // 3. Error comun: sin & se modifica una COPIA
    for (auto e : pila)
        if (e.nombre == "Ana")
            e.nota = 1.0f;               // no cambia la pila

    cout << "Despues:" << endl;
    for (int i = (int)pila.size() - 1; i >= 0; i--)
        cout << "  " << pila[i].nombre << " " << pila[i].nota << endl;
    return 0;
}

Salida

Antes:
  Marta 4.5
  Luis 3.5
  Ana 4.2
Despues:
  Marta 4.5
  Luis 4.8
  Ana 4.2

  2. Escribe una función que muestre la suma y el mayor de una pila de enteros sin destruirla. Pista: recíbela por valor.
    Ver solución 
    #include <iostream>
#include <stack>
using namespace std;

void resumen(stack<int> copia) {       // por valor: copia
    if (copia.empty()) return;
    int suma = 0, mayor = copia.top();
    while (!copia.empty()) {
        suma += copia.top();
        if (copia.top() > mayor) mayor = copia.top();
        copia.pop();
    }
    cout << "Suma: " << suma << "  Mayor: " << mayor << endl;
}

int main() {
    stack<int> p;
    p.push(4); p.push(9); p.push(2);
    resumen(p);                          // Suma: 15  Mayor: 9
    cout << "Sigue con " << p.size() << " elementos";   // 3
    return 0;
}
  3. Elimina todas las apariciones de un valor en una pila, manteniendo el orden de los demás. Pista: pila auxiliar y referencia.
    Ver solución 
    #include <iostream>
#include <stack>
using namespace std;

void eliminarValor(stack<int>& p, int x) {
    stack<int> aux;
    while (!p.empty()) {
        if (p.top() != x) aux.push(p.top());
        p.pop();
    }
    while (!aux.empty()) {               // devolver en el orden original
        p.push(aux.top());
        aux.pop();
    }
}

int main() {
    stack<int> p;
    int datos[] = {1, 2, 3, 2, 5};
    for (int d : datos) p.push(d);

    eliminarValor(p, 2);

    while (!p.empty()) {
        cout << p.top() << " ";         // 5 3 1
        p.pop();
    }
    return 0;
}

Cola (1/3): concepto y std::queue

FIFO: el primero en entrar es el primero en salir

Una cola tiene dos extremos: se entra por el final y se sale por el frente. Es la fila de un banco.

Operación Qué hace
push(x) Agrega x al final
pop() Quita el del frente (no devuelve nada)
front() Lee el del frente
back() Lee el del final
empty(), size() Vacía y cantidad 
salida <- [10] [20] [30] <- entrada
          frente       final

Usos: cola de impresión, turnos de atención, procesos del sistema operativo.

Programa completo con std::queue

#include <iostream>
#include <queue>
#include <string>
using namespace std;

int main() {
    queue<string> turnos;

    turnos.push("Cliente A");     // encolar
    turnos.push("Cliente B");
    turnos.push("Cliente C");

    cout << "Frente: " << turnos.front() << endl;   // Cliente A
    cout << "Final: "  << turnos.back()  << endl;   // Cliente C
    cout << "En fila: " << turnos.size() << endl;    // 3

    turnos.pop();                 // atiende a Cliente A
    cout << "Siguiente: " << turnos.front() << endl; // Cliente B

    // Atender a todos en orden de llegada
    while (!turnos.empty()) {
        cout << "Atendiendo a " << turnos.front() << endl;
        turnos.pop();
    }
    return 0;
}

Cola (2/3): con un arreglo circular, sin librería

El índice vuelve al inicio con el operador %

Si el frente solo avanzara, al llegar al final del arreglo no se podría seguir aunque haya espacios libres atrás. La solución es la cola circular: después del último índice se vuelve al 0 con % MAX.

  • frente: índice del primer elemento.
  • cuenta: cuántos elementos hay.
  • Posición libre para encolar: (frente + cuenta) % MAX.
  • Al desencolar: frente = (frente + 1) % MAX.
  • Vacía: cuenta == 0. Llena: cuenta == MAX.
MAX = 5. Se encolaron 10..50, se sacaron 10 y 20,
y se encolaron 60 y 70 (vuelven al inicio):
indice:  0    1    2    3    4
dato:   [60] [70] [30] [40] [50]
                  ^ frente = 2, cuenta = 5

Programa completo

#include <iostream>
using namespace std;

const int MAX = 5;

struct Cola {
    int datos[MAX];
    int frente = 0;               // indice del primero
    int cuenta = 0;               // elementos actuales

    bool vacia() const { return cuenta == 0; }
    bool llena() const { return cuenta == MAX; }

    bool encolar(int x) {
        if (llena()) return false;
        int fin = (frente + cuenta) % MAX;   // espacio libre
        datos[fin] = x;
        cuenta++;
        return true;
    }

    bool desencolar(int& x) {
        if (vacia()) return false;
        x = datos[frente];
        frente = (frente + 1) % MAX;         // avanza circular
        cuenta--;
        return true;
    }

    void mostrar() const {                   // recorre sin sacar
        for (int i = 0; i < cuenta; i++)
            cout << datos[(frente + i) % MAX] << " ";
        cout << endl;
    }
};

int main() {
    Cola c;
    for (int i = 1; i <= 6; i++) {           // el 6.o no cabe
        if (!c.encolar(i * 10)) cout << "Cola llena, no cabe " << i * 10 << endl;
    }
    c.mostrar();                             // 10 20 30 40 50

    int x;
    c.desencolar(x);                         // sale 10
    c.desencolar(x);                         // sale 20
    c.encolar(60);                           // usa el espacio liberado
    c.encolar(70);
    c.mostrar();                             // 30 40 50 60 70
    return 0;
}

Cola (3/3): con un vector

Se agrega por el final y se saca por el principio

Cola Vector
push(x) push_back(x)
pop() erase(begin())
front() front()
back() back()
  • Sin límite de tamaño y se puede recorrer con for.
  • Costo: borrar el primero obliga a mover todos los demás un lugar. Es lento si hay muchos datos, pero para aprender y para pocos datos sirve.
  • Si necesitas una opción rápida con la biblioteca, usa std::deque: tiene push_back, pop_front, front y se recorre con índices.

Programa completo con vector

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> cola;

    cola.push_back(10);                // encolar
    cola.push_back(20);
    cola.push_back(30);

    cout << "Frente: " << cola.front() << endl;   // 10
    cout << "Final: "  << cola.back()  << endl;   // 30

    cola.erase(cola.begin());          // desencolar (sale el 10)

    // Recorrer del frente al final
    for (int i = 0; i < (int)cola.size(); i++)
        cout << cola[i] << " ";        // 20 30
    cout << endl;

    // Version con deque (pop_front es rapido)
    // #include <deque>
    // deque<int> d;  d.push_back(1);  d.pop_front();
    return 0;
}

Recorrer una cola (1/3): std::queue

Se rota: sacar el del frente y volver a meterlo al final

Con std::queue tampoco hay índices. Se hace una rotación completa:

  1. Guardar la cantidad inicial n = size().
  2. Repetir n veces: tomar el frente, pop(), revisar o cambiar el dato y hacer push() otra vez.

Después de n vueltas, todos fueron visitados y la cola queda en el mismo orden.

Para solo mirar, también sirve pasar la cola por valor (una copia).

frente -> Ana, Luis, Marta
vuelta 1: Ana   sale y entra -> Luis, Marta, Ana
vuelta 2: Luis  se cambia   -> Marta, Ana, Luis'
vuelta 3: Marta sale y entra -> Ana, Luis', Marta

Programa completo: mostrar y reemplazar un campo

#include <iostream>
#include <queue>
#include <string>
using namespace std;

struct Estudiante {
    string nombre;
    float  nota;
};

// Por VALOR: trabaja con una copia
void mostrar(queue<Estudiante> copia) {
    cout << "Cola (frente primero):" << endl;
    while (!copia.empty()) {
        cout << "  " << copia.front().nombre << " "
             << copia.front().nota << endl;
        copia.pop();
    }
}

// Por REFERENCIA: rotacion completa
bool reemplazarNota(queue<Estudiante>& c, const string& nombre, float nueva) {
    bool hallado = false;
    int n = c.size();                 // cantidad inicial
    for (int i = 0; i < n; i++) {
        Estudiante e = c.front();
        c.pop();
        if (e.nombre == nombre) {
            e.nota = nueva;           // cambiar el campo
            hallado = true;
        }
        c.push(e);                    // vuelve a entrar por el final
    }
    return hallado;
}

int main() {
    queue<Estudiante> cola;
    cola.push({"Ana", 4.2f});
    cola.push({"Luis", 3.5f});
    cola.push({"Marta", 4.5f});

    mostrar(cola);
    if (reemplazarNota(cola, "Luis", 4.8f))
        cout << "Nota de Luis actualizada" << endl;
    mostrar(cola);
    return 0;
}

Recorrer una cola (2/3): arreglo circular

El elemento número i está en (frente + i) % MAX

Con la cola de arreglo se recorre desde el frente, cuenta elementos, y el índice real se calcula con el módulo:

for (int i = 0; i < cuenta; i++) {
    int pos = (frente + i) % MAX;
    // datos[pos] es el elemento i-esimo
}
  • Para mostrar, se imprime datos[pos].
  • Para reemplazar un campo, se asigna directamente: datos[pos].nota = nueva;
  • No hace falta rotar ni copiar nada.

Importante: no se recorre de 0 a MAX, porque la cola puede empezar en cualquier posición y haber espacios sin uso.

Programa completo

#include <iostream>
#include <string>
using namespace std;

const int MAX = 5;

struct Estudiante {
    string nombre;
    float  nota;
};

struct Cola {
    Estudiante datos[MAX];
    int frente = 0;
    int cuenta = 0;

    bool encolar(const Estudiante& e) {
        if (cuenta == MAX) return false;
        datos[(frente + cuenta) % MAX] = e;
        cuenta++;
        return true;
    }

    bool desencolar(Estudiante& e) {
        if (cuenta == 0) return false;
        e = datos[frente];
        frente = (frente + 1) % MAX;
        cuenta--;
        return true;
    }

    void mostrar() const {
        for (int i = 0; i < cuenta; i++) {
            const Estudiante& e = datos[(frente + i) % MAX];
            cout << "  " << e.nombre << " " << e.nota << endl;
        }
    }

    bool reemplazarNota(const string& nombre, float nueva) {
        for (int i = 0; i < cuenta; i++) {
            int pos = (frente + i) % MAX;
            if (datos[pos].nombre == nombre) {
                datos[pos].nota = nueva;
                return true;
            }
        }
        return false;
    }
};

int main() {
    Cola c;
    c.encolar({"Ana", 4.2f});
    c.encolar({"Luis", 3.5f});
    c.encolar({"Marta", 4.5f});

    Estudiante x;
    c.desencolar(x);                  // sale Ana
    c.encolar({"Pedro", 3.9f});       // el arreglo ya esta dando la vuelta

    c.reemplazarNota("Luis", 4.8f);
    c.mostrar();                      // Luis 4.8, Marta 4.5, Pedro 3.9
    return 0;
}

using namespace std;

int main() {

  3. Separa una cola de enteros en dos colas: pares e impares.
    Ver solución 
    #include <iostream>
#include <queue>
using namespace std;

void mostrar(queue<int> q) {          // por valor: no destruye
    while (!q.empty()) {
        cout << q.front() << " ";
        q.pop();
    }
    cout << endl;
}

int main() {
    queue<int> q, pares, impares;
    int datos[] = {7, 2, 9, 4, 5, 6};
    for (int d : datos) q.push(d);

        q.pop();

        else            impares.push(v);

    mostrar(impares);    // 7 9 5
    return 0;
}

Aplicaciones con pila

Dos problemas clásicos

1. Paréntesis balanceados. Cada símbolo que abre se apila. Cada símbolo que cierra debe coincidir con el tope: si no coincide, o la pila está vacía, está mal. Al final, la pila debe quedar vacía.

"{[()]}"  -> balanceado
"(]"      -> no
"(("      -> no (sobra un parentesis)

2. Decimal a binario. Se divide entre 2 y se apila cada residuo. Al desapilar salen en el orden correcto, porque el último residuo es el primer dígito.

13 / 2 = 6  residuo 1
 6 / 2 = 3  residuo 0
 3 / 2 = 1  residuo 1
 1 / 2 = 0  residuo 1
al desapilar: 1 1 0 1

Programa completo

#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool balanceado(const string& s) {
    stack<char> p;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            p.push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (p.empty()) return false;
            char t = p.top();
            p.pop();
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) return false;
        }
    }
    return p.empty();
}

string decimalABinario(int n) {
    if (n == 0) return "0";
    stack<int> residuos;
    while (n > 0) {
        residuos.push(n % 2);
        n /= 2;
    }
    string bin;
    while (!residuos.empty()) {
        bin += to_string(residuos.top());
        residuos.pop();
    }
    return bin;
}

int main() {
    cout << balanceado("{[()]}") << endl;   // 1 (si)
    cout << balanceado("(]") << endl;       // 0 (no)
    cout << decimalABinario(13) << endl;    // 1101
    return 0;
}

Aplicaciones con pila y cola

Palíndromos y turnos de procesos

1. Palíndromo. Se mete cada letra en una pila y en una cola. La pila las entrega de atrás hacia adelante y la cola de adelante hacia atrás. Si todas coinciden, la palabra se lee igual en los dos sentidos.

2. Turnos (Round Robin). Cada proceso recibe un tiempo máximo llamado quantum. Si no termina, vuelve al final de la cola con el tiempo que le falta. Así todos avanzan por turnos.

A(5) B(3) C(8), quantum 3
A ejecuto 3, resta 2   (vuelve a la cola)
B termino (3)
C ejecuto 3, resta 5   (vuelve a la cola)
A termino (2)
C ejecuto 3, resta 2   (vuelve a la cola)
C termino (2)

Programa completo

#include <iostream>
#include <stack>
#include <queue>
#include <string>
using namespace std;

bool esPalindromo(const string& s) {
    stack<char> p;
    queue<char> q;
    for (char c : s) {
        p.push(c);
        q.push(c);
    }
    while (!p.empty()) {
        if (p.top() != q.front()) return false;
        p.pop();
        q.pop();
    }
    return true;
}

struct Proceso {
    string nombre;
    int    tiempo;
};

void roundRobin(queue<Proceso>& q, int quantum) {
    while (!q.empty()) {
        Proceso p = q.front();
        q.pop();
        if (p.tiempo > quantum) {
            p.tiempo -= quantum;
            cout << p.nombre << " ejecuto " << quantum
                 << ", resta " << p.tiempo << endl;
            q.push(p);                    // vuelve al final
        } else {
            cout << p.nombre << " termino (" << p.tiempo << ")" << endl;
        }
    }
}

int main() {
    cout << esPalindromo("reconocer") << endl;   // 1
    cout << esPalindromo("casa") << endl;        // 0

    queue<Proceso> cola;
    cola.push({"A", 5});
    cola.push({"B", 3});
    cola.push({"C", 8});
    roundRobin(cola, 3);
    return 0;
}

Resumen

Pila (LIFO) Cola (FIFO)
Entra por El tope El final
Sale por El tope El frente
Con librería stack: push, pop, top queue: push, pop, front, back
Con arreglo tope sube y baja Circular con % MAX, frente y cuenta
Con vector push_back, pop_back, back push_back, erase(begin()), front
Recorrer con librería Pila auxiliar o copia por valor Rotación n veces o copia por valor
Recorrer con arreglo o vector for del tope al fondo for con (frente + i) % MAX
Reemplazar un campo auto& e o datos[i].campo datos[pos].campo o rotando

Errores comunes: usar top() o front() con la estructura vacía, esperar que pop() devuelva el valor, olvidar la & al modificar (se cambia una copia), recorrer el arreglo circular de 0 a MAX y no revisar si está llena antes de agregar.
