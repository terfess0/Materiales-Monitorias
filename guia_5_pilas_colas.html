5. Pilas y Colas en C++

Estructuras de datos lineales de acceso restringido: métodos LIFO, FILO, FIFO y LILO. Creación, lectura de datos, inserción, eliminación, búsqueda, implementación estática y dinámica, biblioteca STL y aplicaciones en software.

¿Por qué son indispensables las Pilas y Colas?

A diferencia de los arreglos donde puedes acceder a cualquier índice de forma arbitraria (acceso aleatorio), las Pilas y las Colas restringen deliberadamente los puntos de entrada y salida. Este orden estricto es el pilar de los sistemas computacionales modernos:

Pilas (Stacks) • LIFO / FILO

Llamadas a funciones (Call Stack), gestión de memoria, reversión de acciones (Ctrl + Z), verificación de sintaxis y evaluación de expresiones matemáticas.

Colas (Queues) • FIFO / LILO

Planificación de procesos en el CPU (Round Robin), colas de impresión, transmisión de paquetes de red y buffers de atención a usuarios por orden de llegada.

5.0. Concepto de Pila (Stack) y Métodos de Acceso

Una Pila es una estructura de datos lineal y homogénea donde las operaciones de inserción y eliminación se realizan exclusivamente por un único extremo, denominado Tope o Cima (Top).

Principios de Acceso: LIFO y FILO

Son dos formas equivalentes de describir la misma regla fundamental:

  • LIFO Last In, First Out: El último elemento en entrar es el primer elemento en salir.
  • FILO First In, Last Out: El primer elemento en entrar será el último en salir (queda al fondo).

Analogía: Una pila de platos limpios. Cada plato nuevo se coloca sobre el último, y al usar uno, se retira obligatoriamente el que está arriba.

Operación Formal Acción en la Pila Costo Big O
push(x) (Apilar) Inserta el elemento x en el tope O(1)
pop() (Desapilar) Remueve el elemento que está en el tope O(1)
top() / peek() Lee el valor del tope sin removerlo O(1)
estaVacia() / empty() Verifica si la pila no tiene elementos O(1)
buscar(x) Desapila temporalmente hasta encontrar O(N)

Representación Gráfica de Memoria

La variable índice tope rastrea la posición superior. Si la pila está vacía, tope = -1.

[ Índice : Estado en RAM ]
Índice 2: [ 30 ] ← TOPE (Último en entrar / Primero en salir)
Índice 1: [ 20 ]
Índice 0: [ 10 ] ← FONDO (Primer elemento ingresado)

Regla de oro: Nunca intentes acceder directamente a pila[1] desde afuera de la estructura; violarías el principio de encapsulamiento del TAD Pila.

5.1. Creación e Inicialización de una Pila en C++

Para implementar una pila estática en C++ definimos una capacidad máxima MAX, un arreglo para almacenar los datos y una variable entera tope inicializada en -1.

Componentes Fundamentales

  • const int MAX = 100; define el límite físico en memoria.
  • tope = -1; indica formalmente que la pila está vacía.
  • Condición de vacía: tope == -1.
  • Condición de llena: tope == MAX - 1.

Encapsulamiento con struct o class

Agrupar el arreglo y el tope dentro de un struct o class evita variables globales sueltas y permite instanciar múltiples pilas independientes en el mismo programa. 

// Implementación base de Pila Estática en C++
#include <iostream>
using namespace std;

const int MAX = 5; // Capacidad máxima para el ejemplo

struct Pila {
    int elementos[MAX];
    int tope;

    // Constructor: inicializa la pila vacía
    Pila() {
        tope = -1;
    }

    bool estaVacia() const {
        return tope == -1;
    }

    bool estaLlena() const {
        return tope == MAX - 1;
    }

    int cantidad() const {
        return tope + 1;
    }
};

int main() {
    Pila miPila; // Creación de la instancia
    cout << "¿Pila vacía? " << (miPila.estaVacia() ? "Sí" : "No") << endl;
    return 0;
}

5.3. Sacar y Poner Elementos en la Pila

Las dos operaciones esenciales son apilar (push) y desapilar (pop). Ambas exigen verificar los estados límite de la estructura.

1. Poner: Push (Apilar)

Antes de insertar, se comprueba si la pila está llena. Si lo está, ocurre un Desbordamiento (Stack Overflow) y no se puede insertar. Si hay espacio:

  1. Incrementar el tope: tope++.
  2. Almacenar el valor: elementos[tope] = nuevoDato;.

2. Sacar: Pop (Desapilar) y Top (Cima)

Antes de extraer, se comprueba si la pila está vacía. Si lo está, ocurre un Subdesbordamiento (Stack Underflow). Si contiene elementos:

  1. Guardar el valor del tope actual.
  2. Decrementar el índice: tope--.
  3. Retornar el valor extraído.
// Métodos de manipulación en C++
bool push(Pila &p, int valor) {
    if (p.estaLlena()) {
        cout << "[Aviso] Pila llena: Desbordamiento.\n";
        return false;
    }
    p.tope++;
    p.elementos[p.tope] = valor;
    cout << "Apilado con éxito: " << valor << endl;
    return true;
}

bool pop(Pila &p, int &valorExtraido) {
    if (p.estaVacia()) {
        cout << "[Aviso] Pila vacía: Subdesbordamiento.\n";
        return false;
    }
    valorExtraido = p.elementos[p.tope];
    p.tope--;
    return true;
}

bool top(const Pila &p, int &valorTope) {
    if (p.estaVacia()) return false;
    valorTope = p.elementos[p.tope];
    return true;
}

5.2. Lectura de Datos y Búsqueda en Pilas

El reto del acceso restringido: En una pila no está permitido hacer un bucle for(int i = 0; i < n; i++) que lea los elementos internos directamente. Para leer, buscar o modificar datos se utiliza una pila auxiliar.

Protocolo de Lectura sin Destrucción

  1. Crear una pila temporal Pila aux;.
  2. Desapilar cada elemento de la pila original y procesarlo (imprimirlo o comparar).
  3. Apilar el elemento extraído en aux.
  4. Una vez concluido, desapilar de aux y devolver los elementos a la original para restaurar el estado inicial.

Búsqueda y Modificación

Si se desea cambiar un valor específico, se busca durante el paso a la auxiliar; al hallarlo se modifica el dato antes de volver a apilarlo en el proceso de retorno. 

// Lectura y Búsqueda en C++ preservando la Pila
bool buscarYModificar(Pila &p, int buscado, int nuevoValor) {
    Pila aux;
    bool encontrado = false;
    int actual;

    // Fase 1: Pasar a la pila auxiliar buscando el dato
    while (!p.estaVacia()) {
        pop(p, actual);
        if (actual == buscado && !encontrado) {
            actual = nuevoValor; // Modificación del dato
            encontrado = true;
        }
        push(aux, actual);
    }

    // Fase 2: Restaurar los elementos a la pila original
    while (!aux.estaVacia()) {
        pop(aux, actual);
        push(p, actual);
    }

    return encontrado;
}

Pilas con Memoria Dinámica y la Biblioteca STL

En proyectos de producción existen dos opciones modernas: implementar nodos enlazados con punteros o usar el contenedor estándar std::stack.

Pila Dinámica con Nodos Enlazados

No tiene límite rígido MAX. Cada elemento es un nodo que guarda su dato y un puntero al nodo inferior. 

struct Nodo {
    int dato;
    Nodo* siguiente;
};

void pushDinamico(Nodo* &tope, int valor) {
    Nodo* nuevo = new Nodo();
    nuevo->dato = valor;
    nuevo->siguiente = tope;
    tope = nuevo;
}

void popDinamico(Nodo* &tope) {
    if (tope == nullptr) return;
    Nodo* temp = tope;
    tope = tope->siguiente;
    delete temp; // Libera memoria
}

Uso Profesional con <stack> (C++ STL)

Es la forma estándar y segura en la industria. Ofrece soporte para cualquier tipo de dato mediante plantillas (templates). 

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> miPila;

    miPila.push(10);
    miPila.push(20);
    miPila.push(30);

    cout << "Tope actual: " << miPila.top() << endl; // 30
    cout << "Cantidad: " << miPila.size() << endl;  // 3

    miPila.pop(); // Quita el 30

    cout << "Nuevo tope: " << miPila.top() << endl; // 20
    return 0;
}

5.0. Concepto de Cola (Queue) y Métodos FIFO / LILO

Una Cola es una estructura de datos lineal donde las inserciones se realizan por un extremo denominado Final (Rear / Back) y las extracciones se realizan por el extremo opuesto llamado Frente (Front).

Principios de Acceso: FIFO y LILO

  • FIFO First In, First Out: El primer elemento en ingresar es el primero en ser atendido y salir.
  • LILO Last In, Last Out: El último elemento en llegar a la fila será el último en salir de ella.

Analogía: La fila de clientes en un banco o la cola de impresión. Quien llega primero tiene prioridad de atención.

Operación Formal Acción en la Cola Costo Big O
encolar(x) / push Inserta el elemento x al final O(1)
desencolar() / pop Remueve el elemento del frente O(1)
frente() / front Inspecciona el primer elemento O(1)
final() / back Inspecciona el último elemento O(1)

Punteros de Control: Frente y Final

La cola utiliza dos índices para sincronizar el flujo sin tener que desplazar físicamente todos los elementos a la izquierda en cada extracción.

[ 100 ]
FRENTE (Salida)
[ 200 ]
Medio
[ 300 ]
Medio
[ 400 ]
FINAL (Entrada)

Problema de la Cola Lineal Simple

Si solo incrementamos frente y final, se alcanza el final del arreglo aunque queden posiciones libres a la izquierda. La solución técnica es la Cola Circular.

5.1 y 5.3. Implementación de Cola Circular en C++

La Cola Circular une virtualmente el final del arreglo con el principio utilizando el operador módulo % MAX. Esto reutiliza los espacios liberados al desencolar sin mover datos.

Mecánica de la Cola Circular

  • Inicialización: frente = 0; final = -1; contador = 0;
  • Avanzar el final: final = (final + 1) % MAX;
  • Avanzar el frente: frente = (frente + 1) % MAX;
  • Control de capacidad: la variable contador lleva la cuenta exacta de elementos activos.

Eficiencia Garantizada

Tanto encolar como desencolar son operaciones de tiempo constante O(1), ideales para buffers de audio, red y videojuegos en tiempo real. 

// Cola Circular estática en C++
#include <iostream>
using namespace std;

const int MAX = 5;

struct ColaCircular {
    int datos[MAX];
    int frente;
    int final;
    int contador;

    ColaCircular() : frente(0), final(-1), contador(0) {}

    bool estaVacia() const { return contador == 0; }
    bool estaLlena() const { return contador == MAX; }

    bool encolar(int valor) {
        if (estaLlena()) {
            cout << "[Aviso] Cola llena.\n";
            return false;
        }
        final = (final + 1) % MAX; // Salto circular
        datos[final] = valor;
        contador++;
        return true;
    }

    bool desencolar(int &valor) {
        if (estaVacia()) {
            cout << "[Aviso] Cola vacía.\n";
            return false;
        }
        valor = datos[frente];
        frente = (frente + 1) % MAX; // Salto circular
        contador--;
        return true;
    }
};

5.2. Lectura de Datos y Búsqueda en Colas

Al igual que en las pilas, en una cola pura no se deben alterar arbitrariamente los punteros internos. Para listar, contar o buscar elementos preservando el orden original, se desencola hacia una cola auxiliar o se rota la misma cola.

Estrategia 1: Uso de Cola Auxiliar

Desencolas cada elemento, lo imprimes o evalúas, y lo encolas en ColaCircular aux. Al final, regresas todos los elementos de aux a la cola original.

Estrategia 2: Rotación Completa $N$ veces

Conociendo el número de elementos $N$, desencolas un valor y lo vuelves a encolar en la misma estructura inmediatamente. Al repetir $N$ veces, todos los datos fueron leídos y regresaron a su orden inicial. 

// Búsqueda por rotación en C++ sin estructuras extras
bool buscarPorRotacion(ColaCircular &c, int buscado) {
    if (c.estaVacia()) return false;

    int total = c.contador;
    bool encontrado = false;
    int temp;

    for (int i = 0; i < total; i++) {
        c.desencolar(temp);
        if (temp == buscado) {
            encontrado = true;
        }
        c.encolar(temp); // Vuelve a entrar por el final
    }

    return encontrado; // La cola queda intacta
}

Colas Dinámicas y la Biblioteca Estándar (`std::queue`)

En proyectos reales de C++ se utiliza memoria dinámica para soportar colas infinitas o la plantilla industrial std::queue.

Cola Dinámica con Punteros Dobles

Guarda dos punteros: frente y final. Al encolar se liga por el final; al desencolar se avanza por el frente y se libera memoria con delete. 

struct NodoCola {
    int dato;
    NodoCola* siguiente;
};

struct ColaDinamica {
    NodoCola* frente = nullptr;
    NodoCola* final = nullptr;

    void encolar(int v) {
        NodoCola* nuevo = new NodoCola{v, nullptr};
        if (!frente) frente = final = nuevo;
        else { final->siguiente = nuevo; final = nuevo; }
    }
};

Uso Estándar con <queue> en C++

La biblioteca estándar proporciona una cola segura, probada y altamente optimizada. 

#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<string> turnos;

    turnos.push("Cliente A"); // Encolar
    turnos.push("Cliente B");
    turnos.push("Cliente C");

    cout << "Próximo a atender: " << turnos.front() << endl; // Cliente A
    cout << "Último en fila: " << turnos.back() << endl;     // Cliente C

    turnos.pop(); // Se atiende al Cliente A

    cout << "Nuevo próximo: " << turnos.front() << endl;    // Cliente B
    return 0;
}

Aplicaciones en la Industria y Sistemas Computacionales

Las pilas y colas resuelven problemas arquitectónicos fundamentales en sistemas operativos, redes y desarrollo web.

Casos Reales con Pilas (LIFO)

  • Call Stack de la CPU: Cada vez que un programa llama a una función en C++, la dirección de retorno y las variables locales se apilan en el Stack de memoria.
  • Operación Deshacer (Undo / Ctrl + Z): Editores de código y suites como Photoshop apilan cada acción del usuario para revertirla en orden inverso.
  • Validación de Sintaxis: Los compiladores verifican el balanceo de etiquetas HTML, llaves {} y paréntesis ().
  • Evaluador de Expresiones: Conversión de notación infija a postfija (Notación Polaca Inversa) para calculadoras.

Casos Reales con Colas (FIFO)

  • Spooler de Impresión: Los documentos enviados por múltiples usuarios se encolan y se imprimen estrictamente en el orden recibido.
  • Planificador de CPU (Round Robin): El sistema operativo asigna rodajas de tiempo de procesador a cada programa rotándolos en una cola circular.
  • Message Brokers (RabbitMQ / Kafka): Servidores en la nube comunican microservicios procesando millones de transacciones por segundo en colas.
  • Algoritmos de Grafos (BFS): Búsqueda en anchura para encontrar la ruta más corta en mapas (GPS) y redes sociales.

1. Inversión de una Cadena de Texto con Pila

Escribe una función que reciba un string y retorne la cadena invertida utilizando una pila stack<char>.

#include <iostream>
#include <stack>
using namespace std;

string invertir(const string &s) {
    stack<char> p;
    for (char c : s) p.push(c);
    string res = "";
    while (!p.empty()) {
        res += p.top();
        p.pop();
    }
    return res;
}

2. Conteo de Elementos en Pila sin Destruirla

Determina cuántos elementos tiene una pila manual sin acceder a la variable tope, usando una pila auxiliar.

int contarElementos(Pila &p) {
    Pila aux;
    int c = 0, val;
    while (!p.estaVacia()) {
        pop(p, val);
        push(aux, val);
        c++;
    }
    while (!aux.estaVacia()) {
        pop(aux, val);
        push(p, val);
    }
    return c;
}

3. Duplicar Elementos de una Cola

Dada una cola de números enteros, duplica cada valor de forma consecutiva (ej: [1, 2] → [1, 1, 2, 2]).

#include <queue>
void duplicar(queue<int> &q) {
    int n = q.size();
    for (int i = 0; i < n; i++) {
        int v = q.front();
        q.pop();
        q.push(v);
        q.push(v);
    }
}

4. Copiar una Pila Preservando el Orden

Copia todos los datos de una pila origen a una pila destino manteniendo exactamente el mismo orden original.

void copiarPila(stack<int> origen, stack<int> &destino) {
    stack<int> aux;
    while (!origen.empty()) {
        aux.push(origen.top());
        origen.pop();
    }
    while (!aux.empty()) {
        destino.push(aux.top());
        aux.pop();
    }
}

5. Sumar los Elementos de una Cola

Calcula la suma total de los elementos de una cola sin alterar su contenido al finalizar.

int sumarCola(queue<int> &q) {
    int suma = 0, n = q.size();
    for (int i = 0; i < n; i++) {
        int v = q.front();
        suma += v;
        q.pop();
        q.push(v);
    }
    return suma;
}

6. Eliminar el Fondo de una Pila

Elimina el elemento más antiguo (el del fondo) de una pila dejando los demás intactos.

void eliminarFondo(stack<int> &p) {
    if (p.empty()) return;
    stack<int> aux;
    while (p.size() > 1) {
        aux.push(p.top());
        p.pop();
    }
    p.pop(); // Se descarta el fondo
    while (!aux.empty()) {
        p.push(aux.top());
        aux.pop();
    }
}

7. Comprobar si Dos Pilas son Idénticas

Determina si dos pilas contienen los mismos valores en las mismas posiciones sin destruirlas.

bool sonIdenticas(stack<int> a, stack<int> b) {
    if (a.size() != b.size()) return false;
    while (!a.empty()) {
        if (a.top() != b.top()) return false;
        a.pop();
        b.pop();
    }
    return true;
}

8. Separar Pares e Impares de una Cola

Recibe una cola de enteros y genera dos colas separadas: una con los pares y otra con los impares.

void separar(queue<int> q, queue<int> &pares, queue<int> &impares) {
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        if (v % 2 == 0) pares.push(v);
        else impares.push(v);
    }
}

9. Obtener el Valor Mínimo de una Pila

Encuentra el menor valor almacenado en una pila manteniendo su orden original al concluir.

int minimoPila(stack<int> p) {
    if (p.empty()) return -1;
    int minVal = p.top();
    while (!p.empty()) {
        if (p.top() < minVal) minVal = p.top();
        p.pop();
    }
    return minVal;
}

10. Invertir una Cola Utilizando una Pila

Invierte completamente el orden de los elementos de una cola utilizando una pila como intermediaria.

void invertirCola(queue<int> &q) {
    stack<int> p;

        p.push(q.front());
        q.pop();
    }
    while (!p.empty()) {
        q.push(p.top());
        p.pop();
    }
}

11. Verificación de Paréntesis y Corchetes Balanceados

Verifica si una cadena contiene delimitadores bien balanceados: (), [], {}.

#include <stack>
bool balanceado(const string &expr) {
    stack<char> p;
    for (char c : expr) {
        if (c == '(' || c == '[' || c == '{') p.push(c);
        else if (c == ')' || c == ']' || c == '}') {
            if (p.empty()) return false;
            char t = p.top(); p.pop();
            if (c == ')' && t != '(') return false;
            if (c == ']' && t != '[') return false;
            if (c == '}' && t != '{') return false;
        }
    }
    return p.empty();
}

12. Conversión de Decimal a Binario con Pila

Convierte un número entero positivo a su representación binaria apilando los residuos de la división sucesiva por 2.

string decimalABinario(int n) {
    if (n == 0) return "0";
    stack<int> residuos;
    while (n > 0) {
        residuos.push(n % 2);
        n /= 2;
    }
    string bin = "";
    while (!residuos.empty()) {
        bin += to_string(residuos.top());
        residuos.pop();
    }
    return bin;
}

13. Comprobación de Palíndromos con Pila y Cola

Determina si una palabra se lee igual al derecho y al revés comparando el frente de una cola con el tope de una pila.

bool esPalindromo(const string &palabra) {
    stack<char> p;
    queue<char> q;
    for (char c : palabra) {
        p.push(c);
        q.push(c);
    }
    while (!p.empty()) {
        if (p.top() != q.front()) return false;
        p.pop();
        q.pop();
    }
    return true;
}

14. Intercalado de Dos Colas

Combina dos colas $A$ y $B$ de igual longitud intercalando sus elementos en una tercera cola $C$.

queue<int> intercalar(queue<int> a, queue<int> b) {
    queue<int> c;
    while (!a.empty() || !b.empty()) {
        if (!a.empty()) { c.push(a.front()); a.pop(); }
        if (!b.empty()) { c.push(b.front()); b.pop(); }
    }
    return c;
}

15. Eliminar Ocurrencias de un Valor en una Pila

void eliminarValor(stack<int> &p, int x) {
    stack<int> aux;
    while (!p.empty()) {
        if (p.top() != x) aux.push(p.top());
        p.pop();

    while (!aux.empty()) {
        p.push(aux.top());

}

16. Fusión Ordenada de Dos Colas Ordenadas

Dadas dos colas cuyos elementos están ordenados de menor a mayor, crea una tercera cola ordenada sin usar algoritmos de ordenamiento.

queue<int> fusionarOrdenadas(queue<int> a, queue<int> b) {
    queue<int> res;
    while (!a.empty() && !b.empty()) {
        if (a.front() <= b.front()) {
            res.push(a.front()); a.pop();
        } else {
            res.push(b.front()); b.pop();
        }
    }
    while (!a.empty()) { res.push(a.front()); a.pop(); }
    while (!b.empty()) { res.push(b.front()); b.pop(); }
    return res;
}

17. Ordenar una Pila Usando Otra Pila Auxiliar

Ordena los elementos de una pila de menor a mayor (el menor en el tope) utilizando únicamente otra pila auxiliar.

void ordenarPila(stack<int> &p) {
    stack<int> aux;
    while (!p.empty()) {
        int temp = p.top();
        p.pop();
        while (!aux.empty() && aux.top() > temp) {
            p.push(aux.top());
            aux.pop();
        }
        aux.push(temp);
    }
    p = aux;
}

18. Invertir los Primeros K Elementos de una Cola

Invierte únicamente los primeros $K$ elementos de una cola dejando el resto en su orden original.

void invertirK(queue<int> &q, int k) {
    if (q.empty() || k <= 0 || k > q.size()) return;
    stack<int> p;
    for (int i = 0; i < k; i++) {
        p.push(q.front());
        q.pop();
    }
    while (!p.empty()) {
        q.push(p.top());
        p.pop();
    }
    int restantes = q.size() - k;
    for (int i = 0; i < restantes; i++) {
        q.push(q.front());
        q.pop();
    }
}

19. Comprobar si los Elementos de una Pila son Consecutivos

Determina si cada elemento difiere en exactamente 1 con el elemento adyacente en la pila.

bool sonConsecutivos(stack<int> p) {
    if (p.size() <= 1) return true;
    int prev = p.top(); p.pop();
    while (!p.empty()) {
        int act = p.top(); p.pop();
        if (abs(prev - act) != 1) return false;
        prev = act;
    }
    return true;
}

20. Reemplazar Elementos Mayores que un Umbral en Cola

void truncarCola(queue<int> &q, int limite) {
    int n = q.size();

        q.push(v);

}

21. Evaluación de Expresiones Postfijas (Notación Polaca Inversa)

Evalúa una expresión aritmética en notación postfija como "5 3 + 2 *" utilizando una pila de operandos.

#include <sstream>
int evaluarPostfijo(const string &expr) {
    stack<int> p;
    stringstream ss(expr);
    string token;
    while (ss >> token) {
        if (token == "+" || token == "-" || token == "*" || token == "/") {
            int b = p.top(); p.pop();
            int a = p.top(); p.pop();
            if (token == "+") p.push(a + b);
            else if (token == "-") p.push(a - b);
            else if (token == "*") p.push(a * b);
            else if (token == "/") p.push(a / b);
        } else {
            p.push(stoi(token));
        }
    }
    return p.top();
}

22. Implementar una Cola Utilizando Dos Pilas

Construye una estructura ColaConPilas que emule operaciones FIFO (push y pop) empleando internamente dos pilas.

struct ColaConPilas {
    stack<int> entrada, salida;

    void encolar(int x) { entrada.push(x); }

    int desencolar() {
        if (salida.empty()) {
            while (!entrada.empty()) {
                salida.push(entrada.top());
                entrada.pop();
            }
        }
        if (salida.empty()) return -1;
        int v = salida.top(); salida.pop();
        return v;
    }
};

23. Sistema de "Deshacer" y "Rehacer" (Undo / Redo)

Implementa el mecanismo clásico de editores de texto con dos pilas: una de acciones realizadas y otra de deshechas.

struct EditorTexto {
    stack<string> undoStack;
    stack<string> redoStack;
    string textoActual = "";

    void escribir(string nuevo) {
        undoStack.push(textoActual);
        textoActual += nuevo;
        while (!redoStack.empty()) redoStack.pop();
    }
    void deshacer() {
        if (!undoStack.empty()) {
            redoStack.push(textoActual);
            textoActual = undoStack.top();
            undoStack.pop();
        }
    }
    void rehacer() {
        if (!redoStack.empty()) {
            undoStack.push(textoActual);
            textoActual = redoStack.top();
            redoStack.pop();
        }
    }
};

24. Simulación de Planificación Round Robin con Cola

Simula el reparto de tiempo de procesador en un sistema operativo con un quántum determinado.

struct Proceso { string nombre; int tiempo; };

void roundRobin(queue<Proceso> &q, int quantum) {
    while (!q.empty()) {
        Proceso p = q.front(); q.pop();
        if (p.tiempo > quantum) {
            p.tiempo -= quantum;
            cout << p.nombre << " ejecutó " << quantum << "ms. Resta: " << p.tiempo << "ms\n";
            q.push(p);
        } else {
            cout << p.nombre << " TERMINÓ tras ejecutar " << p.tiempo << "ms\n";
        }
    }
}

25. Encontrar el Siguiente Mayor Elemento (Next Greater Element)

Dado un arreglo de enteros, encuentra para cada posición el primer elemento mayor a su derecha utilizando una pila monótona $O(N)$.

#include <vector>
vector<int> siguienteMayor(const vector<int>& arr) {
    int n = arr.size();
    vector<int> res(n, -1);
    stack<int> p; // Guarda índices
    for (int i = 0; i < n; i++) {
        while (!p.empty() && arr[i] > arr[p.top()]) {
            res[p.top()] = arr[i];
            p.pop();
        }
        p.push(i);
    }
    return res;
}

26. Bicola (Deque) Implementada con Arreglo Circular

Crea una estructura donde se pueda insertar y eliminar libremente tanto por el frente como por el final.

struct Bicola {
    static const int CAP = 100;
    int arr[CAP];
    int frente = 0, final = -1, tam = 0;

    void pushFront(int v) {
        frente = (frente - 1 + CAP) % CAP;
        arr[frente] = v; tam++;
    }
    void pushBack(int v) {
        final = (final + 1) % CAP;
        arr[final] = v; tam++;
    }
    int popFront() {
        int v = arr[frente];
        frente = (frente + 1) % CAP; tam--; return v;
    }
    int popBack() {
        int v = arr[final];
        final = (final - 1 + CAP) % CAP; tam--; return v;
    }
};

27. Simplificación de Rutas de Archivos estilo UNIX

Convierte una ruta como "/a/./b/../../c/" a su formato canónico "/c" utilizando una pila de directorios.

string simplificarRuta(string path) {
    stack<string> p;
    stringstream ss(path);
    string dir;
    while (getline(ss, dir, '/')) {
        if (dir == "" || dir == ".") continue;
        if (dir == "..") {
            if (!p.empty()) p.pop();
        } else p.push(dir);
    }
    string res = "";
    while (!p.empty()) { res = "/" + p.top() + res; p.pop(); }
    return res.empty() ? "/" : res;
}

29. Pila con Consulta del Mínimo en Tiempo Constante O(1)

Crea una estructura MinStack que soporte push(), pop(), top() y getMin() en $O(1)$ sin recorrer la pila.

struct MinStack {
    stack<int> datos;
    stack<int> minimos;

    void push(int val) {
        datos.push(val);
        if (minimos.empty() || val <= minimos.top()) minimos.push(val);
    }
    void pop() {
        if (datos.empty()) return;
        if (datos.top() == minimos.top()) minimos.pop();
        datos.pop();
    }
    int top() { return datos.top(); }
    int getMin() { return minimos.top(); }
};

30. Eliminación de Duplicados Adyacentes en Cadena

Elimina pares de caracteres repetidos adyacentes de forma iterativa (ej: "abbaca" → "ca") usando una pila.

string eliminarDuplicados(string s) {
    stack<char> p;
    for (char c : s) {
        if (!p.empty() && p.top() == c) p.pop();
        else p.push(c);
    }
    string res = "";
    while (!p.empty()) { res += p.top(); p.pop(); }
    reverse(res.begin(), res.end());
    return res;
}
