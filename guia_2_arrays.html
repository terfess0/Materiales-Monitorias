Arrays Multidimensionales (3D o más)

Imagina un Cubo de Rubik, o un edificio: Piso (z), Fila de apartamentos (y), Número de cuarto (x).

De la Teoría a la Práctica

A nivel de hardware, la memoria del computador sigue siendo una línea recta (1D). C++ hace la matemática internamente para traducir cubo[piso][fila][col] a una posición lineal.

Puedes crear arrays de 3, 4 o más dimensiones, pero ten cuidado: la memoria requerida crece exponencialmente.

  • int datos[10] = 10 enteros
  • int datos[10][10] = 100 enteros
  • int datos[10][10][10] = 1,000 enteros

En C++

// 3 Dimensiones (ej: 2 páginas, 3 filas, 4 columnas)
int cubo[2][3][4];

// Acceso específico
cubo[1][2][3] = 99;

// Recorrido requiere 3 for anidados
for(int p = 0; p < 2; p++) {
    for(int f = 0; f < 3; f++) {
        for(int c = 0; c < 4; c++) {
            cubo[p][f][c] = 0; // Limpiar cubo
        }
    }
}

¿push_back() o asignación con v[i]?

Dos formas de trabajar con un vector: cuándo conviene usar push_back() y por qué no debes usar v[i] para agregar elementos nuevos.

Diferencias y Cuándo Usar Cada Uno

  • Para agregar datos usa push_back(x): El vector se encarga de apartar espacio y actualiza su tamaño automáticamente. Agregar
  • Para modificar usa v[i] = x: Solo se debe usar sobre casillas que ya existen (de 0 a size() - 1). Por ejemplo, si creaste vector<int> v(5); ya tienes 5 casillas listas para editar. Modificar
  • ¿Por qué no usar v[i] para agregar? Si intentas hacer v[i] = x con un índice mayor o igual al tamaño actual, v.size() no sabrá que agregaste ese elemento y seguirá mostrando el tamaño anterior. Además, estás accediendo a una posición no reservada, lo que puede causar fallos inesperados en el programa. Importante

Comparativa en C++

#include <iostream>
#include <vector>
using namespace std;

// CASO 1: Agregar elementos con push_back()
vector<int> a; // Inicia con tamaño 0 (vacío)
a.push_back(10); // Tamaño pasa a 1 -> [10]
a.push_back(20); // Tamaño pasa a 2 -> [10, 20]
a.pop_back();    // Retira el 20 -> queda [10]

// CASO 2: Vector con tamaño inicial y modificar con v[i]
int n = 3;
vector<int> b(n); // Ya tiene 3 casillas: [0, 0, 0]
b[0] = 100;       // Modifica la casilla 0
b[1] = 200;       // Modifica la casilla 1
b[2] = 300;       // Modifica la casilla 2

// ¿Qué pasa si haces b[5] = 500?
// b.size() seguirá diciendo 3 (no sabrá que está ahí),
// y esa casilla no está apartada. ¡Usa push_back()!

Simulador: Inserción y Desplazamiento (insert)

A diferencia de push_back() que solo añade al final, insert() permite colocar datos en cualquier posición mediante iteradores, empujando los demás elementos a la derecha.

Elementos: 4 Empuja elementos a la derecha
Posiciones con iteradores: begin() al inicio | end() al final 
// Estado inicial: vector<int> v = {10, 20, 30, 40};
v.insert(v.begin() + 2, 77); // Desplaza [30, 40] a la derecha

Observa cómo los elementos existentes abren espacio desplazándose hacia la derecha para dar lugar al nuevo elemento.

Inserción con insert() e Iteradores

Comprende cómo los iteradores indican la posición exacta donde quieres insertar y qué hace el computador por dentro.

¿Cómo funcionan los Iteradores en insert()?

insert() no recibe un número entero simple, sino un iterador (un indicador de posición):

  • v.begin(): Apunta al primer elemento (índice 0).
  • v.begin() + k: Apunta a la posición con índice $k$.
  • v.end(): Apunta justo después del último elemento.

¿Qué pasa por dentro? Al insertar al inicio o en el medio, C++ debe mover todos los elementos posteriores una casilla hacia la derecha para abrir espacio. Por eso, insertar al final con push_back() es mucho más directo.

Sintaxis y Ejemplos en C++

#include <iostream>
#include <vector>
using namespace std;

vector<int> v = {10, 20, 30, 40};

// 1. Insertar al principio (índice 0)
v.insert(v.begin(), 5);
// Resultado: {5, 10, 20, 30, 40}

// 2. Insertar en una posición específica (ej: índice 2)
v.insert(v.begin() + 2, 77);
// Resultado: {5, 10, 77, 20, 30, 40}

// 3. Insertar varias copias del mismo número
// v.insert(posicion, cantidad, valor)
v.insert(v.begin() + 1, 2, 99); // Inserta dos 99s

Simulador: Eliminación y Compactación (erase)

erase() elimina un dato puntual o un rango completo de elementos continuos, compactando el vector hacia la izquierda para no dejar huecos.

Elementos restantes: 6 Compacta elementos a la izquierda
Regla de oro: El rango [inicio, fin) excluye el elemento fin 
// Vector inicial: {15, 28, 42, 60, 75, 90}
v.erase(v.begin() + 1, v.begin() + 4); // Elimina índices 1, 2 y 3

Haz clic en "Borrar Rango" para ver cómo se resalta y elimina un subconjunto entero en un solo paso.

Eliminación con erase(): Puntual y por Rango

La regla del rango semiabierto $[inicio, fin)$, limpieza completa con clear() y verificación con empty().

Puntual, Rangos y Limpieza Total

  • Borrado Puntual: v.erase(v.begin() + i); elimina únicamente el dato en la posición $i$. Los elementos a la derecha se corren hacia la izquierda. Puntual
  • Borrado por Rango Semiabierto: v.erase(ini, fin); elimina todos los elementos desde ini hasta justo antes de fin. El elemento en fin no se borra. Rango
  • Limpieza Rápida: v.clear() elimina todos los datos a la vez dejando el tamaño en 0. Puedes comprobar si quedó vacío con v.empty() (devuelve true). Limpieza

En C++

#include <iostream>
#include <vector>
using namespace std;

vector<int> v = {15, 28, 42, 60, 75, 90};

// 1. Borrar un elemento puntual (índice 2: el 42)
v.erase(v.begin() + 2);
// Queda: {15, 28, 60, 75, 90}

// 2. Borrar un RANGO: borra índices 1, 2 y 3 (excluye el 4)
// Borra el 28, 42 y 60. Conserva el 75 (índice 4).
v.erase(v.begin() + 1, v.begin() + 4);
// Queda: {15, 75, 90}

// 3. Vaciar completamente
v.clear();
if (v.empty()) {
    cout << "El vector está vacío";
}

Matrices con Vectores: Concepto y Sintaxis

Cómo declarar matrices dinámicas, crear filas de tamaño variable (matrices irregulares) y recorrerlas con bucles anidados en C++.

Ventajas frente a la Matriz Clásica (int m[3][4])

  • Tamaño al Ejecutar: Puedes pedir las filas y columnas al usuario con cin >> f >> c; y crear la matriz a la medida exacta sin tamaños fijos. Flexible
  • Filas de Diferente Tamaño: Cada fila es un vector independiente. Una fila puede tener 2 elementos y otra 10 sin desperdiciar casillas vacías. Versátil
  • Fácil de Pasar a Funciones: Se pasa directamente como void procesar(vector<vector<int>>& m) sin tener que definir un número de columnas fijo en la función. Limpio

Sintaxis y Recorrido en C++

#include <iostream>
#include <vector>
using namespace std;

// 1. Inicialización con datos predefinidos
vector<vector<int>> m = {
    {1, 5, 9, 3}, // Fila 0
    {7, 2, 8, 4}, // Fila 1
    {6, 0, 1, 5}  // Fila 2
};

// 2. Crear matriz de F filas x C columnas llena de ceros:
int F = 3, C = 4;
vector<vector<int>> vacia(F, vector<int>(C, 0));

// 3. Recorrido dinámico con bucles:
for(int i = 0; i < m.size(); i++) {
    for(int j = 0; j < m[i].size(); j++) {
        cout << m[i][j] << " ";
    }
    cout << endl;
}

Listas vs. Arrays

¿Cuándo usar un Array/Vector y cuándo usar una Lista (std::list)?

Array / std::vector

Memoria: Continua/Contigua (bloque único).

Ventaja: Acceso instantáneo. Si quieres la posición 1000, vas directo con v[1000].

Desventaja: Insertar o borrar en el medio es lento (hay que empujar todos los demás elementos).

Lista Doblemente Enlazada (std::list)

Memoria: Nodos esparcidos unidos por punteros.

Ventaja: Insertar o borrar datos en el medio es rapidísimo.

Desventaja: Acceso secuencial. No puedes hacer lista[1000], debes recorrerla desde el principio.

30. Reto Final: Vector de Notas Dinámico Avanzado

Planteamiento: Pide al usuario meter calificaciones hasta ingresar -1. Guarda en un vector. Ordena el vector de menor a mayor. Elimina la nota más baja usando erase(). Imprime el promedio de las notas restantes.

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<float> notas;
    float nota;
    
    cout << "Ingresa notas (-1 para fin):\n";
    while(cin >> nota && nota != -1) {
        notas.push_back(nota);
    }
    
    if(!notas.empty()) {
        sort(notas.begin(), notas.end());
        notas.erase(notas.begin()); // Elimina la mas baja
        
        float suma = 0;
        for(float n : notas) suma += n;
        
        cout << "Promedio sin la peor nota: " << suma / notas.size();
    }
    return 0;
}

Resumen

  • Arrays 1D: Conjunto ordenado y finito de variables en una sola línea (estáticos).
  • Arrays 2D (Matrices): "Array de arrays", ideal para cuadrículas, tableros o sistemas de coordenadas. Requiere dos índices.
  • Multidimensionales (3D+): Útiles para modelar el espacio, pero el consumo de memoria crece muy rápido.
  • std::vector y Operaciones Clave: Estructura dinámica en el Heap. Crece con push_back() o se indexa con v[i] si fue predimensionado. Permite inserciones con insert() y eliminaciones puntuales o por rangos semiabiertos [inicio, fin) con erase().
  • Matrices con Vectores (Vectores 2D): vector<vector<T>> supera las limitaciones de las matrices estáticas: memoria dinámica en el Heap, paso limpio a funciones y soporte para filas de longitud variable (matrices irregulares o jagged).
  • <algorithm>: Utiliza siempre esta librería para no reinventar la rueda (sort, reverse, count).
